# 服务维护工具

本轮只更新课程GitHub源码，不部署服务、不更改生产账号/成绩/场次。现有场次使用保存的题库快照，题库源码更新不得覆盖这些快照。真实运行目录、凭据、数据库、会话映射和备份只由部署环境保管，不纳入公开课程仓库。

backfill_session_snapshots.py可先只读检查已有数据库与对应历史题库，只有另获部署授权、确认逐场次来源及完整性并指定新的备份文件时才可写入。保存快照的场次不得覆盖；名称相同也要核整份题库SHA-256。测试使用临时数据库与明确合成的映射，不能拿合成映射处理实际场次。

维护者需要时可从本仓库Git历史查看旧操作文档，但不得把历史记录当当前环境状态或本轮执行授权。Dockerfile、compose及HTTP接口保留；生产环境由明确授权的维护流程单独管理。
