# 第14课（S12）｜失败诊断与最终评价

承接第13课短信实验，区分失败的可能原因，选定完整系统，再进行首次最终留出评价。

## 学习顺序

1. 阅读[知识讲解](LEARN.md)：表示碰撞、区分实验、成对比较、系统定案与最终评价。
2. 完成[概念与计算练习](EXERCISES.md)。
3. 按[运行帮助](SUPPORT.md)保存开发实验，再将选定系统交教师评价。

## 课堂任务

从dev失败中选择问题，提出两个竞争解释及各自预期。设计一次控制其他条件的实验，保存原、新方案证据；依据dev选择完整系统并说明理由，之后进行最终评价。

你决定研究问题及表示、训练或复核规则的合理选择，至少包含两项影响结论的自主选择。AI可辅助计算与写作，无需提交对话日志。

## 数据与运行

train3877条用于训练，dev807条用于开发，保持原文、ID及划分一致。可继续使用第13课结果；若需一个新起点，在仓库根目录运行 `python3 lesson-14/analysis.py`。本课默认配置为TF–IDF，输出到 `lesson-14/artifacts/baseline/`；其他表示按自己的实验计划选择。

## 成果与提交

在[报告](report.md)中整理问题、预期、计算、比较与建议；用 `contract.json` 记录计划，`submission.json` 登记自己的重建命令和产物。完成后运行 `python3 scripts/course_l1314.py check 14` 与 `python3 scripts/course_l1314.py ci 14`，标签沿用 `v2-l14-final`，评分要求不变。

最终评价由教师执行，日常重建不调用最终留出。课堂选择题按教师开放的场次完成。
