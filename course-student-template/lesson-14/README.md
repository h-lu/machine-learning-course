# 第14课（S12）｜两种解释、区分实验与首次最终评价

## 本课的问题
继续已有短信作品。一个错误可能有不止一种解释，怎样设计实验区分，并让最终评价保持独立？

## 学习入口
[LEARN](LEARN.md)先用小例解释关系；[SUPPORT](SUPPORT.md)回答运行和文件问题；[EXERCISES](EXERCISES.md)帮助检查理解。已有方案可直接开始，不强制统一路线。

## 课堂任务
从已有dev失败中选择具体问题，提出两个竞争解释和可区分的预期；设计一次控制其他条件的实验，保存原/新方案证据。依据dev选择完整系统并说明理由，之后才交教师第一次最终评价。可以结论不明确，不能在最终结果出来后悄悄改阈值再报同一次评价。

你自主决定研究的失败或目标，以及表示/实验/复核门槛与名额的合理选择；至少两项会影响结论。默认程序只跑一个条件，不自动选择赢家或生成完整报告。AI可帮助计算和写作，无需交对话日志。

## 数据与资源
train3877条用于训练，dev807条用于开发。英文原文、ID、近重复组与划分保持不变；最终留出只在第14课定案后由教师评价。普通CPU即可，依赖和模型由教师课前准备。

## 起点与成功信号
在学生仓库根目录运行 `python3 lesson-14/analysis.py`，默认结果在`lesson-14/artifacts/baseline/`。先看summary的分母和错误数，再看prediction_trace的具体记录。另存配置和新目录开展自己的比较，不能把默认结果当完成任务。

## 基础与提高
基础小例解释必要计算，不代替标准任务。提高任务关注新输入边界、失败解释或评价稳定性，不靠增加模型数量凑工作量。可以有依据地保留、修改或暂缓使用。
