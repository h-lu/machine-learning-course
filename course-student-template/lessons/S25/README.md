# S25｜先试一试，还是继续选最好的一项

## 本课要解决什么问题

为一个可以反复选择的场景比较探索策略，例如轮流展示学习资源或尝试不同服务方案。你要决定为了了解未知选项，可以接受多少眼前损失。提交多次仿真、回报变化检查和采用理由。探索代价过高或环境与设定不同，就限制试验、恢复固定方案或停止自动选择。

起步程序在人工设定的成功概率下运行多臂老虎机仿真，比较随机探索、无随机探索的贪心选择与置信上界选择，并在概率改变后重新检查。程序知道所有设定概率，是为了计算仿真参照；策略只能根据自己观察到的回报学习。

数据字段和生成方式见 [数据说明](data/DATA.md)。你可以改问题、数据、方法和评价；必须说明至少一个选择怎样影响结果。示例的结论不是你的任务答案。

## 本课要学会什么

- **多臂老虎机（multi-armed bandit）**：反复选一个动作并看到它的回报，不直接看到没选动作的结果。
- **探索与利用（exploration / exploitation）**：前者尝试不确定的选项，后者利用目前估计最好的选项。
- **随机探索策略（epsilon-greedy）**：以一定概率随机尝试，其余时间选择当前估计最好的动作。
- **累计回报与遗憾（cumulative reward / regret）**：前者汇总所得，后者比较已选动作与指定理想参照之间的损失；参照必须写清。

读 [学习卡](LEARN.md)，先用里面的小例子理解计算，再决定本课实验怎样用这些概念。

## 90 分钟安排

| 时间 | 你要做什么 |
|---|---|
| 0–12 分钟 | 确定使用者和问题，写下预计会看到的结果 |
| 12–25 分钟 | 学习本课概念，核对学习卡的一处计算 |
| 25–52 分钟 | 用 AI 协助运行起点并实现自己的比较 |
| 52–65 分钟 | 核对主要数字，运行自己设计的失败或条件变化检查 |
| 65–75 分钟 | 在新输出目录重跑，写出结论并整理提交 |
| 75–90 分钟 | 先做概念检查，再用 AI 学习，最后判断一个不同情境 |

新环境在课前准备；课堂内留时间复跑。遇到技术故障，先保留错误信息，按 [故障处理](../../docs/TROUBLESHOOTING.md) 修复，并说明还有哪一步没有完成。

## 完成步骤

下面命令从学生仓库根目录运行。没有安装环境时，先按 [环境准备](../../docs/GETTING_STARTED.md) 完成准备。

1. **把问题写具体。** 选择一个低成本且允许试验的情境，定义一次动作、一次回报与试验期。决定你关心总成功数、学习速度还是某些动作的尝试上限；说明现实中回报是否立即出现、是否只看得到被选项。 在 `contract.json` 中填写任务说明（task specification）：问题、使用者、数据来源、主指标、评测划分与预计结果。先写下预计会看到的结果，再开始比较。
2. **读数据并运行起点。** 先读本课 `data/DATA.md` 和 `config.json`，确认每条记录及参数的含义；运行后打开生成的 `summary.json`，区分示例结果与自己的结论。

   ```bash
   python3 lessons/S25/analysis.py
   cp lessons/S25/config.json lessons/S25/config-trial.json
   cp lessons/S25/data/base.json lessons/S25/data/trial.json
   ```

3. **做出有理由的比较。** 使用同一组环境概率与相同试验长度，比较固定方案或无随机探索的贪心方案，与至少一种探索方案。运行多个种子，记录平均回报与差异；如果修改探索率，理由应来自试验期限和探索后果。 可以让 AI 解释、修改代码并整理图表；在配置和数据副本中完成自己的改动，保留原始文件。若新任务超出接口，直接改写 `analysis.py`，并记录新的运行命令。

   ```bash
   python3 lessons/S25/analysis.py --config lessons/S25/config-trial.json --data lessons/S25/data/trial.json --output lessons/S25/artifacts/trial
   ```

4. **核对数字和含义。** 核对每个动作实际被选了多少次、成功率分母是多少；不能把未选择动作的模拟真实概率泄漏给学习策略。遗憾必须说明与固定最佳动作还是每个时点最佳动作比较。 不只复制汇总结果，要追踪至少一个样本、计数或计算过程。
5. **加入自己的检查。** 自己改变回报机制，例如后半程原来最好的动作变差，或让某个动作早期偶然成功。实际运行，查看策略是否长期困在错误选择、能否重新发现更好的动作。 起步程序已有的条件变化帮助理解方法，但还需要你提出并实际运行一条与自己用途有关的检查；保留它支持或推翻原判断的结果。
6. **修改决定并重跑。** 记录环境假设、观察限制、不同策略的多次回报、探索次数、失败轨迹，以及继续探索、降低探索或保留固定方案的理由。 把说明写进 `update.md`，比较实际结果与原先预计。在课前准备的新环境或干净仓库副本中运行下面命令，确认程序不依赖旧输出；若尚未完成新环境验证，如实写出已验证到哪一步。

   ```bash
   python3 lessons/S25/analysis.py --config lessons/S25/config-trial.json --data lessons/S25/data/trial.json --output /tmp/ml-s25-recheck
   ```

   核对主要数字后，将最终结果留在仓库内，并更新 `submission.json` 的进度、运行命令和文件位置。它是提交清单；具体字段和正式结果保存办法见 [提交说明](../../docs/SUBMISSION.md)。

## 必须提交什么

- 程序、实际使用的数据或获取说明、参数与运行命令，让别人能重新得到主要结果。
- 写明用途与预计结果的 `contract.json`，以及包含主要指标和分母的程序输出。自己的结果不能只保留默认示例。
- 自己设计并实际运行的失败输入或条件变化、输出和解释；可引用单独文件，不要求固定图表数量。
- `update.md` 中的比较、与预计不同之处，以及采用、限制试用或停止使用的理由；`submission.json` 指向最终文件。

有依据地不采用模型可以完成本课。仍需提交已运行的比较、失败证据和可行的下一步，不能用“效果不好”替代分析。

## 不同起点怎么做

### 必做任务（Core）：完成所有人都要作出的关键判断

定义实际回报与探索后果；比较固定或无随机探索的路线与探索路线；运行多个种子并查看动作次数；实际检查回报变化或早期误导；写明仿真不能证明真实因果收益；从新目录重跑。

### 入门支持（Support）：用较小的起点完成同样的判断

先用两个动作和短试验，逐步看一次成功怎样更新均值。AI 可以运行多种子，你要核对策略是否使用了不该知道的信息。

### 提高任务（Upgrade）：增加一种能改变判断的比较

增加置信上界或汤普森采样策略，或研究有限期限、延迟回报和滑动窗口，说明新增假设。

### 换数据重测（Transfer）：换一份数据或场景再跑一次

换一组回报概率或试验长度再跑一次，例如从长期服务换成只能试十次的活动。

### 自选拓展（Open extension）：课后探索自己提出的新问题

可以沿本课问题尝试更大数据、其他模型或已有服务。先写它比必做实验多回答什么，再报告实际资源与新增证据；未运行的能力写成待验证假设。

## 运行限制

必做为表格仿真，建议不超过 10 个动作、每次 1,000 步、30 次重复；没有真实用户投放。 默认普通 CPU、约 8 GB 可用内存即可，课堂实验离线运行，不依赖付费 API、云 GPU 或临时下载大模型。单次目标不超过 3 分钟，从头重新运行目标不超过 5 分钟。超过预算时先缩小数据或重复次数，保留本课必须完成的比较与判断，并记录缩减影响。

所有起步数据都是教学合成数据或人工微型样例，不能当作真实机构、真实群体或实际线上效果。参数和输出接口见 [运行办法](../../docs/RUNTIME.md)。
