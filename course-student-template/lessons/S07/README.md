# S07 · 直线能支持哪一种预测

## 本课要解决什么问题

运营人员想用少量输入估计连续结果。有时一条直线已经方便且足够；有时平均关系掩盖了弯曲、分组差异或训练范围之外的不确定性。你要判断线性模型能够支持你选定的哪一种预测。

请提交线性与简单规则的比较、残差检查和使用条件。直线在某些记录上失败时，可以限定在已有数据区间内使用，或继续保留简单规则；需要说明失败证据。

### 由你选择的用途与方案

可以服务常规条件下的一般估计，也可以服务新增条件下的计划；可自拟不同用途。由你选择输入、正则化程度、评价指标以及允许预测的范围。不能因为方程能算出任何输入，就宣称每个数都可信。

本课随附数据是教学合成数据。先读[字段和生成说明](data/DATA.md)，再查看[原始记录](data/base.json)；示例中的使用者帮助比较用途，不代表真实机构的业务。你可以全程让AI编写代码、计算和起草文字；不需提交完整对话。提交前要核对数字及其支持的建议。

## 本课要学会什么

- **最小二乘（ordinary least squares）**：通过减小平方误差拟合直线，对大偏离较敏感。
- **斜率（slope）**：描述输入变化与预测变化的关系，不自动表示改变输入的因果效果。
- **残差诊断（residual diagnostics）**：查看误差随输入、组别和预测值是否有规律。
- **外推（extrapolation）**：预测超出训练资料范围的条件，需要额外依据。
- **正则化（regularization）**：限制系数变化，比较预测稳定性与拟合损失的取舍。

[学习材料](LEARN.md)用一个小例子解释这些概念。它们应帮助你选择和检查方案，不能只出现在报告的术语表里。

## 90 分钟安排

0—12分钟明确预测范围；12—27分钟解释直线与外推；27—52分钟拟合和规则比较；52—66分钟残差与范围外测试；66—75分钟建议与重跑；75—90分钟概念题与变式。

遇到实现困难，可以让AI提供更完整的代码，也可以复用现有程序。优先减少重复操作与排版时间，保留比较与判断。

## 完成步骤

1. 阅读x1、x2、target的说明；在 update.md 写你预计一条直线会在哪些位置偏差较大。
2. 运行默认实验，改变 config.json 的 ridge 或 extrapolation_distance，比较系数和外推结果；一次只改变一项有目的的设置。
3. 保留一个普通范围内输入和一个范围外输入，记录两者的依据差别。

### 运行与修改

从学生仓库根目录运行：

```bash
python3 lessons/S07/analysis.py
```

默认结果保存为 `lessons/S07/artifacts/summary.json`。打开[配置文件](config.json)与[程序](analysis.py)，结合数据说明修改：`ridge` 控制系数限制，`extrapolation_distance` 控制范围外测试离已有数据多远。 默认设置仅用于开始实验，不是评分答案。需要其他模型、指标或输出时，可以替换程序，写清依赖和运行命令。

在新的输出目录再运行一次，便于比较两次结果：

```bash
python3 lessons/S07/analysis.py --output artifacts/S07-demo
```

`--output` 后面是目录。报告中引用实际生成的数值，写清两次运行各用了什么设置。设计的错误输入可保存在本课目录，写明如何通过程序检查；保留原始数据副本；另存你设计的输入，说明改了哪里和为什么。

### 必做任务（Core）：把本课问题回答完整

1. 选定使用者和预测范围，说明输入时刻与误差后果，先写主指标及预期。
2. 比较简单规则与线性模型，解释系数的单位，并在同一评价资料上算误差。
3. 检查残差是否随输入或分组变化，找出一条直线不够解释的记录或结构。
4. 对训练范围之外的输入作测试，明确哪些结论有数据支持、哪些只是延伸假设，再修改建议。

完成比较后，按[仓库首页](../../README.md)的环境说明在干净环境从原始数据重新运行，核对主要数值，保存实际输出。程序不能运行时记录命令、报错和已核对部分，修复后补跑；不要把估计的数字写成运行结果。

## 必须提交什么

线性与规则预测的可重算比较；系数含义；一项残差结构检查；范围外输入的结果与限制；给使用者的建议。合格标准是不会把好看的拟合图当作所有条件下的保证。

- [任务说明](contract.json)：用已有字段写清问题、使用者、数据、指标、划分办法和最初预计；数据不需要划分时说明原因。
- [预计与结论](update.md)：先保留预计，再写实际选择、关键结果、错误案例、修改或保留的建议。可以按自己的问题组织，引用程序产生的文件。
- 程序、配置、支持结论的结果文件，以及[提交说明](submission.json)。若更换运行入口或结果路径，同步修改提交说明；完成后把 `status` 改成 `complete`。

自动检查可以帮助发现文件、字段或路径问题。方案是否合适仍要看本课的比较与解释，检查通过不替代这些判断。

## 不同起点怎么做

### 入门支持（Support）：借助现成工具完成同一个问题

使用已有一元或二元线性拟合，重点在残差、系数单位和外推判断。

### 必做任务（Core）：完成上面的比较、检查和建议

所有人都要完成“完成步骤”中的四项判断，并交出“必须提交什么”中的具体成果。选择简单办法或有依据地暂不使用，都可以完成主任务。

### 提高任务（Upgrade）：对重要选择多做一次有用的检查

比较正则化或非线性候选，解释改善来自哪些记录。

### 换数据重测（Transfer）：换一份数据或场景再跑一次

换到输入范围不同的新批次，检查原使用条件。

### 自选拓展（Open extension）：提出本课问题之外的新探索

设计包含预测不确定性的展示，但说明区间方法及假设。

## 运行限制

随课示例包含 180 条记录，数据文件约 39.6 KB。自带数据时先取能说明问题的小样本，建议不超过 100 MB，再按下面的时间目标控制实验规模。

必做部分使用本地数据、普通CPU和约8 GB可用内存，不需要GPU、网络下载或付费API。保留小数据和小模型；单次运行目标不超过3分钟，从原始数据重新运行目标不超过5分钟。新增依赖写入环境说明，课前准备好离线安装材料。更多数据、更大模型或联网服务可用于自选拓展，但必须有能离线完成必做判断的版本。

时间和资源要求是课程设计目标，真实耗时以你的记录为准。超出限制时先减少无关搜索、重复运行或模型规模，保留关键比较；不要省略需要解释的错误。
