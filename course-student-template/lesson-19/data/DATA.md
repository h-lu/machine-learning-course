# S17 数据说明：三条适配路线的固定候选输出

本课比较同一个课程问答用途下的三条路线：`prompt_revision` 只改任务说明，`retrieval_context` 在推理时加入本地资料，`parameter_adapter` 表示更新过少量任务参数的候选。`routes` 同时记录是否更新参数、需要多少资料或标注样例，以及 `setup_minutes`。

`setup_minutes` 的单位是分钟，数值 10、25、60 是课程情境为了练习成本选择而设定的人工假设。它不是教师或学生真实测得的开发时间，也不能推广到真实模型和平台；报告应写成“在本课假设下的准备时间”。

六个 `cases` 对三条路线各有一份匹配输出。它们是教师准备的**固定运行材料**，不是本课现场调用真实模型得到的结果。程序只允许比较材料中存在的路线；新增问题或改写提示后，如果没有三条路线各自的新输出，就必须报告“没有结果”，不能继续套用旧文字。

`expected_answer` 和 `required_source` 用于相同规则下的核对。空答案表示现有资料不能回答。这个小表能支持路线选择练习，不能证明参数适配在真实模型上的效果，也不能把“训练样例”当成可核对的事实来源。
