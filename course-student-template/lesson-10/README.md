# 第10课（S08）：短信概率怎样变成复核行动

## 本课要解决什么问题

一批公共英语短信需要人工复核。模型估计每条属于垃圾短信的概率；你还要决定达到多大概率才送去复核，以及最多能查多少条。正常短信的标签是ham，垃圾短信是spam；标签是原数据的分类，复核是我们选择的动作。

## 本课要学会什么

- 区分模型给的概率与原数据标签。
- 把文字变成几个数字，再追到得分和概率。
- 数清选对、误选、漏选、正确放过各有几条。
- 说明概率门槛和人数容量怎样改变复核结果。
- 用训练部分学参数，用开发部分选方案，保留最终评价部分。

## 课堂任务

先说明谁复核、误选正常短信和漏选垃圾短信各有什么后果。在同一批短信上保持概率不变，只比较两种概率门槛（阈值），或只比较两种容量。追踪一条原文怎样得到概率、为何入队或未入队；核算两方案的四类计数及复核总数。

你决定更关注哪类错误或哪组短信；再决定要比较哪两个门槛或容量，并解释理由。 AI可帮助写代码、计算和分析；要核对关键数值，不能只交默认输出。允许自拟其他路线，只要有真实可运行材料、相同的比较条件、本课的计算追踪，并且最后评价数据没有参与方案选择。

即使比较后少漏掉了一些，也要看误选增加多少、复核是否做得完。交复核不等于自动删除。

## 完成步骤

在学生仓库根目录运行；已有环境是Python 3.10+和NumPy。

先运行一个短信模型，得到概率。比较门槛时可复用这些概率，无需重新训练：

```bash
python3 lesson-10/analysis.py
```

结果在lesson-10/artifacts/baseline。再次运行请加`--output lesson-10/artifacts/新目录名`，保留旧结果。默认用人工选的六项计数，见[LEARN](LEARN.md)。records.csv的probability是概率、action=1表示交复核；summary.json给四类计数。下一步按[SUPPORT](SUPPORT.md)比较自己的两种安排。

阅读和实验顺序由你安排；[HINTS](HINTS.md)解决具体卡点，[EXERCISES](EXERCISES.md)检查能否换一个例子解释。

一份作品要包含：问题与两项重要选择、一条真实记录的计算、同记录的两方案比较、失败检查、建议和限制。填写contract.json，保存报告、代码、配置和结果；把submission.json的run改为自己的命令，artifacts列齐该命令生成的结果。只运行起点尚未完成任务，不另交额外报告或AI对话日志。

沿用v2-l10-final和revision标签，[提交流程](../docs/WORKFLOW.md)与[评分](../docs/ASSESSMENT.md)不变：完成25、代表作品25、期末50，每六课取最好五次。课末A独立判断→AI学习→B换情境，按参与计分，不按正确率扣完成分。

## 不同起点怎么做

先用完整小例看懂关系，再用可选程序或自己实现的方法完成比较。较快者可在同一作品多查一个分组或设置，但不要同时改许多条件后猜原因。有证据地保留原方案也合理。

## 运行限制

短信已固定分为train（训练）、dev（开发，供比较选择）和finalholdout（最终留出）。文字处理和模型参数只从train学；dev选方法、门槛、停止点和要检查的错误组。第14课选好方案后才第一次评价finalholdout。见[数据与英文支持](../data/sms/DATA.md)。

普通CPU、约8GB内存即可，无付费服务或GPU；安装和模型缓存由教师课前准备，课堂不下载大文件。作者运行成功不等于已经通过真人课堂试教。
