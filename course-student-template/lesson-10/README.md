# 第10课 · 短信概率怎样变成复核名单？

模型可以给每条短信一个“可能是垃圾”的概率（probability），但人手有限，不能把所有短信都复核一遍。你的任务是把概率变成一份有理由、做得完的复核名单。

从本课到第14课，我们会连续改进同一个公开英语短信项目。本课先固定模型，研究行动规则。AI可以帮助理解、编程和分析，不要求提交对话记录。

## 先学哪几件事？

[LEARN](LEARN.md)用六条人工通知解释：
- 概率、原有标签（label）和复核行动（action）有什么区别；
- 阈值（threshold）与容量（capacity）怎样改变名单；
- 查准率（precision）和召回率（recall）的分母分别是谁；
- 一段短信怎样经过数字特征、加权得分，变成概率。

可以先看小例，也可以遇到问题时回来查；术语的具体含义与计算在学习材料中逐项解释。

## 正式任务

使用同一批开发短信、同一个模型给出的概率，比较两套复核安排。

先说明更关注哪种后果：漏掉垃圾短信，还是把正常短信送去复核、占用人手。再作一个清楚的对照：

- 保持容量不变，比较两个阈值；或者
- 保持阈值不变，比较两个容量。

两个设置由你选择并解释。不要同时改变模型、阈值和容量，再把结果差异归给其中一个。

标准作品应包含：
1. 一条真实短信从原文特征到概率的计算核对。
2. 两套安排的复核总数、四类结果（选对TP、误选FP、漏选FN、正确放过TN）、查准率和召回率。
3. 名单变化的解释，以及收益、代价和你的建议。
4. 数据适用范围与一项局限。

若名单完全相同，要查明是否被容量限制住了。有依据地保留原安排，也属于合理结论。送交复核不等于自动删除短信。

## 从可运行的起点开始

请先按教师提供的第十课更新说明取得新材料。已有课程和作业会保留。

在学生仓库根目录运行：

```bash
python3 lesson-10/analysis.py
```

程序使用训练短信拟合一个固定起点模型，在开发短信上输出概率和当前复核安排。结果在lesson-10/artifacts/baseline。

第一次运行后，重点看：
- records.csv：每条开发记录的概率与是否入选；
- summary.json：当前安排的四类计数与指标；
- prediction_trace.json：一条真实预测的计算过程。

再次运行请使用新的输出目录，例如：

```bash
python3 lesson-10/analysis.py --output lesson-10/artifacts/check-02
```

旧目录不会被静默覆盖。比较阈值或容量时可以直接复用第一次的概率，不必重新训练。怎样读取输出、核对一条预测和构建自己的比较，见[SUPPORT](SUPPORT.md)。

## 不同完成程度怎样选择？

- **基础练习：**读懂六条通知的小例，能够自己数四类结果，并解释“降低门槛但名单没变”。这一步帮助起步，还不是完整正式作品。
- **标准完成：**完成上述四项证据，形成一份简短建议与可重跑比较。
- **扩展练习：**从[EXERCISES](EXERCISES.md)选一项，研究空名单、并列概率，或排序不变时概率数字怎样影响行动。扩展不是隐含必做任务。

## 数据边界

训练集（training set，train）学习参数，开发集（development set，dev）用于比较选择；最终留出集（final holdout set，finalholdout）留到第14课方案确定后才首次评价。本课程序只读取train与dev。

资料是历史英语短信，不代表当前中文短信的实际效果。可以请AI解释英文，但模型仍使用原文。不要拨打短信中的号码或打开其中的网址，不导入个人短信。来源、许可与固定划分见[数据说明](../data/sms/DATA.md)。
