# S08 数据说明

`base.json` 保存 48 条人工合成咨询记录和一个课前固定模型输出的概率。本课不重新训练产生这些概率。

## 一行数据代表什么

一行代表一条在提交后已经得到是否需要人工复核结果的咨询记录。

| 字段 | 含义 |
|---|---|
| `id` | 人工编号 |
| `split` | 训练、验证或测试用途；本课只读取验证/测试 |
| `message_length` | 消息长度，单位“词” |
| `history_count` | 此前相关记录数，单位“条” |
| `urgency_count` | 预先规定的紧急词出现次数 |
| `attachment_missing` | 应有附件是否缺失，1 是、0 否 |
| `channel` | `web`、`email` 或 `phone` |
| `needs_review` | 真实标签：1 需要人工复核，0 不需要 |
| `prepared_probability` | 课前固定模型对标签 1 的预测概率 |

验证集 12 条，测试集 12 条。概率由透明教学公式生成，不是个人风险分数。每个概率分组的实际比例以该组记录数为分母；样本很少时差异会很大。
