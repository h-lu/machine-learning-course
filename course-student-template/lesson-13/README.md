# 第13课（S11）｜预训练表示与迁移学习

第11课研究怎样把短信变成数字，第12课研究怎样训练分类器。本课借用已经训练好的文本编码器，比较它与自建表示对同一批短信的作用。

## 本课要学会什么

- 分清预训练编码器与本课分类头各自从哪里来、哪些参数保持不变。
- 沿“原文→词元→句向量→分类概率→复核行动”核对一次计算。
- 正确使用向量缓存，知道改变什么条件后需要重新编码。
- 在相同数据与评价规则下比较表示，用具体失败和探针解释差别。

## 学习顺序

1. 阅读[知识讲解](LEARN.md)，先理解模型来源、词元和句向量，再学习分类头与缓存。
2. 完成[概念与手算练习](EXERCISES.md)，需要时查看[分层提示](HINTS.md)。
3. 按[运行帮助](SUPPORT.md)训练默认方案，核对文件及一条真实短信。
4. 保存自己的两种表示配置，比较同一批dev记录，再设计两条新英文探针。
5. 整理报告、重建脚本与产物，通过提交检查。

## 课堂任务

完成一份自建表示与预训练表示的比较报告。

1. **选择对照**：在manual、bow、tfidf中选择自己的一个方案，与pretrained比较。说明目标、错误代价、训练预算和复核规则。
2. **追踪同一记录**：按ID找到同一条真实dev短信，解释两种表示怎样产生概率，以及阈值和容量怎样决定是否复核。
3. **比较整体与具体失败**：列出复核数、TP/FP/FN/TN、查准率和召回率，并查看训练曲线。不要求预训练方案一定获胜。
4. **设计两条新英文**：围绕一个具体疑问改变文本，用本地编码器处理，解释向量或概率怎样变化。无标签探针用于观察响应，不用于报告准确率。
5. **提出建议**：结合数据、计算与失败情况，说明是否采用预训练表示，以及还需什么证据。

两种表示分别训练自己的分类头，但使用同一train/dev及评价口径。相同步数表示相同预算设置，不保证两种表示都训练充分；可以据曲线讨论，但不要偷偷多训练一个方案后仍称预算相同。

## 数据与运行

train共3877条，dev共807条，沿用公开历史英语短信；最终留出资料到第14课定案后再评价。默认实验读取 `data/sms/cache/` 中的固定句向量，只训练分类头，普通CPU即可运行。

```sh
python3 lesson-13/analysis.py
```

默认输出在 `lesson-13/artifacts/baseline/`。新英文不在缓存中，要调用仓库自带的本地模型；首次使用先按[运行前准备](SUPPORT.md#运行前准备)安装编码依赖。模型权重、分词器和配置随学生仓库提供，不需要在线调用模型服务。

## 提交什么

- [报告](report.md)：比较问题与设置、一条真实计算、整体与失败分析、两条英文探针、建议。
- `contract.json`：自己的实验计划；两份配置与可重复运行的脚本。
- 两个方案的确定性产物和新英文探针结果。
- `submission.json`：登记实际重建命令、报告和产物；完成后再设为 `complete`。

```sh
python3 scripts/course_l1314.py check 13
python3 scripts/course_l1314.py ci 13
```

标签沿用 `v2-l13-final`，评分要求不变。AI可辅助编程与写作，无需提交对话日志；结果必须能由自己的文件复算。课堂选择题按教师开放场次完成。
