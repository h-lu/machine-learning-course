# 第13课（S11）｜预训练表示与迁移学习

第11、12课分别学习文本表示和分类器训练。本课使用预训练编码器提取短信特征，与自建表示比较，学习迁移学习的基本流程。

## 学习材料

- [知识讲解](LEARN.md)：按“预训练→词元与句向量→分类头→缓存与实验”的顺序阅读。
- [练习](EXERCISES.md)与[提示](HINTS.md)。
- [运行帮助](SUPPORT.md)：命令、输出文件、依赖及HF Mirror模型入口。

## 课堂任务

1. 选择自己的manual、bow或tfidf方案，与固定预训练表示比较；说明目标、错误代价和比较预算。
2. 追踪同一条真实短信从特征到概率、再到复核行动的计算。
3. 根据失败问题设计两条新英文，用编码器处理并分析变化。无标签探针用于观察模型响应。

问题、实验设置和复核规则由你选择。默认程序提供一个比较起点，AI可用于辅助计算与写作，无需提交对话日志。

## 运行与提交

默认实验读取已经保存好的短信向量（缓存），只训练分类头。新写的英文则由仓库中的模型即时编码，首次使用需安装[编码依赖](SUPPORT.md#运行前准备)。

在学生仓库根目录运行 `python3 lesson-13/analysis.py`，默认结果保存在 `lesson-13/artifacts/baseline/`。另存配置与输出目录开展自己的实验，命令见运行帮助。

本课使用3877条train和807条dev短信，采用CPU本地推理。模型随课程材料提供；最终留出数据在第14课定案后评价。

在[报告](report.md)中整理问题、计算、比较与建议；填写 `contract.json` 和 `submission.json`，附配置及可复跑产物。完成后运行 `python3 scripts/course_l1314.py check 13` 与 `python3 scripts/course_l1314.py ci 13`，提交标签沿用 `v2-l13-final`。
