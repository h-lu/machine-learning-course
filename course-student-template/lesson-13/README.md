# 第13课（S11）｜冻结预训练表示与自建表示

## 本课的问题
继续第10–12课短信研究，不另换任务。借来的英文编码器不更新，但后面的分类器仍会学习。怎样判断这种表示是否值得采用？

## 学习入口
[LEARN](LEARN.md)先用小例解释关系；[SUPPORT](SUPPORT.md)回答运行和文件问题；[EXERCISES](EXERCISES.md)帮助检查理解。已有方案可直接开始，不强制统一路线。

## 课堂任务
选择自己的manual/bow/tfidf方案与固定预训练表示作公平比较。明确使用目标和错误代价、比较设置及开发尝试预算；追踪同一条真实短信从表示到概率的计算。再自行设计两条与失败问题相关的新英文，让真实编码器处理并解释敏感性。无标签探针不算准确率，预训练未胜出也是有效结果。

你自主决定研究的失败或目标，以及表示/实验/复核门槛与名额的合理选择；至少两项会影响结论。默认程序只跑一个条件，不自动选择赢家或生成完整报告。AI可帮助计算和写作，无需交对话日志。

## 数据与资源
train3877条用于训练，dev807条用于开发。英文原文、ID、近重复组与划分保持不变；最终留出只在第14课定案后由教师评价。普通CPU即可，依赖和模型由教师课前准备。

## 起点与成功信号
在学生仓库根目录运行 `python3 lesson-13/analysis.py`，默认结果在`lesson-13/artifacts/baseline/`。先看summary的分母和错误数，再看prediction_trace的具体记录。另存配置和新目录开展自己的比较，不能把默认结果当完成任务。

## 基础与提高
基础小例解释必要计算，不代替标准任务。提高任务关注新输入边界、失败解释或评价稳定性，不靠增加模型数量凑工作量。可以有依据地保留、修改或暂缓使用。
