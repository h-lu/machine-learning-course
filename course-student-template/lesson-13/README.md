# 第13课（S11）：借用已经学好的文字转数字方法

## 本课要解决什么问题

别人已经用其他资料训练好一个把英文变成数字的模型，称为预训练编码器。本课保持它内部参数不变，只训练后面的短信分类器，再与自己的文字转数字方法比较。借来的方法不一定更好。

## 本课要学会什么

- 说明借来的模型来自哪里、原来用于什么任务。
- 区分保持编码器不变（冻结）与训练后面的分类器。
- 核对保存的向量是否对应同一原文、ID和模型版本。
- 让编码器实际处理自己新写的英文，而非重放旧结果。
- 在同样数据和试验次数下比较，说明跨任务限制。

## 课堂任务

选一个开发记录中仍会出错的情形，用自建方法与真实冻结编码器比较，保持短信划分、分类目标、复核设置和试验次数可比。选一个实际ID，追踪原文→384个数字→分类系数→概率。再实际编码至少两条自己写的英文，检查你怀疑的问题；列清哪些参数没改、哪些重新学习了。

你决定借来的模型可能帮助或失败在哪；再决定用什么新文本对或开发分组来检查。改写后的文本要另标，不能冒充原始观测。 AI可帮助写代码、计算和分析；要核对关键数值，不能只交默认输出。允许自拟其他路线，只要有真实可运行材料、相同的比较条件、本课的计算追踪，并且最后评价数据没有参与方案选择。

新写的英文没有真实业务标签时，只能检查改写怎样影响输出，不能由此报告真实准确率。缩写、过长文本和原训练任务不同都可能影响效果。

## 完成步骤

在学生仓库根目录运行；已有环境是Python 3.10+和NumPy。

默认读取已经真实计算并保存的数字，只训练短信分类器。完整新文本编码命令也在[SUPPORT](SUPPORT.md)：

```bash
python3 lesson-13/analysis.py
```

结果在lesson-13/artifacts/baseline。再次运行请加`--output lesson-13/artifacts/新目录名`，保留旧结果。先看records.csv与prediction_trace.json，再按原文ID核对data/sms/cache的记录。新文本必须另跑encode；理解两种操作的区别见[LEARN](LEARN.md)。

阅读和实验顺序由你安排；[HINTS](HINTS.md)解决具体卡点，[EXERCISES](EXERCISES.md)检查能否换一个例子解释。

## 必须提交什么

一份作品要包含：问题与两项重要选择、一条真实记录的计算、同记录的两方案比较、失败检查、建议和限制。填写contract.json，保存报告、代码、配置和结果；把submission.json的run改为自己的命令，artifacts列齐该命令生成的结果。只运行起点尚未完成任务，不另交额外报告或AI对话日志。

沿用v2-l13-final和revision标签，[提交流程](../docs/WORKFLOW.md)与[评分](../docs/ASSESSMENT.md)不变：完成25、代表作品25、期末50，每六课取最好五次。课末A独立判断→AI学习→B换情境，按参与计分，不按正确率扣完成分。

## 不同起点怎么做

先用完整小例看懂关系，再用可选程序或自己实现的方法完成比较。较快者可在同一作品多查一个分组或设置，但不要同时改许多条件后猜原因。有证据地保留原方案也合理。

## 运行限制

短信已固定分为train（训练）、dev（开发，供比较选择）和finalholdout（最终留出）。文字处理和模型参数只从train学；dev选方法、门槛、停止点和要检查的错误组。第14课选好方案后才第一次评价finalholdout。见[数据与英文支持](../data/sms/DATA.md)。

普通CPU、约8GB内存即可，无付费服务或GPU；安装和模型缓存由教师课前准备，课堂不下载大文件。作者运行成功不等于已经通过真人课堂试教。
