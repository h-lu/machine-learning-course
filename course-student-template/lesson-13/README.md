# 第 13 课（S11）：借来的表示适合当前数据吗

## 本课要解决什么问题

**先按 [入门支持](SUPPORT.md) 运行起点，确认“源数据”和“当前任务数据”不是同一批。** 本课比较两条路线：直接使用当前任务的四个缩放特征，或者使用从另一批无标签咨询记录中学习到、随后冻结的低维表示，再只训练当前任务的输出层。

这个课堂表示用主成分分析（PCA）从 60 条人工源数据学习，用来演示“先从源数据学习表示，再用于下游任务”的关系。它不是大型预训练模型，也不是对表示进行微调。你要在相同数据划分下比较两条路线，并检查一个字段信息缺失时结果怎样变化；提交数据角色说明、表示组成、比较表、压力检查和测试前选择。运行失败时保留命令与报错，先按支持页区分三批数据，修复后补跑。

## 本课要学会什么

| 标准术语 | 学完后的表现 |
|---|---|
| 表示学习 | 说明表示中的组合方向来自源数据，而不是人工直接指定 |
| 预训练与下游任务 | 区分学习表示所用的无标签源数据与训练复核标签的当前任务数据 |
| 冻结表示 | 说明下游训练只更新输出层，没有改变借来的表示 |
| 迁移学习 | 判断源数据中学到的结构是否帮助当前任务，而不是默认一定有效 |
| 分布不匹配 | 用信息缺失或场景变化检查源数据结构与当前用途是否不一致 |

先读 [LEARN.md](LEARN.md) 的“源数据—冻结表示—下游任务”过程和数值例子；陌生词再查 [术语表](../docs/TERMINOLOGY.md)。

## 90 分钟安排

0–20 分钟区分源数据、当前任务和冻结表示；20–35 分钟运行并读表示组成；35–55 分钟公平比较两条路线；55–65 分钟做信息缺失检查；65–75 分钟形成建议；75–90 分钟完成概念检查。

## 完成步骤

### 1. 运行同一划分上的两条路线

在仓库根目录运行：

```bash
python scripts/course.py start 13
python lesson-13/analysis.py --config lesson-13/config-start.json --output lesson-13/artifacts/start
```

先打开 `comparison.csv`。两条路线使用相同的 24 条目标训练记录、相同验证记录和相同输出层训练方法；区别是输入表示。比较训练与验证准确率，不要把训练准确率当作迁移效果。

### 2. 查清借来的表示从哪里来

打开 `source_components.csv`。每个分量把 `message_length`、`history_count`、`urgency_count` 和 `attachment_missing` 按不同权重组合。`source_variance` 只表示该方向在无标签源数据中变化较多，不代表它对当前标签最重要。

手算一个分量中的单项贡献：选一条记录，把某个字段减去源数据均值、除以源数据标准差，再乘以表中的权重。其余项由程序完成即可。报告明确写出：表示在源数据上学习后被冻结，下游只训练输出层。

### 3. 检查源数据与当前用途是否匹配

打开 `stress_check.csv`。程序把验证记录的一个字段统一替换成目标训练集均值，相当于该信息不可用，再保持已训练模型不变进行预测。这不是重新训练，也不是现实因果实验。比较两种表示的准确率变化，并说明哪条路线更依赖该字段。

### 4. 做一次有理由的选择

复制 `config-start.json` 为 `config-mine.json`，只改 `borrowed_dimensions` 为 1、2 或 3，或者只改 `stress_feature`。先预计，再运行：

```bash
python -m json.tool lesson-13/config-mine.json
python lesson-13/analysis.py --config lesson-13/config-mine.json --output lesson-13/artifacts/mine
```

维度更多不保证更适合当前标签。根据验证结果、信息缺失检查和计算成本选择原始或借来表示。写回 `config.json`，记录选择后再改为测试集运行 `python scripts/course.py run 13`。

### 5. 完成提交检查

填写任务说明和报告，标记完成并运行 `python scripts/course.py check 13`。保存源表示组成和压力检查；不能只交一个准确率。

## 必须提交什么

提交程序、配置、任务说明、报告，以及 `summary.json`、`comparison.csv`、`source_components.csv`、`stress_check.csv`、`records.csv`。报告说明源数据与目标数据、表示是否冻结、一次手算、同划分比较、信息缺失影响、测试前选择和结论边界。

## 不同起点怎么做

### 入门支持（Support）：先辨认三批信息的用途

[SUPPORT.md](SUPPORT.md) 逐步说明源数据、目标训练数据和验证数据分别做什么，并提供现成配置。

### 必做任务（Core）：公平比较原始与借来表示

相同划分和输出层下比较两条路线，检查至少一个场景变化，不把冻结表示称为微调。

### 提高任务（Upgrade）：比较表示维度

比较 1、2、3 维借来表示，记录验证表现与源方差；解释两者为什么不是同一件事。

### 换数据重测（Transfer）：构造明显不匹配的源数据

改变源数据中一个字段的变化方式，重新学习表示并检查当前任务。明确这是人工机制实验。

### 自选拓展（Open extension）：允许表示参与更新

实现一种会更新表示的下游训练，并与冻结路线比较；此项需要清楚标为微调，属于选做。

## 运行限制

Python 3.10 以上与 NumPy；60 条无标签源记录、48 条目标记录，普通 CPU 单次不足 1 秒。课堂 PCA 表示只演示迁移关系，不能代替真实预训练模型实验。
