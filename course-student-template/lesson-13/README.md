# 第13课（S11）｜为什么复用预训练表示，怎样接上自己的分类器

## 本课的问题
第11课我们自己规定短信怎样变成数字，第12课用这些数字训练分类器。本课追问：能否复用别人已从文本中学好的转换方法，补充人工特征或词袋可能遗漏的信息？

这种已有的转换模型叫预训练编码器。本课先解释它从哪里来、输出什么，再保持它的参数不变，用自己的短信标签训练后面的分类器。它不一定优于旧方法，是否采用要用同任务的证据判断。

## 学习入口
[LEARN](LEARN.md)从第11、12课的已有知识讲起：表示的局限→预训练的来源→文本向量→冻结与训练的区别→真实比较。没学过神经网络也可以从这里开始；[SUPPORT](SUPPORT.md)回答运行和文件问题；[EXERCISES](EXERCISES.md)帮助检查理解。已有方案可直接开始，不强制统一路线。

## 课堂任务
选择自己的manual/bow/tfidf方案与固定预训练表示作公平比较。明确使用目标和错误代价、比较设置及开发尝试预算；追踪同一条真实短信从表示到概率的计算。再自行设计两条与失败问题相关的新英文，让真实编码器处理并解释敏感性。无标签探针不算准确率，预训练未胜出也是有效结果。

你自主决定研究的失败或目标，以及表示/实验/复核门槛与名额的合理选择；至少两项会影响结论。默认程序只跑一个条件，不自动选择赢家或生成完整报告。AI可帮助计算和写作，无需交对话日志。
