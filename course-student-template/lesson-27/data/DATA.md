# 第 27 课数据说明：离线反馈轮次

本课继续使用 `equipment-helpdesk-v1` 服务台作品。数据由课程编写者制作，不是真实使用者记录。

- `feedback_rounds`：一行代表一次请求到达；共有 16 行，每个策略、每个随机种子都经历这 16 轮。
- `id`：请求编号，例如 F01。
- `request_type`：借用期限、库存、费用、账户或规则例外等人工类别。
- `brief_feedback`、`guided_feedback`：模拟器为两种回答准备的 0/1 后果。策略作选择时只能得到被选列；另一列是反事实结果，也就是“如果当时选择另一回答可能得到什么”，不能进入该轮学习。
- `project_id`：六课保持一致，用来确认仍在追踪同一作品。

程序输出的 `rounds.csv` 不公开未选方案的数值，而写“未观察”。多随机种子只是重复模拟不同选择顺序，不是真实用户数量。修改反馈时另存 `mine.json`，说明改了哪一类及其理由。

`episodes.csv` 的 `action_counts` 是 JSON 对象，例如 `{"brief": 12, "guided": 4}` 表示该策略和该随机种子下，16 轮中简短回答被选 12 次、带步骤回答被选 4 次。两个数相加应为 16。
