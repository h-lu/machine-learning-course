# 课程数据

01–08课的标准任务使用[UCI Bike Sharing离线数据](bike/LICENSE_AND_SOURCE.md)：`data/bike/hour.csv`，共17,379条真实小时记录。各课的 `data/base.json` 是用于解释概念的人工小例子；小例子上的结果不能代替真实数据实验，人工或合成数据也不能当作真实观察。

一行表示一个已记录小时的租借情况。说明使用结果时已知哪些信息、目标是什么及其单位。`casual` 和 `registered` 相加等于目标 `cnt`，不能把它们作为预测 `cnt` 的输入，否则会发生目标泄漏。缺少的165个小时记录不能补成零租借。仓库保留原始文件、来源和许可；自选数据时，说明来源、使用许可、处理方式和独立评价安排。
