# 第一次运行与目录

先按[离线环境](../ENVIRONMENT.md)核对完整学生目录、Python启动命令和NumPy。每课从README了解任务与证据标准，自主安排工作。遇阻时按卡点读SUPPORT，那里给读取支持与命令示例，不要求统一执行全部步骤。

contract.json保存任务说明：question写要估计或检查的问题，user写使用者，data_source写真实来源及任何人工热身，metric写指标/单位/分母，split_plan写训练验证测试职责，initial_expectation写看结果前的预计。保留lesson字段。

submission.json保留lesson、report、artifacts、run接口。真实完成后才将status改为complete；仅运行成功或复制例题不算完成。检查只核文件和复现，不替你判断结论。
