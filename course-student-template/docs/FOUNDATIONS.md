# 前八课怎样衔接与提交

01数据字典→02模型比较→03用途说明→04覆盖审计→05划分方案→06评价与行动→07补样计划→08诊断实验。前1–7已上，新版可补学，不追改已完成要求。使用真实数据时，旧人工数据的分数不能直接作同样本改进比较。

各课给核心关系与证据标准；你可以沿给定问题探索，也可以说明理由后自拟等价路线。至少两个重要决策由你自己确定；看结果前保存预计，在同条件下比较，追踪具体编号/分母，保存独立选择与失败诊断。SUPPORT是完成必做任务的一条路径，不因使用提示降低评分；完成后不重复另一份必做。EXERCISES标准练习逐渐撤提示，HINTS按卡点查，课后挑战不用于凑课堂时间。

完成时保存代码、最终配置、contract.json、report.md、submission.json与全部引用证据。清单只列可由run命令重建的主结果；其他试验也保存配置/结果并在报告列独立重算命令。检查：

```bash
python3 scripts/course.py check 08
```

将08换成本课号。status=complete必须在你完成后设置；检查通过不代表分析正确，也不代表已上传。artifacts通常被Git忽略，按[提交流程](WORKFLOW.md)显式加入；保留既有v2-lNN-final标签与修订标签，不覆盖旧标签。第8验证选择后才评价测试；如果用测试结果修改，它成为开发证据，需要新测试。
