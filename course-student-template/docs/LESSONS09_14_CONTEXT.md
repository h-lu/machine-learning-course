# 第9—14课如何接起来

这张地图帮助查先修，不增加作业，也不要求统一学习顺序。

|课次|与前课的联系|本课主要改变什么|保持清楚的条件|
|---|---|---|---|
|9|接第8课共享单车误差诊断|同信息下比较线性模型与浅树|原train/validation，旧测试不重新当未见|
|10|沿用数值输入、预测与评价思路，转二分类|固定概率，比较阈值或容量|改用SMS，不沿用Bike参数和数据|
|11|沿用SMS任务和评价规则|manual/bow/tfidf表示|各自训练分类器，共同划分和预算|
|12|打开前课已调用的分类器训练过程|固定表示，比较更新幅度或停止点|同数据、初值、其他训练条件|
|13|接分类头训练，先介绍预训练背景|冻结外部编码器，比较表示来源|θ固定，w/b仍用train标签学|
|14|复用第8课对照方法，利用近几课实验|区分解释、定案完整系统、首次最终评价|最终资料不用于调参或选阈值|

validation与dev在这里都承担比较/选择职责，但Bike和SMS不是同一批记录。训练损失、验证指标和实际行动效果也不相同。整个预测系统包含表示、训练所得参数和复核规则，不只是一个模型名称。
