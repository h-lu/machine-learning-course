# 运行与结果

环境与目录见[环境说明](../ENVIRONMENT.md)。第01–07课的默认入口是本课 `analysis.py`；第08课默认使用本课 `analysis.py`，可选计算工具在 `scripts/lesson08.py`，参数见本课 `SUPPORT.md`。你也可以另写程序，并更新提交清单的 `run` 字段。当前主实验使用真实 Bike 数据；旧人工计算例子的代码仍保留，供按需讲解概念。

实验配置 JSON 记录程序的参数和选择；CSV 可以保存逐条结果，供重算指标。先看清每行代表什么：若同一记录由三个方法分别预测，这三行是三个预测，不能当作三个新样本；各方法的误差应分别按实际评价记录数计算。

前1–7课只用训练和验证数据。第04课可以检查全文件的日期和记录编号等元数据，但不统计最后测试部分的目标值。第08课在看验证结果前保存事前实验计划，在看测试结果前保存选定方案。

显式指定 `--output` 时，只能使用学生仓库内尚不存在的新目录。正式主结果由 `submission.json` 的 `run` 命令重建。自动复现检查会逐文件核对清单中的结果内容是否相同，具体见[提交流程](WORKFLOW.md)。报告引用的其他试验也要保存配置、结果和重算命令；默认检查只复现清单列出的主结果。

真实来源与许可见[data/bike](../data/bike/LICENSE_AND_SOURCE.md)。人工小表只用于追踪计算；租赁记录不等于未满足需求或因果行动效果。09–32当前不提供新运行课包，自动扫描以active_lessons.json为准。
