# 运行与结果

环境与目录见[ENVIRONMENT](../ENVIRONMENT.md)。01–07统一使用本课analysis.py；08使用本课analysis.py或scripts/lesson08.py的明确任务入口，参数见各课SUPPORT。原共享mlcourse代码为兼容和旧热身保留，但当前课包的主实验使用真实Bike数据。

实验配置JSON记录学生选择；CSV逐条证据可独立重算指标。不同课产物各有含义，不把所有CSV行当新样本；多个方法/种子对同一记录的输出须分别取分母。前1–7只用开发区间，04全文件日期审计只核元数据，不打开测试目标统计。08验证前需预登记，测试前需保存已选方案的决策。

显式--output只创建新目录。正式主结果可按submission.run重建；CI保留原逐文件哈希复现规则。报告引用的其他试验配置和结果也随提交保存，并列单独重算命令；默认CI的范围是清单列出的主结果，不能冒称已核所有独立试验。

真实来源与许可见[data/bike](../data/bike/LICENSE_AND_SOURCE.md)。人工小表只用于追踪计算；租赁记录不等于未满足需求或因果行动效果。09–32当前不提供新运行课包，自动扫描以active_lessons.json为准。
