# 遇到失败时怎样继续

## 找不到文件

确认终端位于学生仓库根目录，再执行 `python3 lesson-01/analysis.py`。如果使用自己的数据，检查文件名、路径和格式；不要为了消除报错直接删掉读不到的样本。

## 提示没有 NumPy

回到课前准备好的 Python 环境。运行 `python3 -c "import sys; print(sys.executable)"` 查看实际解释器路径，并与教师提供的环境比较。离线课堂请使用事先准备的安装包；不用临时下载大模型解决环境问题。

如果创建虚拟环境时提示缺少 `ensurepip`，这是 Python 环境组件未装齐。课前按操作系统说明补齐虚拟环境组件，或使用教师预备的环境；不必修改实验代码。教师验收记录会说明实际采用了哪种环境。

## 结果和预想不同

先缩到几条记录，打印输入、预处理结果、预测与真实值。手动核对一次分母和指标。计算正确而结论不符合预计，也是有价值的结果；解释预计建立在哪个假设上。

## 运行太慢

先恢复本课入门配置，减少行数、训练轮次或模拟次数，再记录缩小后哪些结论还能比较。更大计算可放在课后，必做任务不依赖显卡。不能只保留跑得快且看起来好的结果。

## 示例能跑，自己的方案还没跑通

保留出错的输入和报错，说明已查到哪一步。可以用入门程序先完成同一概念的判断，再逐项替换。没有运行成功的方案应写成待验证设想，不能填写想象出来的指标。
