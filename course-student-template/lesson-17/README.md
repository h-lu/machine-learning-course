# 第 17 课 · 图像换个样子，还能认出来吗

## 本课要解决什么问题

选择一种你想识别的图像，以及识别错了以后谁要处理。本课比较直接使用像素和先提取局部图案两条路线，判断图像的位置、方向变化会不会改变选择。提交能重跑的比较、出错图像及处理建议。识别失败时，先判断变换后标签是否仍成立，再决定补数据、限制拍摄条件或停止自动识别。

起步数据是教学合成的小图像。程序把固定方向卷积核和池化得到的特征交给可训练分类头，并与直接读取像素的多层感知机比较。卷积核本身没有通过训练学习；这能检查局部结构假设，不能代表完整卷积神经网络的效果。

数据字段和生成方式见 [数据说明](data/DATA.md)。你可以改问题、数据、方法和评价；必须说明至少一个选择怎样影响结果。示例的结论不是你的任务答案。

## 本课要学会什么

- **卷积（convolution）**：同一个小窗口在不同位置计算，用来寻找重复出现的边缘或纹理。
- **权重共享（weight sharing）**：不同位置复用同一组参数，减少参数数量；它并不保证所有变换下结果相同。
- **池化（pooling）**：合并邻近位置的信息，可能增强位置容忍度，也可能丢掉重要的细节。
- **数据增强（data augmentation）**：改变训练图像但保留标签；先判断这个改变在任务里是否合理。

读 [学习卡](LEARN.md)，先用里面的小例子理解计算，再决定本课实验怎样用这些概念。

## 90 分钟安排

| 时间 | 你要做什么 |
|---|---|
| 0–12 分钟 | 确定使用者和问题，写下预计会看到的结果 |
| 12–25 分钟 | 学习本课概念，核对学习卡的一处计算 |
| 25–52 分钟 | 用 AI 协助运行起点并实现自己的比较 |
| 52–65 分钟 | 核对主要数字，运行自己设计的失败或条件变化检查 |
| 65–75 分钟 | 在新输出目录重跑，写出结论并整理提交 |
| 75–90 分钟 | 先做概念检查，再用 AI 学习，最后判断一个不同情境 |

新环境在课前准备；课堂内留时间复跑。遇到技术故障，先保留错误信息，按 [故障处理](../docs/TROUBLESHOOTING.md) 修复，并说明还有哪一步没有完成。

## 完成步骤

下面命令从学生仓库根目录运行。没有安装环境时，先按 [环境准备](../docs/GETTING_STARTED.md) 完成准备。

1. **把问题写具体。** 选择使用者和误判后果：例如分拣简单图案、辨认方向标记，或你自己的非敏感图片。决定位置、亮度、旋转中哪些变化应保留标签。选准确率之外最影响使用的一项检查，如某方向的漏识别比例或人工复核数量。 在 `contract.json` 中填写任务说明（task specification）：问题、使用者、数据来源、主指标、评测划分与预计结果。先写下预计会看到的结果，再开始比较。
2. **读数据并运行起点。** 先读本课 `data/DATA.md` 和 `config.json`，确认每条记录及参数的含义；运行后打开生成的 `summary.json`，区分示例结果与自己的结论。

   ```bash
   python3 lesson-17/analysis.py
   cp lesson-17/config.json lesson-17/config-trial.json
   cp lesson-17/data/base.json lesson-17/data/trial.json
   ```

3. **做出有理由的比较。** 保持训练和评测图像相同，比较像素模型与卷积特征分类头；分别记录原图和所选变换下的正确数与总数。训练数据和用于选变换强度的数据分开。若改用自己的方法，仍保留一条简单路线作为比较。 可以让 AI 解释、修改代码并整理图表；在配置和数据副本中完成自己的改动，保留原始文件。若新任务超出接口，直接改写 `analysis.py`，并记录新的运行命令。

   ```bash
   python3 lesson-17/analysis.py --config lesson-17/config-trial.json --data lesson-17/data/trial.json --output lesson-17/artifacts/trial
   ```

4. **核对数字和含义。** 从一张图开始查看像素、卷积输出和分类结果，说明一个局部响应是怎样得到的。核对变换前后的标签：方向箭头旋转后可能已经变成另一类，不能把这类错误算成模型不稳定。 不只复制汇总结果，要追踪至少一个样本、计数或计算过程。
5. **加入自己的检查。** 自己设计一张容易认错的图：图案靠边、两种图案叠在一起，或只留下与标签无关的背景。把它加入单独的数据副本，实际运行，说明错误来自局部特征、位置依赖还是标签变化。 起步程序已有的条件变化帮助理解方法，但还需要你提出并实际运行一条与自己用途有关的检查；保留它支持或推翻原判断的结果。
6. **修改决定并重跑。** 说明你允许哪些拍摄条件；列出两个方法在原图与变换图上的计数；展示并解释失败图像；根据复核负担决定采用、限制使用或保留人工处理。 把说明写进 `report.md`，比较实际结果与原先预计。在课前准备的新环境或干净仓库副本中运行下面命令，确认程序不依赖旧输出；若尚未完成新环境验证，如实写出已验证到哪一步。

   ```bash
   python3 lesson-17/analysis.py --config lesson-17/config-trial.json --data lesson-17/data/trial.json --output /tmp/ml-s15-recheck
   ```

   核对主要数字后，将最终结果留在仓库内，并更新 `submission.json` 的进度、运行命令和文件位置。它是提交清单；具体字段和正式结果保存办法见 [提交说明](../docs/SUBMISSION.md)。

## 必须提交什么

- 程序、实际使用的数据或获取说明、参数与运行命令，让别人能重新得到主要结果。
- 写明用途与预计结果的 `contract.json`，以及包含主要指标和分母的程序输出。自己的结果不能只保留默认示例。
- 自己设计并实际运行的失败输入或条件变化、输出和解释；可引用单独文件，不要求固定图表数量。
- `report.md` 中的比较、与预计不同之处，以及采用、限制试用或停止使用的理由；`submission.json` 指向最终文件。

有依据地不采用模型可以完成本课。仍需提交已运行的比较、失败证据和可行的下一步，不能用“效果不好”替代分析。

## 不同起点怎么做

### 必做任务（Core）：完成所有人都要作出的关键判断

能解释一个卷积响应；对同一批图像运行两条路线；检查一种有理由的图像变化并自造一张失败图；用计数支持采用决策；从新输出目录重新运行。无需自行训练卷积核，但必须写清哪些参数训练过。

### 入门支持（Support）：用较小的起点完成同样的判断

先用合成图像，把一个图案移到另一位置；借助 AI 画出卷积前后矩阵。你仍需判断标签是否保持，以及哪种错误可以接受。

### 提高任务（Upgrade）：增加一种能改变判断的比较

增加可训练的浅层卷积网络或第二种变换，比较改进是否来自结构、训练量还是更多数据。

### 换数据重测（Transfer）：换一份数据或场景再跑一次

换一份图像或拍摄条件再跑一次，例如把居中图案换成靠边图案；重新判断原来的增强是否合理。

### 自选拓展（Open extension）：课后探索自己提出的新问题

可以沿本课问题尝试更大数据、其他模型或已有服务。先写它比必做实验多回答什么，再报告实际资源与新增证据；未运行的能力写成待验证假设。

## 运行限制

起步实验使用微型灰度图和小型 NumPy 网络，不下载图片或模型。自带图片先缩小并保留来源说明；必做实验控制在 1,000 张、每张不超过 32×32。 默认普通 CPU、约 8 GB 可用内存即可，课堂实验离线运行，不依赖付费 API、云 GPU 或临时下载大模型。单次目标不超过 3 分钟，从头重新运行目标不超过 5 分钟。超过预算时先缩小数据或重复次数，保留本课必须完成的比较与判断，并记录缩减影响。

所有起步数据都是教学合成数据或人工微型样例，不能当作真实机构、真实群体或实际线上效果。参数和输出接口见 [运行办法](../docs/RUNTIME.md)。
