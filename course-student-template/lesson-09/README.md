# 第09课（S07）· 同样的信息，线性模型和浅树怎样拟合

## 这节课从一个熟悉的问题开始

我们继续使用共享单车数据，估计一个小时里的租借次数。

假如已经知道这个小时的时间、是否工作日，以及当时的气温、湿度和风速，怎样把这些信息变成一个预测数字？

这节课比较两种方法：

- **线性模型（linear model）**：给每项信息一个系数，把各项贡献加起来。
- **浅决策树（shallow decision tree）**：先按条件把记录分组，再用最后一组的平均租借次数作预测。“浅”表示分组的层数较少。

两种方法使用同样的信息，却可能给出不同的预测。我们要弄清：预测是怎样算出来的，在什么情况下哪一种方法更准确。

## 先学懂，再做比较

建议先读[概念与例子](LEARN.md)。里面只用四条记录，把直线的系数、树的分组条件和误差都算出来。这样再看程序输出时，你就知道数字从哪里来了。

然后用真实的共享单车数据完成本课任务。可以使用现成程序，也可以自己实现；AI可以帮助写代码、计算和解释。不会写模型训练程序，不妨碍你完成这节课。

本课使用的是“这个小时的实际天气”。因此，我们研究的是**已知这些信息时，怎样估计该小时的租借量**。若要提前一天作调度，还需要考虑天气预报是否准确等问题，本课结果不能直接代替那一步。

## 本课必做：你要完成什么？

### 1. 选一个值得重点检查的时段

例如：

- 工作日早晚高峰；
- 周末下午；
- 你在前一课发现预测不好的某类小时。

先写清为什么关心它。你也可以看完本课结果再发现问题，只需说明这是看过数据后提出的检查，而不是事先的猜想。

### 2. 让两种模型在相同条件下比较

两种模型要使用相同的输入字段（input features）、训练记录和验证记录。训练集（training set）中的记录用来确定模型；验证集（validation set）中的记录用来检查预测，并帮助我们比较方案。

程序默认使用小时、是否工作日、温度、湿度、风速五项信息，默认树深度为2。你可以决定保留哪些共同字段，或者把树的深度改为1至5之间的整数。

本课至少解释两项选择：一是重点检查什么、主要用什么指标比较；二是共同输入怎么选，或树分几层。可以保留默认设置，但要说出理由，不用为了“有修改”而随意改参数。

### 3. 看总体，也看你关心的时段

先比较全部验证记录的误差，再比较你选出的那组小时。

本课提供的指标是平均绝对误差（mean absolute error，MAE）。例如，三个小时分别少估10次、多估20次、少估30次，MAE就是：

**(10+20+30)÷3=20次/小时。**

数值越小，表示这批记录中平均偏差越小。总体较好的模型，在早晚高峰不一定也较好，所以两种结果都值得看。

也可以选择其他合适指标，但要说明它怎样计算、为什么适合你的问题，并对两种模型使用同一算法。

### 4. 挑一条真实记录，解释预测怎样产生

记下这条记录的编号和实际租借次数，然后分别核对：

- 线性模型：各项贡献加起来，是否等于它的预测？
- 决策树：依次判断哪些条件，最后落在哪一组？为什么得到这个预测？

不必画出整棵树。把这一条记录的过程讲明白即可。再看它错了多少；单条记录能说明一次预测的原因，但不能独自证明哪个模型总体更好。

## 第一次怎样运行？

在学生仓库根目录运行。课程环境需要Python 3.10或以上版本和NumPy。

```bash
python3 lesson-09/analysis.py --compare --output lesson-09/artifacts/first-comparison
```

程序会同时训练两种模型，生成三个文件：

|文件|用途|
|---|---|
|summary.json|查看两种模型的总体MAE|
|records.csv|查看每个小时的实际值、预测值和误差|
|trace.json|查看一条记录的预测计算过程|

先打开 `summary.json` 看总体结果，再打开 `records.csv` 找你关心的记录。不会读文件、筛选时段或更换设置时，看[操作帮助](SUPPORT.md)。

如果结果目录已有文件，就换一个新目录名。这是为了保留上一次结果，方便比较。只运行不带 `--compare` 的命令，得到的是均值参照，不是本课要求的两模型比较。

## 最后写出怎样的结论？

报告要回答：你更愿意保留哪种方案，证据是什么，还有什么没解决。

例如，可以写：“在全部验证小时中，模型甲的MAE更小；但在我们关心的早晚高峰中，两者差距很小。因此，现有结果支持……，还不能说明……。”

“平均误差变小”与“已经够实际使用”是两件事。若不知道调度工作最多能接受多大的误差，就先把结论限定为本次比较的改善，不急着说可以投入使用，也不要只凭一个误差数字断言毫无用处。

## 进阶拓展：选一个问题再往前走

如果已经完成必做，可以选择：
- 固定输入字段，把树深度从1改到5，比较训练和验证误差；
- 在同一份预测上增加均方根误差（root mean squared error，RMSE），看看较大的错误怎样影响评价；
- 去掉一个输入字段再比较两模型，检查这个字段在当前建模方式下是否有帮助。

详细步骤见[练习页](EXERCISES.md)。任选一个，结果写入原报告末尾即可。这里允许得到“没有改善”或“证据不足”的结论，不以跑出更好数字作为完成条件。
