# 第09课（S07）：同样的信息，线性模型和浅树怎样拟合

## 本课要解决什么问题

继续估计共享单车在一个小时里的租借次数。做估计时，已经知道这个小时的实际天气和日历信息。一个模型把各项影响相加，另一个按条件分组再取平均：用相同信息，它们会怎样出错？

## 本课要学会什么

- 说明训练怎样从有冲突的观测中选出系数。
- 把截距和各项贡献相加，核对线性模型的一次预测。
- 沿条件找到树的末端分组，核对组内训练均值。
- 用相同输入字段、训练记录和评价记录比较模型。
- 区分“平均误差变小”与“已经够实际使用”。

## 课堂任务

从前课或当前验证结果中，自选一个值得检查的情形。用相同原始字段和记录，比较线性模型与浅树；再看你关心的那组记录，而不只看总体平均。自选一条真实记录，分别算线性各项之和、沿树的条件找到预测，解释误差与限制。

你来决定重点情形和主要评价指标；再决定两方共同使用的字段，或树最多分几层。这些选择要有理由，并能影响实验或建议。 AI可帮助写代码、计算和分析；要核对关键数值，不能只交默认输出。允许自拟其他路线，只要有真实可运行材料、相同的比较条件、本课的计算追踪，并且最后评价数据没有参与方案选择。

平均少错一些，还不能说明已经够实际使用。若没有事先说明能接受多大误差、判断错了有什么代价，结论应是“比较中改善了，还需用途证据”，不能只凭MAE的大小说能用或不能用。

## 完成步骤

在学生仓库根目录运行；已有环境是Python 3.10+和NumPy。

下面只运行训练均值参照，不完成两模型任务。要开始比较，可直接用[SUPPORT的可选比较程序](SUPPORT.md)，再作自己的选择：

```bash
python3 lesson-09/analysis.py
```

结果在lesson-09/artifacts/baseline。再次运行请加`--output lesson-09/artifacts/新目录名`，保留旧结果。均值起点产生summary.json和records.csv；可选比较还产生trace.json。比较运行后先看两方法的MAE（平均绝对误差，即每条预测差多少的平均值），再用记录编号instant找自己的例子。怎么读贡献和树路径见[LEARN](LEARN.md)。

阅读和实验顺序由你安排；[HINTS](HINTS.md)解决具体卡点，[EXERCISES](EXERCISES.md)检查能否换一个例子解释。

## 必须提交什么

一份作品要包含：问题与两项重要选择、一条真实记录的计算、同记录的两方案比较、失败检查、建议和限制。填写contract.json，保存报告、代码、配置和结果；把submission.json的run改为自己的命令，artifacts列齐该命令生成的结果。只运行起点尚未完成任务，不另交额外报告或AI对话日志。

沿用v2-l09-final和revision标签，[提交流程](../docs/WORKFLOW.md)与[评分](../docs/ASSESSMENT.md)不变：完成25、代表作品25、期末50，每六课取最好五次。课末A独立判断→AI学习→B换情境，按参与计分，不按正确率扣完成分。

## 不同起点怎么做

先用完整小例看懂关系，再用可选程序或自己实现的方法完成比较。较快者可在同一作品多查一个分组或设置，但不要同时改许多条件后猜原因。有证据地保留原方案也合理。
