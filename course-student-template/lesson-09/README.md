# 第 09 课（S07）：直线能支持哪一种预测

## 本课要解决什么问题

前几课讨论了怎样准备数据和评价结果。这一课进一步检查线性回归：它在已有输入上比均值基线好，是否就能用于更远的输入？怎样从残差发现问题？

**基础还不稳时，直接打开 [入门支持：逐步做一遍](SUPPORT.md)**。用现成配置运行、手算一行、比较一个设置，再解释自己的检查即可覆盖必做任务；不用另做一套 Core，也不要求从零写训练代码。

本课是现行 S07 的线性回归实验，不是新知识地图中全部模型比较的完成声明。数据换成 180 条无量纲人工样本，x1、x2 都不是排队人数，目标值也不是分钟。先理解 [数据说明](data/DATA.md)，不要沿用前课的单位。

提交程序、配置、比较结果、残差和外推检查，以及有依据的建议。程序不能运行时记录命令与报错，先用学习卡的小例子继续计算，修复后补跑；不能把手算数值冒充程序产物。

## 本课要学会什么

| 通用术语 | 要能解释或核对什么 |
|---|---|
| 普通最小二乘法（OLS） | 用训练样本选择使残差平方和最小的系数，并解释大偏差的影响 |
| 多元线性回归与回归系数 | 本例用两个特征；一个特征系数的含义需保持另一个特征不变 |
| 残差（residual） | 阅读表采用真实值减预测值；正值为低估，负值为高估 |
| 外推（extrapolation） | 超出训练输入范围时，计算可行不代表证据充分 |
| 岭回归（Ridge）与正则化 | 对系数加入平方惩罚，观察拟合和验证表现的取舍 |

先读 [LEARN.md](LEARN.md) 的一行计算。不要求推导矩阵公式，但应能代入两个特征并解释残差。

## 90 分钟安排

第 30 分钟仍未找到结果时，请教师核对目录、环境与输出文件，先做入门指南的小计算。选做任务不挤占核心理解；现行在线场次的具体时间安排由教师说明，本次不自动改变服务配置。

## 完成步骤

### 1. 先限定用途，运行起点

在 `report.md` 写“我先评价给定人工样本区间内的预测；范围外需要额外证据”。可以换用途，但要说明相应单位与数据，不把合成样本当真实业务。

命令在能看到 `scripts`、`lesson-09` 的学生仓库根目录执行。电脑只识别 `python3` 时替换命令中的 `python`。

```bash
python scripts/course.py start 09
python lesson-09/analysis.py --config lesson-09/config-start.json --output lesson-09/artifacts/support-start
```

`config-start.json` 保留原参数：`ridge=0`、`extrapolation_distance=4`、`seed=7`。先看 `comparison.csv` 的方法名与 MAE，再看 `records.csv` 的特征、预测、真实值和残差；`extrapolation.csv` 是人为改变输入关系的对照，`summary.json` 保存完整计算。

本例 120 条 `train` 用于训练，60 条 `evaluation` 用于开发评价。反复选参数后不能称其为未见测试集；本课入口不支持 `--split`。自己的最终效果声明需要另备未参与选择的数据。

### 2. 核对预测与残差

在 `records.csv` 找 `S07-000`，同时读 x1、x2，而不是只看一个输入。按 [学习卡](LEARN.md) 的公式代入系数，核对约 2.783 的预测及约 0.175 的正残差。回到同样 60 条样本的 MAE 比较，避免用一条好预测说明整体都好。

### 3. 只改一种正则化设置

现成 `config-support.json` 只将 `ridge` 从 0 改为 10：

```bash
python lesson-09/analysis.py --config lesson-09/config-support.json --output lesson-09/artifacts/support-compare
```

比较系数、普通评估集 MAE 和逐条残差，解释取舍；较大惩罚不保证效果更好。两次数据和外推距离相同，不能同时更换数据后只归因于正则化。

### 4. 自己选择一个外推检查

从 `config-start.json` 另存 `config-mine.json`，保持 `ridge=0`，只将 `extrapolation_distance` 改为自己选择的非负值，例如 2 或 6。先写预计，再运行：

```bash
python lesson-09/analysis.py --config lesson-09/config-mine.json --output lesson-09/artifacts/my-check
```

在 `extrapolation.csv` 核对 x1 改变多少，哪些输入超过训练范围。外推标签由课程规定的非线性公式生成，不是真实观察；不同距离的 MAE 不能当作同一测试集上的性能提升。另选一条正残差、一条负残差解释模型在哪些记录上低估或高估，并按入门指南比较不同 x1 区间的记录，检查是否有值得进一步调查的规律。更多有条件的探索见下面的分层任务。

### 5. 保留证据，整理提交

把准备保留的参数写回 `config.json`，报告写清每个配置及对应结果目录。填写 `contract.json` 的任务、使用者、来源、指标、划分与预计；`split_plan` 明确“train 训练，evaluation 用于开发，没有独立最终测试”。替换报告提示，实际完成后将 `submission.json` 的 `status` 改为 `complete`。

```bash
python scripts/course.py run 09
python scripts/course.py check 09
git add lesson-09
git add -f lesson-09/artifacts
git diff --cached --name-only
```

确认报告、配置副本和全部引用结果都在暂存列表中，再按 [提交步骤](../docs/WORKFLOW.md) 创建提交及 `v2-l09-final` 标签。检查通过不等于已经上传；不要覆盖旧标签。修改过共享代码时也需保存它。

## 不同起点怎么做

### 入门支持（Support）：跟着详细步骤完成核心任务

使用 [SUPPORT.md](SUPPORT.md) 和已准备的 `config-start.json`、`config-support.json`。先核对一行，再做一项比较，最后选择一个有理由的改动并解释。可以请教师或 AI 解释操作，不要求自己从零实现算法。**入门支持不是低分任务，是否完成取决于比较和解释，而不是代码量。**

### 必做任务（Core）：所有路径共同需要完成的内容

在同一评估集比较回归与均值基线；解释两个特征的系数；检查有正负号的残差；比较一种正则化设置，并说明外推对照的假设。使用入门路径完成这些要求后，不再额外做一次“Core 作业”。

### 提高任务（Upgrade）：有余力再加深一个比较

在验证数据上比较多个岭回归强度，分析哪些记录改变最多；不以训练误差最低作为采用理由。

### 换数据重测（Transfer）：用新数据重新检查

换成不同输入区间的数据，用相同基线与残差分析核对迁移后的使用条件。更换字段或任务时一并调整程序和评价，不只改名称。

### 自选拓展（Open extension）：探索本课之外的问题

进一步学习预测区间及其假设，不能把点预测外推当成可靠保证。以上选做项不替代必做任务，也不要求全部完成。
