# S07 入门支持：看懂线性回归，再检查残差和外推

这是 [本课任务](README.md) 的详细做法，不是额外作业。完成下面的比较、自己的检查和解释，就覆盖必做任务；不用再把 README 的另一条路径重复一遍。你可以使用现成程序和教师帮助，不需要先会写训练代码。**先做第一项小任务：找到第一条评估样本，按两个特征算出预测值。**

## 1. 先知道今天在检查什么

**多元线性回归**用多个特征预测数值；本课有 x1、x2 两个人工特征。它们没有米、分钟等现实单位，称为无量纲，不是排队人数。**残差**在本课阅读表中指“真实值 − 预测值”。**外推**指把模型用到训练输入范围之外。

先读 [LEARN.md](LEARN.md) 的对应例子。术语表按需查，不要为了开始上课把整张表背完。在 `report.md` 先写一句你的用途和预计结果；其余栏目等拿到结果再填写。

## 2. 不改代码，先跑通并找到结果

在学生仓库根目录运行，那里同时有 `scripts` 和 `lesson-09`。不知道终端或根目录在哪里，按 [第一次运行指南](../docs/FIRST_RUN.md) 的目录与环境检查操作；不要在 Python 的 `>>>` 中输入命令。只能识别 `python3` 的电脑，将以下 `python` 换成 `python3`。

```bash
python scripts/course.py start 09
python lesson-09/analysis.py --config lesson-09/config-start.json --output lesson-09/artifacts/support-start
```

`config-start.json` 是随课准备的起始配置，先不要改；数据仍来自本课 `data/base.json`。终端出现“结果写入”后，在 `lesson-09/artifacts/support-start/` 找到 `comparison.csv`、`records.csv`, `extrapolation.csv` 和 `summary.json`。CSV 可以用表格软件或文本编辑器打开；文本编辑器中每行是记录，逗号隔开列。先看下面点名的列，不要求一次看懂所有指标。

## 3. 停下来核对，不只看运行成功

这次沿用 S07 已有实验，不把它当成新地图中的全部模型比较。默认有 120 条训练样本和 60 条评估样本；不必手读 180 行，只先看一行和汇总。`evaluation` 在这里用于反复练习和选参数，作用相当于开发验证集，不是未使用过的最终测试集。不要把 S01–S06 的 `--split` 参数照搬到本课。

打开 `records.csv` 找 `id=S07-000`。x1 约为 −0.61132，x2 约为 −2.45209，真实值约 2.95846。`coefficients` 的顺序是截距、x1 系数、x2 系数。默认拟合约为：

```text
预测 = 1.938706 + 1.461893 × x1 − 0.708855 × x2
```

代入这一行，得到预测约 2.783197。残差 `2.95846−2.783197≈0.175263`，正值表示低估；绝对误差也是约 0.175263。这里的值没有现实业务单位，不能写成分钟或准确率。

再看 `comparison.csv`：回归和均值基线都在同样 60 条上评价，默认 MAE 约 0.314 与 1.322。基线是训练目标值的平均，不是另一条人工斜率规则。

最后看 `extrapolation.csv`：x1 加 4 后，课程还人为增加了一个非线性项来生成对照标签。它演示“范围外关系可能变化”，不是预测了真实未来，更不能把新增标签称为观测证据。

还要检查残差是否随输入有规律。先在 `records.csv` 中找下面三条，比较 x1 较小、中间和较大处的残差：

| 编号 | x1 | 残差（真实值减预测值，约） |
|---|---:|---:|
| S07-087 | -1.49740 | -0.245 |
| S07-093 | -0.08264 | +1.072 |
| S07-141 | 2.60166 | +0.281 |

再自己选三条不同编号，说明符号是否也这样分布。三条不能证明整体规律；要判断是否呈弯曲趋势，应检查更多记录或画残差图。发现两端与中间长期出现不同方向的偏差，才有理由进一步调查线性关系是否不足；本课不要求先会画图。

以上数值是给定数据和起始配置的**自查参考**，四舍五入造成的小差异正常。它们不是必须达到的评分标准。先自己算或数，再对照；出现较大差异时检查方法名、配置路径和输出目录，不手改结果文件。

## 4. 跑一个已经准备好的对照

`config-support.json` 已经准备好，不用从空白文件写 JSON。

这个副本只把 `ridge` 从 0 改为 10，外推距离仍为 4。这是岭回归（Ridge）：在拟合目标中加入系数平方惩罚，即 L2 正则化。原评估集仍用同样 60 条比较；系数约从 `[1.939,1.462,-0.709]` 变成 `[1.926,1.353,-0.655]`，MAE 约从 0.314 变为 0.349。惩罚更强不保证验证误差更小。

```bash
python lesson-09/analysis.py --config lesson-09/config-support.json --output lesson-09/artifacts/support-compare
```

并排打开两次结果，把“改了什么、哪项结果变了、哪项不变”记在报告。两个输出目录分开，不覆盖第一份。

## 5. 做一次有理由的个人选择

从 `config-start.json` 另存 `config-mine.json`，自己选一个非负外推距离，只改 `extrapolation_distance`（如 2 或 6）。核对 `extrapolation.csv` 中 x1 的改变量、预测和人工对照标签。再在 `records.csv` 挑一条正残差、一条负残差。按 x1 从小到大看残差是否有成段同号等规律；不能仅凭两条记录判断非线性。手算误差 1 与 10 的平方，说明为何大偏差可能影响最小二乘；说清外推还缺什么真实数据。

另存文件时在编辑器中使用“另存为”，文件名是 `lesson-09/config-mine.json`。只改刚才点名的字段值，保留英文双引号、逗号和冒号，其他字段先不动。文件名不要多出 `.txt` 后缀。检查格式，再运行：

```bash
python -m json.tool lesson-09/config-mine.json
python lesson-09/analysis.py --config lesson-09/config-mine.json --output lesson-09/artifacts/my-check
```

这次填写自己的预计、实际结果和理由，不照抄例子中的采用建议。允许结果支持保留原方案，也允许暂不使用。需要 AI 帮助时，可以提问：“请只解释这条命令和这一行数据，先让我计算，再帮我核对；不要替我填最终建议。”
