# 第09课 · 换一个小例，看看自己是否理解了

下面仍是人工编制的文件传送数据。可以用计算器或AI帮助计算，保留算式和理由即可。这是练习，不是正式A/B自查题，也不需另交报告。

|文件大小（MB）|耗时（秒）|
|---|---:|
|0|2|
|2|6|

1. 写一条能准确经过这两个点的直线：预测耗时=b+w×文件大小。w和b分别是多少？
2. 如果树按“文件大小≤1MB”分成两组，每组用本组训练耗时的平均值预测，那么3MB文件会得到什么预测？
3. 同一个3MB文件，用第1题的直线会预测多少秒？
4. 目前没有3MB文件的真实耗时。仅凭这两个预测，你能判断谁更好吗？为什么？
5. 假如后来在一批新文件上发现，一种模型平均少错1秒。要判断它是否足够用于实际工作，还需要知道什么？
