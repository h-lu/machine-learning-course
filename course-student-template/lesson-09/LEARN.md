# S07：从一个特征到两个特征，再看残差和外推

C02 用人数这一个特征预测分钟数。本课继续学习线性回归，但数据换成两个没有现实单位的人工特征 x1、x2。先看一个能手算的例子，再读本课程序结果。

## 两个特征怎样得到一个预测

**多元线性回归（multiple linear regression）**用多个特征预测数值。本课形式是：

```text
预测值 = 截距 + x1 的系数 × x1 + x2 的系数 × x2
```

例如人为给一组系数 `2、1.5、−0.7`，当 x1=1、x2=2 时，预测为 `2+1.5×1−0.7×2=2.1`。这是帮助理解的手算例子，不是程序保证得到的参数。**回归系数（coefficient）**表示在其他特征不变时，该特征增加 1，预测变化多少；不能直接解释成现实干预效果。

程序通过训练数据拟合系数。`ridge=0` 时采用**普通最小二乘法（ordinary least squares，OLS）**，目标是让训练样本的残差平方和尽量小。本例 120 条训练样本拟合后，系数约为 `1.938706、1.461893、−0.708855`；并不恰好等于上面的手算参数。

## 残差保留方向，绝对误差不保留方向

本课阅读表定义**残差（residual）=真实值−预测值**。残差为正表示模型低估，为负表示高估。绝对误差取残差的绝对值；MAE 将所有绝对误差相加再除以样本数。

| 本课数据 S07-000 | 数值（无量纲） |
|---|---:|
| x1 | −0.61132 |
| x2 | −2.45209 |
| target：真实值 | 2.95846 |
| 拟合模型预测 | 约 2.783197 |
| 残差 | 约 0.175263 |

代入两个特征核对预测，再算 `2.95846−2.783197`。不要把 x1 当成排队人数，也不要写“误差 0.175 分钟”。结果中的 `residual_actual_minus_prediction` 明确了减法顺序；读其他程序的残差时也要先确认约定。

**残差分析（residual analysis）**不只看平均误差。若一部分记录持续低估，另一部分持续高估，平均残差可能抵消；这不代表预测都好。可以先选一正一负两条核对，再按特征大小或组别观察，但两条记录本身不能证明普遍规律。

## 为什么一条极端记录也可能改变直线

**极端值（extreme value）**是相对其他记录很偏离的数。它可能是真实少见情况，也可能是录入错误，不能一见到就删除。最小二乘使用平方误差：误差 1 的平方是 1，误差 10 的平方是 100，因此一个大偏差可能明显影响拟合。先核对数据来源，再比较保留或修正的影响，而不是为了提高分数随意删样本。

看残差是否随 x1、x2 或分组出现规律，是在检查模型遗漏了什么。比如两端多为正、中间多为负，可能提示直线没有描述弯曲关系；它只是需要进一步检查的线索，不是仅凭两条记录就证明了非线性。

## 为什么仍然保留均值基线

**均值基线**对所有评估样本预测训练目标值的平均。它不使用 x1、x2，但也不能用评估标签重新计算均值。

默认在同样 60 条评估样本上，线性回归 MAE 约 0.314，均值基线约 1.322。这个比较支持的是当前样本上的误差差异，不证明所有数据都适合线性回归。本课的 `evaluation` 会反复用于开发和选参数，不能当作未见过的最终测试集；不提供 S01–S06 的 `--split` 切换。

## 正则化是取舍，不是保证

**岭回归（Ridge regression）**在残差平方和之外，再惩罚系数平方和，这是 **L2 正则化（L2 regularization）**。本程序 `ridge` 对应惩罚强度，截距不受惩罚，0 表示不加这项惩罚。

把 `ridge` 改为 10 时，x1、x2 系数约变为 1.353、−0.655，评估 MAE 约为 0.349。与普通最小二乘相比，系数受到更强限制，误差却略大。正则化可能减少不稳定，也可能增加偏差；不能把“越强越好”当规则。先用现成配置观察，不要求推导矩阵公式。

## 外推为什么需要额外依据

**外推（extrapolation）**是在训练输入范围外作预测。即使代入公式很容易，也不知道新区域是否仍保持原关系。

本课将评估样本的 x1 加上 `extrapolation_distance`，并用下面的人工公式生成对照标签：

```text
对照标签 = 2 + 1.5×新x1 − 0.7×x2 + 0.5×max(新x1−2, 0)^2
```

`max(新x1−2,0)` 意思是两者取较大值，末尾 `^2` 表示平方；当新 x1 大于 2 时，关系会弯曲。这是课程刻意设定的情境，不是模型预测出的真实答案，也不是实际采集的数据。

`extrapolation.csv` 给出输入前后、预测及人工对照标签。变化中既有输入移动，也有对照关系改变，所以不能仅凭误差增加就测出了现实分布变化的影响。自己的项目没有真实范围外标签时，只能说明会输出什么，不能凭空计算真实误差。

## 什么时候使用，什么时候还不够

当线性关系在目标数据中是合理近似、残差与用途相符时，线性回归可以作为容易解释的方案。出现明显非线性、缺少范围外数据或任务要求逐个样本可靠保证时，需要更谨慎。系数不等于因果效应，训练拟合好不等于能够外推，MAE 小不等于每条都好。
