# S07 数据说明

`base.json` 是人工合成的咨询处理记录，用于比较模型复杂度。它不包含真实个人信息，也不能代表实际业务规律。

## 一行数据代表什么

一行代表一条已经处理完的咨询记录。

| 字段 | 含义与单位 | 何时可知 |
|---|---|---|
| `id` | 人工记录编号 | 始终可知 |
| `split` | `train`、`validation` 或 `test` | 课程预先固定 |
| `detail_count` | 提交时包含的细节项数，单位“项” | 开始处理前可知 |
| `handling_minutes` | 从开始到处理完成的分钟数，是回归标签 | 处理完成后才知道 |

共有 36 条：训练 20 条、验证 8 条、测试 8 条。训练中的 `detail_count` 范围是 0–10。`outside_inputs` 只有输入，没有观察到的处理时间，不能用于计算 MAE 或判断模型对错。

## 数据用途和限制

训练集拟合参数；验证集比较复杂度和设置；测试集只评价事先选中的方案。处理时间由教学公式加固定扰动生成，故意包含弯曲关系。它只适合练习假设、泛化和外推，不能推出增加细节会造成现实处理时间变化。
