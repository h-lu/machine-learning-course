# 第07课分级提示（按需）

先写自己的问题和预计；如果卡住再选择以下方向，不必逐条完成。

1. 核对象：抽样与代表性、标签质量、AI数据生产与真实证据中你到底在比较哪个量？用LEARN小例区分它与相近概念。
2. 核证据：卡在选择时，只把候选编号/日期/hr/workingday等已知信息交给选择逻辑，先写计划再用被选标签；不要把全表cnt交给AI让它替你倒选。
3. 核边界：看标签前保存计划及依据；训练池与验证/测试分离；来源是已有真实记录、独立新观察还是生成；覆盖均衡不等于代表性；不挑最好种子；稀少天气仍缺真实证据。
4. 核建议：如果两条合理路线结论不同，哪项检查最能区分原因？可以保留原方案；当前没有证据的条件写未知。
