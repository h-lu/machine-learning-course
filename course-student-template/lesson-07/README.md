# 第07课（S05）｜还缺哪些数据，哪些记录值得补

本课围绕**抽样与代表性、标签质量、AI数据生产与真实证据**改进你的作品。你可以沿用已有问题、改变它，或自拟有依据的小问题；起点代码帮助你读入数据，分析方法由你选择。先确定想研究的问题，再按需用[学习页](LEARN.md)、[支持](SUPPORT.md)与[开放代码工具](../docs/CODE_TOOLKIT.md)。本增强版不追溯增加已授课作业要求，不重算旧成绩或更改既有线上场次。

## 本课要解决什么问题

新增的是哪种信息？我按什么可见条件选择？有没有先看候选标签，再反过来挑选记录？合成是否只重复原模型？哪个条件仍未覆盖？ 课程共用的数据包含17,379条真实小时记录；也可以换用有明确来源的数据或自己的程序。请说明本课概念怎样帮助回答问题、数据能支持哪些判断，以及怎样用现有资源检验。你可以依据结果保留原方案、修改任务、将部分判断交由人工处理，或暂不采用当前方案。

## 本课要学会什么

理解抽样与代表性、标签质量、AI数据生产与真实证据；能追踪一条计算/记录，预先判断条件变化可能怎样影响结果，构建合理替代并说明证据限制。[LEARN](LEARN.md)给通俗解释、不同小表的已完成例题与误区，例题不完成你的正式研究。

## 课堂任务

完成一件补数据/复核作品：查看候选标签前的选择依据、真实来源与同预算比较、仍缺证据的条件。自定最值得补查的缺口；自己决定预算、候选策略、复核/AI标签审查或分组评价中的至少两项。 这些选择应实际影响分析过程或结论。AI可以全程协助；你需要用具体样本核算，并在不同情境中解释自己的判断。

**基本任务：**用小例解释核心关系并使自己的程序实际读取数据。

**标准任务：**用训练期真实记录构建候选池，模拟有限标注预算下先选择、后查看标签的过程。策略可自行设计，不限覆盖优先或随机抽样。比较相同初始集/预算/评价的合理替代，保留编号和所有重复结果；也可研究标签复核或AI合成对照，但须有独立真实评价。

**提高任务：**自选新预算、复核规则或AI生成方式作审查，明确成本差异；课后真实采集计划仅是计划，不宣称已经采集。 三类任务围绕同一件作品。使用支持材料不影响评价；不要求人人做完所有扩展或重复交三个作品。

## 完成步骤

**你的研究方案需覆盖这些证据，顺序由你决定：**

- 说明使用者、目标、预测/观测时点与实验前预期；保留至少两个重要决策及依据。
- 使用真实数据自行构建标准分析；以同用途下的合理替代作公平比较，记录变化与控制条件。
- 追踪具体记录/分组/计划，核算一项关键值，自己设计一次失败检查或条件变化。
- 据证据保留、修改或暂停，说明尚不能得出的结论；保存能重跑的程序与原/新结果。

检查边界：看标签前保存计划及依据；训练池与验证/测试分离；来源是已有真实记录、独立新观察还是生成；覆盖均衡不等于代表性；不挑最好种子；稀少天气仍缺真实证据。 默认起点无抽样策略、学习曲线或标签揭示答案。公开CSV含标签，课堂先选择是实验协议不是保密机制；用已有记录模拟标注预算，不等于实际采集了新数据。 支持材料按问题选用，不要求沿固定顺序完成研究。

## 必须提交什么

提交自己的分析程序、配置/任务说明、实际结果与报告；报告格式可改，但问题/用途、数据来源、至少两个重要选择、公平比较、失败检查、核算和适用限制不能省。保留原方案与比较试验，见[练习资源](EXERCISES.md)。

默认的`submission.json`只列出起点结果，**运行起点代码不等于完成项目**。完成自己的分析后，把结果文件路径写入`artifacts`，替换或补充原清单；把`run`改成实际能够重新生成这些文件的命令。

完成研究后，才把`status`改为`complete`。在学生仓库根目录运行`python3 scripts/course.py check 07`及`python3 scripts/course.py ci`。CI（自动检查）会重新运行命令，核对清单中结果文件的内容是否一致；它不判断结论是否正确。未列入清单的比较试验须另存重跑命令。

保留旧标签，增强复习是否另提交修订依教师安排。

## 不同起点怎么做

不清楚某关系时看LEARN的完整计算，不清楚代码/输出时按SUPPORT的卡点求助；先自己尝试，再看[分级提示](HINTS.md)。基础和提高都保留实质选择。可自主换题/数据/方法/表达，只需保持本课核心概念与证据；不按模型数、代码量、AI对话长度或复杂外观加分。

## 运行限制

使用已准备的Python与NumPy，命令示例为本机`python3`；你原环境若使用`python`或`py`，统一用已经成功的启动命令，不安装新环境。默认起点从学生仓库根目录的`data/bike/hour.csv`离线读取数据，只准备文件检查和样本预览，不能作为正式分析已完成证据。AI可帮助提出问题、写代码、核算和解释，不要求提交提示词记录、不要求所有人同路线或强制逐人答辩。

数据/依赖错误保留命令、工作目录和完整报错；先用不同数据的完整小例继续理解，明确写未实跑，再找教师修复。用`--output`指定的目录若已存在，程序会拒绝覆盖；请换新目录保留旧结果。不指定`--output`时，默认的`artifacts/starter`允许重新生成。正式程序和输出由你决定；`submission.json`中的`run`必须能重新生成`artifacts`列出的分析结果。未列入清单的比较试验，另存配置和重跑命令。

默认起点无抽样策略、学习曲线或标签揭示答案。公开CSV含标签，课堂先选择是实验协议不是保密机制；用已有记录模拟标注预算，不等于实际采集了新数据。 数据来源、字段/时间边界和许可见[data/DATA](data/DATA.md)。普通CPU离线，概念检查与AI接入由教师安排；不能将不可用资源藏到必做要求。
