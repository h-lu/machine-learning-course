# 第 07 课（S05）：还缺哪些数据，哪些记录值得补

## 本课要解决什么问题

**第一次做或基础还不稳：从 [入门支持：逐步做一遍](SUPPORT.md) 开始**。里面有现成配置、完整命令、一条手算、输出核对和报告提示，不要求先写代码。完成这条路径及自己的检查，就覆盖下面的必做任务；提高与拓展均为选做，不必重复做两套流程。

初始数据只有午间记录，晚间预测不理想。预算只能补少量样本，本课比较随机补充、优先补缺少时段与模拟合成数据。新增样本数相同，不代表增加的信息相同。

你将提交自己的任务说明、程序生成的比较表和逐条记录，以及解释选择的简短报告。AI 可以帮助提出方案、编程和解释，但不能用一段流畅说明代替实际比较。出错时按报错核对字段；不会操作文件时先查 [第一次运行指南](../docs/FIRST_RUN.md)，可以从原始小数据重新开始。

## 本课要学会什么

| 通用术语 | 学完后能做什么 |
|---|---|
| 抽样与代表性 | 说明训练样本缺少哪些使用条件 |
| 标注预算 | 在相同新增样本数下比较办法 |
| 随机与定向抽样 | 只用可用信息选择候选编号 |
| 合成数据 | 区分新观察与模型生成的标签 |
| 独立评价 | 固定评价样本，检查总体与分组结果 |

先读 [LEARN.md](LEARN.md) 的情境和小计算，陌生词再查 [术语表](../docs/TERMINOLOGY.md)。不要求预先会算法推导；本课读懂计算与比较，比背下英文名更重要。

## 90 分钟安排

0–20 分钟：教师结合一条样本解释概念；20–30 分钟：运行起始配置并找到指定结果；30–55 分钟：完成一个对照和自己的检查；55–75 分钟：核对数字、整理报告和提交文件；75–90 分钟：参加 A 版概念检查、AI 学习、B 版检查并提交。入门路径与自主路径使用同一时间安排。

到第 30 分钟仍未找到结果时，先完成入门指南的手算检查，并将命令和报错给教师；不要跳去做提高任务。环境按课前安排准备，必要时修复后补跑，不把手算冒充程序结果。

## 完成步骤

### 1. 从用途开始，运行原始实验

在 `report.md` 先写使用者、用途和预计结果。在学生仓库根目录运行，也就是能看到 `scripts/` 与 `lesson-07/` 的目录。只识别 `python3` 的电脑，把命令中的 `python` 换为 `python3`。

```bash
python scripts/course.py start 07
python lesson-07/analysis.py --output lesson-07/artifacts/original
```

程序读取本课 `data/base.json` 和 `config.json`。先看终端的中文比较，再打开本课 `artifacts/original/comparison.csv`，核对每个方法的名称和统计样本数；`records.csv` 用于逐条核对，`summary.json` 保存完整结果，`added_samples.csv` 另外列出新增样本及标签来源。文件、字段和参数对应见 [数据说明](data/DATA.md)。

### 2. 核对一项计算，再运行一个配置副本

先说明训练样本缺少什么。默认初始训练集只有 4 条午间记录，各补充方案使用同一个候选池和验证集。

先读 `added_samples.csv` 的编号、时段和 `label_source`，再读 `comparison.csv` 的 `added_n` 与 `evening_train_n`。默认各补充方案都加 4 条；合成方案并没有新增独立的晚间观察。

下面的副本将预算从 4 改成 2。程序对每种补充办法都使用这同一个新预算，不能只给喜欢的方案更多数据。你还可以另存配置改变 `target_period` 或随机种子，但不要用测试标签来挑候选。

把 `config.json` 另存为 `lesson-07/config-trial.json`。下面是可以完整复制的示例副本；JSON 使用英文双引号、逗号和冒号。它是操作起点，不是所有人必须选择的方案。

```json
{
  "seed": 7,
  "evaluation_split": "validation",
  "budget": 2,
  "target_period": "晚间",
  "primary_strategy": "group_first",
  "synthetic_offset": 0.0,
  "stress_period": "午间"
}
```

运行：

```bash
python lesson-07/analysis.py --config lesson-07/config-trial.json --output lesson-07/artifacts/trial
```

### 3. 作出自己的选择，设计一次检查

对比两个不同随机种子，或在相同预算下改优先补充的时段；记录实际选中的编号与每组样本数。哪种失败还没被新数据覆盖？不要只报告最好的一次。

AI 可以帮你提出不同解释和实现改法。至少一项选择要真正影响比较，不仅把示例改写成自己的话。允许换问题、数据和实现，但要说明为什么仍需要本课知识；不要只改字段名称却保留原结论。进一步运行请使用新输出目录，避免覆盖旧证据。

### 4. 保留比较，确定本课建议

本模块默认使用验证集作开发比较。请保留测试数据；本课不要求为了得到一个“最终分数”而提前查看它。

把本课要保留的参数写回 `config.json`，运行 `python scripts/course.py run 07` 生成主目录结果。程序的 `example_only` 仍表示起步计算，不会替你选择模型、写建议或把作业改成已完成。原方案可胜出，失败也可成为有依据的结论。

### 5. 核对提交文件

将 `report.md` 的提示替换成自己的回答，在 `contract.json` 填写任务说明，再把 `submission.json` 的 `status` 改为 `complete`。六个任务字段、结果保存和提交命令见 [本模块操作说明](../docs/FOUNDATIONS.md)。不要更改清单里的课号。

```bash
python scripts/course.py check 07
```

清单默认包含主结果的 JSON 与 CSV。报告引用的原始和试验结果、配置副本也要一起保留。`artifacts/` 被 Git 忽略，提交时需要显式加入；具体命令和验证方法在模块说明中。检查通过不等于文件已经上传。

## 必须提交什么

提交程序与配置、`summary.json`、`comparison.csv`、`records.csv`、`added_samples.csv`、任务说明和报告；保留报告引用的配置副本、原始与试验输出，以及对应运行命令。不要手填程序结果来代替计算。

报告回答：我在研究什么；什么是输入和标签；比较是否使用了正确的分母与数据；自己检查了什么；哪些证据支持保留、修改或暂停。

## 不同起点怎么做

### 入门支持（Support）：跟着详细步骤完成核心任务

使用 [SUPPORT.md](SUPPORT.md) 和已准备的 `config-start.json`、`config-support.json`。先核对一行，再做一项比较，最后选择一个有理由的改动并解释。可以请教师或 AI 解释操作，不要求自己从零实现算法。**入门支持不是低分任务，是否完成取决于比较和解释，而不是代码量。**

### 必做任务（Core）：所有路径共同需要完成的内容

在同样新增预算下比较抽样与合成标签；核对选中编号和标签来源；比较总体与分组结果；改变一个条件后说明仍缺哪些信息。使用入门路径完成这些要求后，不再额外做一次“Core 作业”。

### 提高任务（Upgrade）：有余力再加深一个比较

在相同预算下重复随机抽样，报告全部结果的波动，不能只保留最优种子。

### 换数据重测（Transfer）：用新数据重新检查

换成缺少嘈杂环境的语音样本，说明候选选择时哪些信息可用。更换字段或任务时一并调整程序和评价，不只改名称。

### 自选拓展（Open extension）：探索本课之外的问题

研究合成标签在什么条件下能帮助学习，另备未参与生成的评价数据。以上选做项不替代必做任务，也不要求全部完成。

## 运行限制

使用 Python 3.10 以上与已安装的 NumPy，本课 28 条人工教学样本，普通 CPU 即可；约 8 GB 可用内存，单次运行目标不超过 3 分钟、从头重跑目标不超过 5 分钟。必做实验不联网、不调用付费模型；AI 学习和在线概念检查的接入或补做另按教师安排。人工数据只能支持本次机制练习，不能证明真实人群、行动效果或 AI 能力。
