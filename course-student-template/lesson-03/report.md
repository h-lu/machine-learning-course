# S01 实验报告

这是填写提示，不是范文。保留自己运行前的预计；每个问题写几句话，计算用表格或算式即可。删除提示后填写实际结果，不用在每一节重复全部文件路径。

## 1. 运行前：任务与预计

谁在什么时候使用？当时可用的特征是什么、单位是什么？要预测的标签是什么？得到预测后准备用来做什么？

先写自己的预计：三种方法可能有什么差别？改变提醒阈值时，预测值和提醒是否会变化？不要拿事后结果冒充运行前的预计。

## 2. 起始实验：从一条记录到同样本比较

选定一个编号，写出特征、真实值、方法名、预测和绝对误差的计算。

核对三种方法使用的验证编号。填写每种方法的样本数、MAE 和分钟单位，至少展开一项 MAE 的求和与除法。不提醒且不提供预测这一行的 MAE 为什么不能算作零？

## 3. 个人试验：选择、预计和实际变化

我为什么选择这个阈值或新输入？只改了哪个字段？先保留预计，再写实际结果。

阈值试验：说明某条记录的预测值与提醒状态分别是否改变，使用预测值而不是真实值判断提醒。新输入试验：写出预测和缺少的标签，说明为何不能计算误差。

## 4. 建议：能说明什么，还缺什么

我准备保留哪个办法、只研究什么用途，或者暂不采用？分别引用比较结果和个人检查。提醒数或 MAE 的改善能不能解释成减少的等待时间？还需要什么新数据或比较？

## 5. 运行记录与文件

写明起始配置、示范对照、个人配置及各自输出目录，列出实际执行的命令，保证别人能按同样条件重算。最后说明 `config.json` 对应哪次选择。报告引用的文件须保存，不只留截图。
