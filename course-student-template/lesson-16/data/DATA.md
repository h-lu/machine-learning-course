# S14 数据说明：微型注意力中的人工数值

本课继续设计“离线课程问答助手”，但只检查一个内部关系：较早位置能否读取较晚位置的信息。每一行是一段四词元序列；**词元（token）** 是模型处理文字时使用的片段，本例直接用四个中文词方便阅读。

每个词元有 `key` 和 `value` 两个人工标量，目标位置还有 `query`。程序用 `query × key` 得到匹配分数，再用 softmax 把可见位置的分数换成总和为 1 的注意力权重，最后对 `value` 作加权平均。这些值由课程人工设置，不是任何真实预训练模型的词向量。

`target_position=1` 表示我们观察第 1 个位置的输出。因果遮罩开启时，它只能看位置 0 和 1；无遮罩时可以看 0 至 3。配置只替换未来位置 3 的 `value`，然后比较较早输出是否变化。这个实验能检查遮罩的信息路径，不能说明真实模型如何理解“截止”或回答是否正确。
