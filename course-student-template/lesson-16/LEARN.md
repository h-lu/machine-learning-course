# S14 学习材料：注意力能看见什么

## 词元、查询、键和值

**词元（token）** 是模型处理文字时使用的片段。真实分词器可能把一个词拆成多个片段；本课为便于手算，直接把四个中文词作为四个词元。

注意力计算常用 **查询（query）**、**键（key）** 和 **值（value）**。可以把查询理解为当前位置正在找什么，键用于计算匹配程度，值是匹配后实际汇入当前位置的信息。本课都用一个标量；真实模型通常使用向量。

对 `sequence-01` 的目标位置 1，查询为 1。位置 0、1 的键是 0 和 0.7，因此分数是：

```text
1×0 = 0
1×0.7 = 0.7
```

## softmax 怎样得到权重

**softmax** 先对每个分数取指数，再除以全部指数之和：

```text
位置0权重 = exp(0) / (exp(0)+exp(0.7)) ≈ 0.332
位置1权重 = exp(0.7) / (exp(0)+exp(0.7)) ≈ 0.668
```

权重非负且总和为 1。对应值是 1 和 2，因此输出是：

```text
0.332×1 + 0.668×2 ≈ 1.668
```

权重高表示这个计算里分配的比重大，不自动等于词语“更重要”，也不证明因果关系。

## 因果遮罩为什么挡住未来

在下一词元预测中，位置 1 只能利用位置 0、1；若能读取位置 2、3，就等于训练时提前看到了要预测内容。**因果遮罩（causal mask）** 在 softmax 前把未来位置排除，使它们没有权重。

本课把位置 3 的值从 5 改成 8。因果遮罩下，位置 3 不在可见集合，较早输出保持 1.668。无遮罩时位置 3 有约 0.414 的权重，输出增加约：

```text
0.414 × (8−5) ≈ 1.243
```

这正是 `visibility.csv` 的变化。实验直接检查了微型计算中的信息路径。

## 预测概率不等于事实

模型最后可能把表示转换成词元概率。概率描述模型在给定输入和参数下的分布；事实正确还要核对外部资料。例如“周五”概率高，不说明课程真的周五截止。遮罩正确也只说明没有读取未来位置，不能保证知识来源、推理或答案正确。

## 常见误区

- 用两段黑箱回答不同，声称证明内部注意力改变：没有中间量时只能观察行为。
- 把人工键和值称为预训练表示：本课数值由课程设置。
- 把最大权重解释为唯一原因：多个位置共同参与，权重也不是因果证明。
- 改了键和值，却把变化都归因于值：单因素比较才能较清楚解释。
- 把输出数值叫正确率：它只是加权结果，没有真实标签分母。

## 什么时候使用，什么时候还不够

教学小模型适合追踪一个机制和发现实现错误。要说明真实模型行为，还需要真实模型、同样输入、可复现配置和对应评价；即便如此，注意力权重也不能单独解释全部决策。
