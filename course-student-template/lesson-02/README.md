# 第02课（C02）：构建一项有依据的模型比较

## 本课要解决什么问题

第01课的规则能产生预测，是否值得继续使用还需要比较。本课为同一需求估计作品构建**训练均值基线与自己选择的简单候选**，在同一验证记录上判断收益及失败。候选可以沿用自己的人工规则、温度一元回归，或在本课概念范围内自拟可解释办法；不必须选更复杂模型。

你交一页模型比较证据与可重跑分析。第一个可开始动作是读数据划分与自己的前课规则，写一个你希望比较能回答的问题；默认程序可提供训练均值参照。卡住按需查 [SUPPORT](SUPPORT.md)，保留报错，人工例题先帮助理解，未运行部分明确记录并补跑。增强复习不追改原要求/成绩。

## 本课要学会什么

| 概念 | 能解释什么 |
|---|---|
| 训练、验证、测试 | 参数、候选选择和最后检查使用不同数据 |
| 基线模型 | 简单参照来自训练标签，不由评价答案决定 |
| 一元线性回归 | 参数由训练数据拟合；追踪一条直线预测，不要求推导算法 |
| MAE与公平比较 | 同编号、同目标、同信息与同单位，分母按方法分开 |
| 总体与分组评价 | 平均改善可以与局部失败并存；样本数影响解释 |

[LEARN](LEARN.md)用人工小表完整展示均值、拟合与误差，正式候选及失败组由你选。

## 课堂任务

教师引入问题、概念和一个示范；自主构建同一作品的比较，查失败并决定后续；末尾按通知完成原课堂选择题。基础、标准、提高围绕同一作品，AI可以全程参与，不要求提交提示词记录或答辩。

## 完成步骤

这是证据要求，**分析顺序和实现由你决定**。

- **定用途与候选**：说明希望怎样使用需求估计，保留运行前预计。决定比较什么简单候选及为什么它可能改变结论；若沿用前课作品，程序须真的读你的规则与参数，不能拿不同数据旧分数相减。
- **从训练期确定参数**：均值基线只用训练标签。候选可以人工设定，或用已教的一元回归拟合；参数来源明确。只用前面的训练记录学习，验证标签用于评价。
- **公平比较并独立核算**：两方法使用同一验证编号；给n、MAE单位和分母，自己选一条记录算误差。核对一小组误差加法与程序一致，不把跨方法总行数当分母。
- **选失败检查与解释**：自己选择两个相关小时/条件组，或一种能暴露用途风险的分组方式；同时给样本数、局部结果与具体编号。提出一种可能遗漏的信息和竞争解释。选组要有理由，不用逐行挑当次较准模型冒充可用方案。
- **作出选择**：依据用途与比较，保留基线、继续候选、缩小用途或暂停。允许候选没胜出；指出下一步应验证什么。最后测试仍留第08课。

至少两项实质决策是：**候选方法/参数来源**和**怎样评价目标用途的失败条件**。另一个合理方案应改变实验或建议。

所有命令在学生仓库根目录执行（能看到lesson-01、mlcourse、scripts、requirements.txt）。`analysis.py`是可编辑起点：默认只准备数据/必要基线，运行不会自动完成下列项目。共享`mlcourse/bike_course.py`保留可选例子，也可以借AI自己写读取、规则、拟合、分组与评价代码；不要求必须沿用它的菜单。方法应保持在本课已有概念范围，必要时请AI解释一条输入的计算，不突然引入不理解的新算法。

```bash
python3 lesson-02/analysis.py
```

起点只准备真实开发数据与训练均值必要基线，不自动比较全部候选。先看baseline.json的训练分母与参数来源，认清基线怎样计算；随后自行构建比较程序。可选示例帮助理解温度回归，但不限定你的方案。

## 必须提交什么

模型比较证据页（[report.md](report.md)提示可改结构）、真实候选程序/配置、同样本整体比较、独立计算、两个条件的失败证据、自主选择与可复跑清单。提交真实训练参数来源；不是复制学习页小表或默认基线。

目录工具与程序可由AI协助，但关键选择及结果解释由你承担。保存报告引用的数据版本、代码、配置、完整命令、逐条预测与汇总。`contract.json`保存任务说明，字段名不改，填写六个空字符串；`submission.json`是提交清单，把`run`改为你自己的可重跑命令、`artifacts`列为实际证据文件，完成后将`status`改为`complete`。示范或基线文件齐全不等于项目完成。`python3 scripts/course.py check 02`只检查文件，CI逐字节复算清单中的结果，不替你判断推论；未列入清单的对照仍须保存并给独立命令。用`git add -f lesson-02/artifacts`保存可能被忽略的产物。

C02不计平时分，完成办法、环境故障支持和概念检查沿原制度。

## 不同起点怎么做

**基础支持（Support）**：随需要用人工完整例题与卡点说明理解参数/分母，保留自己的候选与检查选择。

**标准任务（Core）**：构建公平比较并诊断用途风险；规则、基线或回归可有不同结论。

**提高任务（Upgrade）**：围绕同一作品选敏感性、分组权重或候选选择条件之一，说明建议何时改变；不把增加算法名单当提高。

**迁移与课后挑战（Transfer / Open extension）**：为配送时间设计公平比较；或用两个小组构造总体较好而某组较差的数值反例，完整给预测和分母。

## 运行限制

标准任务使用共享的真实 [UCI Bike数据](../data/bike/LICENSE_AND_SOURCE.md)，17,379行、17列，CC BY 4.0。训练 `<2012-07-01` 13,003行；验证 `[2012-07-01,2012-10-01)` 2,208行；最后2,168行测试留到第08课，前七课不评价它。缺165个小时记录不能补成0需求，casual/registered组成cnt，禁止作输入。

实验离线；Python 3.10以上与NumPy即可，普通CPU约8GB内存，无显卡或付费依赖。环境已在本机Python3.14/NumPy2.5验证，不代表每台学生电脑具备同一环境。完整说明见 [ENVIRONMENT.md](../ENVIRONMENT.md)。下面命令用python3，学生沿用自己的python或py启动命令即可。AI辅助与课堂选择题按教师安排联网。运行时间只反映程序计算；项目完成还需选择、检查与解释。
