# 第 02 课：一个结果能说明方案有用吗

## 本课要解决什么问题

沿用上节课的取餐等候问题：用排队人数预测等待分钟数。这次不只检查规则能否运行，还要比较基线模型和线性回归，看看总体误差与不同时段的误差是否支持同一种建议。

你将提交程序、比较结果和报告。可以让 AI 编程和解释，但要自己说明比较方法以及建议的依据。程序出错时先检查数据和配置；实验发现模型不适合某个时段，也可以成为有价值的结论。

## 本课要学会什么

| 知识点 | 学完后能做什么 |
|---|---|
| 基线模型 | 给复杂方法找一个简单参照，不只报一个分数 |
| 训练集、验证集与测试集 | 说清哪些数据学参数、哪些选方案、哪些做最后评价 |
| 一元线性回归 | 看懂“截距 + 斜率 × 特征”，并知道参数来自训练集 |
| 平均绝对误差（MAE） | 逐条取绝对误差再求平均，报告分钟而不是准确率 |
| 分组评估与使用条件 | 同时看总体与时段误差，知道样本少时结论有限 |

先读 [LEARN.md](LEARN.md)。不要求推导最小二乘公式；需要能解释一次预测和一次误差计算。

## 90 分钟安排

前 20 分钟用小表理解基线、数据划分和 MAE；接着 35 分钟运行并比较；用 20 分钟检查分组误差、写明方案后做最后评价；最后 15 分钟完成概念检查与提交。

## 完成步骤

命令仍在学生仓库根目录运行。`python3` 的使用方式与上课相同。

**写清用途，再运行验证集。**例如，结果只用于给出大致等待时间，不作为保证。先写下你认为可以接受的误差，再运行：

```bash
python scripts/course.py start 02
python scripts/course.py run 02
```

数据有 8 条训练样本、4 条验证样本和 6 条测试样本。程序默认只报告验证集。基线预测训练标签的平均值；线性回归只在训练集拟合；上节课的人工规则也一起输出，方便比较。请先不要运行测试集。

**读懂比较。**打开 `lesson-02/artifacts/summary.json` 和 `predictions.csv`。`metrics` 是线性回归，`comparison.baseline` 是均值基线，`comparison.rule` 是人工规则，`details.by_period` 是按时段分组的结果。默认验证集的 MAE 分别为 0.75、1.25 和 0.75 分钟；自行用 CSV 核对至少一项，不把这些数值当作必须达到的作业答案。

这份小数据中，人工规则与拟合直线恰好相同，不表示规则就是训练出来的，也不表示线性回归总能胜出。你在第 01 课改过规则时，只把对应的 `rule_intercept`、`rule_slope` 复制到本课配置，保留本课的 `evaluation_split`。

**做一次自己的选择和检查。**选择继续用规则、使用线性回归，或缩小用途。你可以在验证集比较不同规则，但每次保留配置和结果副本。检查 `details.by_period`：午间表现好，是否也代表晚间表现好？至少选一条失败样本解释；再自行选择一个新人数或其他条件进行检查，不把程序默认的例子原样当作自己的设计。

**确定方案后再看测试集。**先在报告记下准备采用的方案、参数和评价方法，不要看到测试结果后再选最好的一项。把 `config.json` 的 `evaluation_split` 从 `validation` 改为 `test`，再运行 `python scripts/course.py run 02`。这会用同一训练集拟合，并在 6 条测试样本上评价；输出所有候选便于核对，但测试分数不用于重新挑选方案。

再次修改方案时，已经看过的测试集只能用于开发，需要另找新的测试数据。这里的数据是公开教学样例；知道答案后重跑是练习，不是真实场景的独立验证。

**整理提交。**在 `report.md` 写出主要比较、分组结果、自设计检查与最终建议，在 `contract.json` 填写任务说明。保留验证阶段的配置和结果作为过程材料；报告中说明可用 `--split validation --output lesson-02/artifacts/recheck-validation` 重算验证结果。主要结论使用的测试结果由清单中的默认命令和当前配置重算。

实际完成后，将 `submission.json` 的 `status` 改为 `complete`。运行 `python scripts/course.py check 02`，再按 [提交步骤](../docs/WORKFLOW.md)提交。不要手改程序的 `example_only` 来替代报告。

## 必须提交什么

提交程序和配置、程序生成的两份结果文件、任务说明及报告。报告要包含至少一个基线、在同一组样本上的比较、一个分组或失败分析、自设计检查，以及证据能支持的使用建议。说明参数使用哪部分数据得到，验证集与测试集各起什么作用。

可以保留基线、保留规则、只在部分场景试用或暂时不使用，关键是理由与证据相符。C02 不计平时分，但要完成入门练习。

## 不同起点怎么做

入门支持：使用给定数据，逐条核对 CSV 中的误差，请 AI 解释公式中的每个量；仍需自己决定如何使用预测。提高任务：比较均值与中位数基线，或增加一个有意义的特征，使用验证集选择后再安排新的测试数据。不要为了多放模型而增加模型。

## 运行限制

需 Python 3.10 以上及已有依赖。数据只有 18 条，普通 CPU 即可；实验不联网、不调用付费服务。AI 辅助与在线概念检查另按教师安排。合成数据只用于理解比较方法，不能证明真实食堂里的效果。
