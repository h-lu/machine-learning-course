# 第02课数据字典与来源

标准实验读取 [hour.csv](../../data/bike/hour.csv)，一行是系统某日某小时的总租车情况，不是一名用户、一个站点或库存。UCI发布Capital Bikeshare 2011–2012记录，17,379行、17列。引用、CC BY 4.0许可、官方原文件SHA256和完整审计见 [LICENSE_AND_SOURCE.md](../../data/bike/LICENSE_AND_SOURCE.md)。本课未修改CSV。

| 列 | 含义与单位 | 用法界限 |
|---|---|---|
| instant | 记录编号 | 对应证据，不作输入 |
| dteday/hr | 日期/0–23小时 | 日期划分、定位记录，hr可在使用时已知 |
| temp | 标准化温度，0–1比例 | 不解释为摄氏度；实际当小时条件估计可用 |
| atemp/hum/windspeed/weathersit | 实际体感温度/湿度/风速/天气类别 | 前一天没有未来实测天气，不可声称提前已知 |
| workingday/holiday/weekday/mnth/season | 工作日/假日/星期/月/季节编码 | 日历信息；season旧说明与官网标签冲突，保留season_1–4数值 |
| cnt | 每小时租车总次数 | 目标值，预测后用来核对 |
| casual/registered | 临时/注册用户租车次数 | 二者相加恒等于cnt，禁作输入 |
| yr | 年份编码 | 早期示例不作输入，不能把时间增长误解释为因果 |

固定训练<2012-07-01（13,003条）；验证2012-07-01至09-30（2,208条）；最后测试>=2012-10-01（2,168条）留第08课。不要用验证标签计算训练参数；自己选择验证子组时保留同编号比较及组内样本数。整文件少165小时行，缺行不是0需求。天气类别4只有3条训练样本、无验证，不能写验证误差0。

旧`data/base.json`是人工排队热身，保留历史回看，默认不读取；不能称为真实调查或把它替代标准项目。CSV是逗号分列文本；JSON是字段名与值的文本。配置/产物的内部字段不是新算法；需要时查SUPPORT卡片。
