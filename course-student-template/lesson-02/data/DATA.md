# 第02课数据字典与来源

标准实验读取 [hour.csv](../../data/bike/hour.csv)，一行是系统某日某小时的总租车情况，不是一名用户、一个站点或库存。UCI发布Capital Bikeshare 2011–2012记录，17,379行、17列。引用、CC BY 4.0许可、官方原文件SHA-256（文件内容核对值）和完整数据核对说明见 [LICENSE_AND_SOURCE.md](../../data/bike/LICENSE_AND_SOURCE.md)。本课未修改CSV。

| 列 | 含义与单位 | 用法界限 |
|---|---|---|
| instant | 记录编号 | 对应证据，不作输入 |
| dteday/hr | 日期/0–23小时 | 日期划分、定位记录，hr可在使用时已知 |
| temp | 归一化温度，即按数据说明缩放后的0–1数值；0.5不是0.5°C | 已知当小时实际天气时可用；不能当作前一天的天气预报 |
| atemp | 归一化体感温度，不是原始摄氏度 | 与temp一样，是当小时实际天气信息 |
| hum | 归一化相对湿度，0–1；例如0.6表示60% | 是当小时实际天气信息 |
| windspeed | 归一化风速，不是原始风速单位 | 是当小时实际天气信息 |
| weathersit | 天气类别编码：1晴或少云、2雾或多云、3小雨或小雪、4恶劣雨雪等 | 是当小时实际天气信息 |
| workingday/holiday | 是否为工作日/假日，1表示是、0表示否 | 日历信息；工作日指非周末且非假日 |
| weekday/mnth | 星期编码0–6/月编码1–12 | 日历信息；星期0对应星期日 |
| season | 季节编码1–4 | 旧说明与官网标签冲突，本课按编码讨论，不指定中文季节名 |
| cnt | 每小时租车总次数 | 目标值，预测后用来核对 |
| casual/registered | 临时/注册用户租车次数 | 二者相加恒等于cnt，禁作输入 |
| yr | 年份编码，0为2011年、1为2012年 | 早期示例不作输入，不能把时间增长误解释为因果 |

数据按日期分成三部分：2012年7月1日以前的13,003条用于训练；7月1日至9月30日的2,208条用于验证；10月1日及以后的2,168条留到第8课作最后测试。

用训练标签计算模型参数；验证标签用于核对预测。如果单独检查一组验证记录，两种方法要用相同编号，并报告组内条数。

完整日历中有165个小时没有出现在文件里。这些小时的租借次数未知，不能填成0。天气类别4只有3条训练记录，验证集中没有该类记录，因此这一组应写“没有验证记录，无法评价”，不能写“验证误差为0”。

旧`data/base.json`是人工排队热身，保留历史回看，默认不读取；不能称为真实调查或把它替代标准项目。CSV是逗号分列文本；JSON是字段名与值的文本。配置/产物的内部字段不是新算法；需要时查SUPPORT卡片。
