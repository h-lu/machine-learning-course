# C02 实验报告

不用写长文。每个问题用 1–3 句话回答，并引用你实际运行得到的结果。

## 我的任务与选择

1. 这个预测准备用来做什么？我认为多大的分钟误差可以接受？
2. **在看测试集之前**，我准备采用哪个方案：基线、人工规则、线性回归，还是暂不采用？为什么？

## 运行与核对

1. 训练集、验证集、测试集各做什么？
2. 从 `predictions.csv` 选一条样本，手算一个绝对误差。
3. 我核对出的 MAE 是多少？单位是什么？

## 比较与自己的检查

1. 在同一验证集上，基线、人工规则和线性回归的 MAE 分别是多少？
2. 午间和晚间的结果有什么不同？每组各有多少条样本？
3. 我另外做了什么输入检查、失败样本分析或条件变化？

## 最后评价与限制

1. 我是在什么时间点查看测试集的？查看前选择的方案是什么？
2. 测试结果是否支持继续试用这个方案？为什么？
3. 如果看过测试结果后又修改了方案，下一次还需要什么新的测试数据？
