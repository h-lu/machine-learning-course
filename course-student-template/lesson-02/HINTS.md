# 第02课提示：按卡点查看

这些提示帮助继续你的作品，不规定统一路线或结论。

- **数据看不懂**：先说一行是什么，列的单位是什么。阅读data/DATA.md；默认sample只有结构预览，不是完整项目评价集。
- **不知道用什么输入**：对每一列问“在我定义的时点，使用者能知道吗”。不要把cnt或组成它的casual/registered放回输入。
- **程序还没写**：借AI协助，把自己的问题、选择和证据要求写清，让它解释一条样本的计算。核对训练与验证来源，不要求交AI聊天记录。
- **数字对不上**：先核同编号、方法、配置与单位，再核MAE分母；不手改产物数字。示范数值只核示范，不是正式题唯一答案。
- **结果没有改善**：检查是否同记录比较，区分平均与局部；保留失败证据，保留原方案或暂停也可有理据。
- **环境/路径报错**：按SUPPORT环境卡处理，保留报错。尚未运行须写明，不把纸面例题当实际结果。
