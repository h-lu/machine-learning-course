# 第02课 · 怎样知道一个模型比简单规则更好？

上一课可以由人给出一条预测规则。现在我们让数据决定参数，再检查：这样得到的预测，是否真的比一个简单办法好？

先用几张人工订单算清楚，再回到单车项目。不要因为一个方法听起来更复杂，就先认定它更好。

## 1. 最简单的模型：每张订单都预测5分钟

假设四张历史订单的制作时间为2、4、6、8分钟。把它们作为**训练集（training set）**，也就是用来确定模型参数的记录。

平均制作时间是：

**(2+4+6+8)÷4=5分钟。**

于是我们得到一个简单模型：不管来了什么订单，都预测5分钟。这叫**均值基线（mean baseline）**。基线模型（baseline model）是比较其他方法的简单参照，不是最低分要求，也不一定比复杂方法差。

这次模型需要学习的参数只有一个数：5。它由训练记录计算得到，与上一课人为指定参数不同。

## 2. 用没有参与训练的订单检查

另取三张订单作为**验证集（validation set）**，用来检查和比较方案。假设我们还有一个候选方法，它按自己的规则给出下表预测。这里先比较预测结果，不讨论候选方法如何训练。

|验证订单|实际时间（分钟）|均值模型预测|候选方法预测|均值模型绝对误差|候选方法绝对误差|
|---|---:|---:|---:|---:|---:|
|a|3|5|3|2|0|
|b|7|5|6|2|1|
|c|5|5|9|0|4|

先看a：均值模型预测5，实际3，绝对误差是2；候选预测3，误差是0。候选在这一条上更好。

再把三条一起看：
- 均值模型的平均绝对误差（mean absolute error，MAE）是(2+2+0)÷3=4/3分钟。
- 候选的MAE是(0+1+4)÷3=5/3分钟。

候选虽然在前两条上更准，但第三条错得较多，最后总体MAE反而较大。如果主要标准是这三条上的MAE，应保留均值模型。这里不是说“均值模型总是最好”，只是对这两套给定预测、这三条验证记录作比较。

不能在看到实际答案后，对每条挑一个误差最小的模型，再把拼起来的结果当作可用方案。真实预测时没有答案，无法照这样挑选。

## 3. 训练、验证、测试各做什么？

三者可以理解为三个阶段：

**训练：得到参数 → 验证：比较和选择 → 测试：选定后作最后检查。**

**测试集（test set）**是方案确定后才使用的一批记录。若看到测试结果不好就改参数，再测同一批，测试记录已经参与了开发。修改后的方案需要新的独立数据检验。

本课单车项目按时间安排：
- 较早的13,003个小时用于训练。
- 接着2,208个小时用于验证。
- 最后的2,168个小时留到第8课测试。

计算均值、回归系数等参数时，只使用训练记录中的实际结果。验证记录中的实际结果用来核对预测、比较候选方案；不能看到某条验证记录的答案后，再专门修改这一条的预测。

## 4. 输入也能帮助预测：拟合一条直线

刚才的均值模型没有看订单特点。现在换一个人工配送例子，看看怎样使用输入。

|训练距离（公里）|实际配送时间（分钟）|
|---:|---:|
|1|6|
|2|10|
|3|14|

从1公里到2公里，时间增加10−6=4分钟；从2公里到3公里，也增加4分钟。因此斜率取4。把第一条代入“截距+4×1=6”，就得到截距为2。于是这三点恰好落在下面的直线上：

**预测分钟数 = 2 + 4×距离。**

代入1、2、3公里，分别得到6、10、14分钟。这里截距（intercept）是2，斜率（slope）是4分钟/公里。用一个输入预测数值的直线模型，叫作**一元线性回归（simple linear regression）**。

真实记录通常不会恰好排成直线。拟合时常用**最小二乘法（least squares）**：比较预测与实际的差，把每条差平方后相加，选择让这个合计尽可能小的系数。本课可以调用现成的`fit_simple_line`，第9课再完整手算系数；现在先理解系数来自训练数据。

对于2.5公里的新订单，预测为2+4×2.5=12分钟。若后来实际用了15分钟，绝对误差就是3分钟。训练记录上完全吻合，不保证新记录也完全吻合。

训练时用平方误差选系数，评价时用MAE解释平均偏离，两者作用不同，不矛盾。斜率也只是这套预测模型里的关系，不能仅凭它断言改变距离必然造成相应时间变化。

## 5. 比较时，先确认双方看的是同一批记录

一个方法在晴天、另一个在雨天得到的MAE，不能直接当成同条件比较。哪怕两边记录数一样，编号不同，面对的问题也可能不同。

至少核对：
1. 评价记录的编号是否相同？
2. 目标含义和单位是否相同？
3. 两个方案是否只用了允许的训练信息？
4. 是否采用同一个评价指标和相同处理规则？

回到订单小表，前两条的结果与第三条很不一样。把同一模型的预测按条件分开检查，叫作**分组评价（subgroup evaluation）**。它不是为每组重新训练模型，而是看现有预测在哪些条件下更容易失准。

## 6. 两个组的MAE，不能总是直接平均

假设另一份评价里：
- 第一组2条记录，MAE为1分钟；
- 第二组8条记录，MAE为3分钟。

第一组的绝对误差合计为2×1=2分钟，第二组为8×3=24分钟。总体MAE因此是：

**(2+24)÷10=2.6分钟。**

不能直接算(1+3)÷2=2分钟，因为这样让2条记录和8条记录占了同样的比重。按各组记录数计算，叫作**加权平均（weighted mean）**。

你可以用另一种办法核对：先把每条绝对误差合计，再除以总条数，结果也应为2.6分钟。

这个合并方法要求两组不重叠，而且合起来包含所有评价记录。同一条记录如果被算了两遍，就不能这样合并。

## 7. 在正式项目里怎样做？

保留一个均值基线，再选择一个你能解释的候选。可以沿用上一课规则，也可以用温度拟合直线。

按下面的顺序检查：
1. 保存训练记录数和参数来源。均值基线的参数是训练cnt的均值；直线需要保存截距、斜率和输入字段。
2. 对同一批验证记录产生两套预测。
3. 任选一条，手算两种预测和绝对误差，核对程序。
4. 汇总全验证集MAE，再检查一个与你用途有关的组。
5. 说明选择哪个方案、依据是什么，以及哪些使用情形还没有检查。

`temp`不是直接的摄氏度，解释斜率时要沿用数据字段的尺度。程序入口、运行方法和提交要求见[任务页](README.md)；默认起点并不会替你完成全部比较。

## 8. 练习与不同完成程度

- **基础完成：**复算订单小表；再用训练标签1、3、5、7求均值，对实际值2、8计算两条绝对误差和MAE。说清哪个数来自训练，哪个数只在评价时使用。
- **完整完成：**在正式项目中完成基线与候选的同记录比较，解释一条预测和一个分组结果，保存原任务要求的证据。
- **扩展练习（选做）：**在订单小表里分别评价a、b这一组与c这一组。先算每组的MAE，再用记录数合回总体值。想一想：如果使用者特别在意c所属的情况，你会怎样补充“总体较好”这句话？

基础题核对：训练均值为4，两个绝对误差为2和4，MAE=(2+4)÷2=3。先算完再看这一行；若结果不同，检查是否误把验证的2、8加入了训练均值。

最后自检：如果今天只能看到输入，不能看到实际答案，我的预测规则还能执行吗？如果不能，就要回头检查是否把答案带进了方法。
