# 第12课（S10）：参数怎样改动：一次更新与训练曲线

## 本课要解决什么问题

继续使用第10课的短信分类模型。沿用第11课选好的文字转数字方法，观察模型怎样一点点改变系数。只比较每步改多大（学习率），或比较改多少步后停下（停止时机）。

## 本课要学会什么

- 解释训练中要减小的数值（损失）与用途指标有何不同。
- 核算一个系数和截距的一次更新。
- 说清哪些系数受正则约束、每条训练记录占多大分量。
- 只改学习率或步数，保持其他条件相同。
- 读训练/开发曲线，用开发结果选停止点。

## 课堂任务

自选一个仍会出错的情形，并在学习率和停止时机中选一个实验方向。保持文字转数字的方法、划分、起始参数、各条记录的分量、正则和另一项学习设置不变。比较两种设置，核算一次更新及更新前后损失；画出或查看训练和开发曲线，并追踪同一条真实短信的概率变化。

你决定要解释的失败及改变哪个学习设置；再说明什么曲线或复核结果会支持改动。无需强行做出震荡或过拟合，平稳下降也要如实解释。 AI可帮助写代码、计算和分析；要核对关键数值，不能只交默认输出。允许自拟其他路线，只要有真实可运行材料、相同的比较条件、本课的计算追踪，并且最后评价数据没有参与方案选择。

曲线上的损失下降，不保证误选或漏选已经符合用途。停止步数由开发部分选择，不能去最终留出部分找最好的一步。

## 完成步骤

在学生仓库根目录运行；已有环境是Python 3.10+和NumPy。

先沿用自己的文字转数字配置；若还没有可运行版本，默认TF–IDF可作起点：

```bash
python3 lesson-12/analysis.py
```

结果在lesson-12/artifacts/baseline。再次运行请加`--output lesson-12/artifacts/新目录名`，保留旧结果。first_update.json保存第一次改动前后及计算方向；curve.csv每行对应一步。它们各列怎样算、怎样看见[LEARN](LEARN.md)；[SUPPORT](SUPPORT.md)说明只改lr或steps。

阅读和实验顺序由你安排；[HINTS](HINTS.md)解决具体卡点，[EXERCISES](EXERCISES.md)检查能否换一个例子解释。

## 必须提交什么

一份作品要包含：问题与两项重要选择、一条真实记录的计算、同记录的两方案比较、失败检查、建议和限制。填写contract.json，保存报告、代码、配置和结果；把submission.json的run改为自己的命令，artifacts列齐该命令生成的结果。只运行起点尚未完成任务，不另交额外报告或AI对话日志。

沿用v2-l12-final和revision标签，[提交流程](../docs/WORKFLOW.md)与[评分](../docs/ASSESSMENT.md)不变：完成25、代表作品25、期末50，每六课取最好五次。课末A独立判断→AI学习→B换情境，按参与计分，不按正确率扣完成分。

## 不同起点怎么做

先用完整小例看懂关系，再用可选程序或自己实现的方法完成比较。较快者可在同一作品多查一个分组或设置，但不要同时改许多条件后猜原因。有证据地保留原方案也合理。

## 运行限制

短信已固定分为train（训练）、dev（开发，供比较选择）和finalholdout（最终留出）。文字处理和模型参数只从train学；dev选方法、门槛、停止点和要检查的错误组。第14课选好方案后才第一次评价finalholdout。见[数据与英文支持](../data/sms/DATA.md)。

普通CPU、约8GB内存即可，无付费服务或GPU；安装和模型缓存由教师课前准备，课堂不下载大文件。作者运行成功不等于已经通过真人课堂试教。
