# 第12课 · 固定SMS表示的真实训练轨迹

第11课改变短信的表示方式；本课先固定一种表示，研究模型的系数怎样学出来，以及每步改多大、训练到什么时候停。

## 数据与输入

仍使用 `data/sms/train.csv` 的3877条训练短信与 `dev.csv` 的807条开发短信。每行一条短信，text为英文原文，label中的spam为垃圾短信、ham为正常短信。train用于计算梯度，dev用于观察与选择，最终留出数据留到第14课。

可以沿用自己第11课选定的manual、bow或tfidf表示。比较期间保持词表规则、尺度、正则、样本权重和初值不变。默认人工特征作为可检查的起点，六项含义见第11课；本课不要求更换表示。

## 基础练习：完整算一次更新

[LEARN](LEARN.md)用两条人工记录展示：概率→损失→每条记录的梯度贡献→平均→更新系数→重新计算损失。

```sh
python3 lesson-12/small_example.py
```

输出 `lesson-12/artifacts/small-example.json`，应看到w从0变为0.5，平均损失从0.693147降至0.503204。这个小例没有正则，不代替正式SMS任务。

## 课堂任务

选择一个你想解释的训练现象，预先说明什么证据会支持你的判断；在学习率或停止时机中选择一个比较方向。

1. 固定一种SMS表示及其余训练设置。只改变lr，或只改变steps，运行两种设置并保存完整曲线。
2. 从真实训练数据核算一个系数与截距的第一次更新，说明单条记录的贡献与全体梯度的区别；核对更新前后训练目标。
3. 比较训练与开发损失，追踪同一条真实dev短信的概率，同时核对最终误选、漏选。解释你认为训练不足、更新过大或继续训练收益有限的依据。
4. 给出保留或修改设置的建议，说明为什么。稳定下降、没有改善或不支持原假设都可以是结果。

两个重要决定是：你研究哪种现象、改变什么设置，以及依据什么开发证据和使用代价选择方案。可自拟等价分析路线，不要求全班使用同一组学习率或得出同一结论。

## 开始正式运行

在学生仓库根目录运行：

```sh
python3 scripts/course.py start 12
python3 lesson-12/analysis.py
```

默认产生 `lesson-12/artifacts/baseline/`。先看 `first_update.json`（第一次更新）、`curve.csv`（每一步状态）和 `loss.svg`（训练/开发曲线）。[SUPPORT](SUPPORT.md)带你读第一行、核对一个系数，再说明怎样保存第二份配置与比较两次结果。

运行起点只得到一个条件，不自动完成正式比较和判断。`EXERCISES.md` 的基础题帮助理解，提高题为选做；AI可协助全部工作，无需提交对话记录。
