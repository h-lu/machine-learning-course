# 第 12 课（S10）：模型究竟从数据中学到了什么

## 本课要解决什么问题

**先打开 [入门支持](SUPPORT.md)，运行起点并查看第一次参数更新。** 上一课把咨询记录变成了模型可用的数值；本课用一个微型逻辑回归模型判断是否需要人工复核。你不需要从零推导算法，但必须追踪一次“预测—计算损失—计算梯度—更新参数”的过程。

程序比较两个学习率，保存第一次更新、完整学习曲线和逐条概率。你要核对一个参数的更新方向，再只改变一项训练设置。损失下降说明训练正在优化规定的目标，却不能单独证明概率已校准、提醒办法合适或新场景有效。你要提交一次更新手算、两条学习曲线、个人单因素实验和测试前选择。运行失败时保留命令与报错，先按支持页公式核对更新，修复后补跑。

## 本课要学会什么

| 标准术语 | 学完后的表现 |
|---|---|
| 参数 | 指出模型训练过程中会更新的数值，以及它与输入的关系 |
| 目标函数与对数损失 | 解释训练程序准备减小什么，并能读懂损失曲线 |
| 梯度 | 把梯度解释为参数附近的变化方向，不把它说成最终答案 |
| 学习率 | 预计步长过小或过大对更新和学习曲线的影响 |
| 优化与实际用途 | 说明训练损失下降不能代替验证、概率检查和行动评价 |

先读 [LEARN.md](LEARN.md) 的一次参数更新例子；不要求先会微积分，陌生词可查 [术语表](../docs/TERMINOLOGY.md)。

## 90 分钟安排

0–20 分钟跟踪一条预测和一次更新；20–35 分钟运行并核对更新方向；35–55 分钟比较学习率与曲线；55–65 分钟设计单因素检查；65–75 分钟整理提交；75–90 分钟完成概念检查。

## 完成步骤

### 1. 运行并找到第一次更新

在仓库根目录运行：

```bash
python scripts/course.py start 12
python lesson-12/analysis.py --config lesson-12/config-start.json --output lesson-12/artifacts/start
```

成功后先打开 `first_update.csv`。`before` 是更新前参数，`gradient` 是训练集平均梯度，`after = before - learning_rate × gradient`。选 `message_length` 一行，用起始学习率重算 `after`，并说明参数增大还是减小。字段已用训练集均值和标准差缩放，所以参数不是“每增加一个汉字”的原始单位效果。

### 2. 阅读曲线并区分训练与评价

打开 `learning_curve.csv`，分别看两个方法在第 0、1、10 和最后一轮的训练、评价对数损失。再看 `comparison.csv` 的准确率。损失能反映概率置信程度，准确率只看阈值后的类别；两者可能不会同步变化。

### 3. 只改变一个训练设置

复制 `config-start.json` 为 `config-mine.json`。只改 `comparison_learning_rate`，先预计曲线会更快下降、波动还是变差，其他值保持不变。运行：

```bash
python -m json.tool lesson-12/config-mine.json
python lesson-12/analysis.py --config lesson-12/config-mine.json --output lesson-12/artifacts/mine
```

如果较大学习率在这个小实验中表现更好，只能说明当前范围和轮数下有效；不能推出学习率越大越好。也可以只改 `epochs`，但不要同时改学习率后把变化归因于轮数。

### 4. 保存验证选择，再完成最后评价

根据验证损失、曲线是否稳定和实际用途选一个设置，写回 `config.json`。先记录选择，再把 `evaluation_split` 改成 `test`，运行 `python scripts/course.py run 12`。测试后再调参，这批测试数据便不能继续作为独立最终评价。

### 5. 完成提交检查

填写任务说明和报告，把状态改为 `complete`，运行 `python scripts/course.py check 12`。报告保留上一课所选表示的名称；本课程序为了可独立运行会使用固定的四项缩放数值特征，并不会自动读取上一课文件，不能声称已经重跑了个人 S09 方案。

## 必须提交什么

提交程序、最终配置、任务说明、报告，以及 `summary.json`、`first_update.csv`、`learning_curve.csv`、`comparison.csv`、`records.csv`；保留个人配置和输出。

报告回答：模型输入和标签是什么；一个参数怎样更新；两个学习率的曲线有何差异；为何选择最终设置；训练损失下降能支持什么、不能支持什么；测试结果的可以支持的数据和情境。

## 不同起点怎么做

### 入门支持（Support）：逐项核对一次更新

[SUPPORT.md](SUPPORT.md) 给出完整命令、公式位置和核对数字。完成支持路径不降低成绩。

### 必做任务（Core）：追踪更新并比较一个训练设置

核对一次更新方向，读取训练和评价曲线，只改变学习率或轮数之一，并在测试前作出选择。

### 提高任务（Upgrade）：寻找不稳定学习率

逐步增加比较学习率，记录第一次出现损失明显上升或来回波动的位置；不要把偶然一次较低损失当作稳定。

### 换数据重测（Transfer）：换一个二分类用途

保留同一更新过程，把标签换成“是否需要补充信息”等明确结果，重新说明正类和错误后果。

### 自选拓展（Open extension）：逐样本更新

实现一次只用一条训练记录的更新，与当前整批平均梯度比较曲线波动。说明这超出必做范围。

## 运行限制

Python 3.10 以上与 NumPy；48 条人工数据，普通 CPU 单次不足 1 秒。模型仅用于追踪优化机制，不代表生产系统，也不证明任何群体中的真实效果。
