# 第06课分级提示（按需）

先写自己的问题和预计；如果卡住再选择以下方向，不必逐条完成。

1. 核对象：评价用途、错误后果、分母与处理容量中你到底在比较哪个量？用LEARN小例区分它与相近概念。
2. 核证据：不知道类别时先写final_alert与actual_high两布尔值；不知道排名时只按可用预测排序，不能按真实cnt倒挑。
3. 核边界：MAE按真实评价行数；本例加权低估仍用全部行数作分母；候选不等于最终提醒；四类按最终行为；精确率/召回率各自分母；同日全部已打分批次不声称实时或因果效果。
4. 核建议：如果两条合理路线结论不同，哪项检查最能区分原因？可以保留原方案；当前没有证据的条件写未知。
