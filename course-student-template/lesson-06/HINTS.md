# 第06课分级提示（按需）

先写自己的问题和预期；如果卡住再选择以下方向，不必逐条完成。

1. 核对象：评价用途、错误后果、分母与处理容量中你到底在比较哪个量？用LEARN小例区分它与相近概念。
2. 核证据：不知道某小时属于哪类时，先核对`final_alert`（最终是否提醒）与`actual_high`（实际是否达到阈值），二者均为`True`或`False`；排序只用当时可见的预测，不能按实际`cnt`反过来挑选。
3. 核边界：MAE以实际参与评价的记录数为分母；本例把低估误差乘权重后，仍除以这批记录总数；候选不等于最终提醒；四类按最终行为；精确率/召回率各自分母；同一天所有小时预测完成后的提醒比较，不能证明实时可用，也不能证明提醒导致租赁增加。
4. 核建议：如果两条合理路线结论不同，哪项检查最能区分原因？可以保留原方案；当前没有证据的条件写未知。
