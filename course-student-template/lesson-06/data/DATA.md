# 本课数据与证据边界

来源：[UCI Bike Sharing](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset)，Capital Bikeshare 2011–2012，CC BY 4.0。官方 ZIP 的 `hour.csv` 实点 17,379 行、17 列，SHA-256 为 `e03de4ee4ef4dc376ac6e04bf829673c6269e8eba5c60fa121640fa2f829504f`。完整离线副本在学生仓库 `data/bike/hour.csv`，原数据说明见共享数据目录；本课程序校验哈希，错误时不要自己改原 CSV。官网概览数量与文件计数不同，使用文件实点。

一行表示系统一个有记录的小时；`dteday`+`hr` 是时点，`instant` 是记录编号。`cnt` 为该小时完成的租赁次数，不能观察有多少人因无车未租到；不是单站库存，也不是独立用户人数。`workingday=1` 表示非周末且非节假日；`temp` 为已归一化温度。`casual` 和 `registered` 相加等于 `cnt`，始终禁作预测输入。`season` 数字保留，原 README 与官网季节名称冲突须注明来源，不擅自改标签。

真实任务是同小时实际天气条件下需求估计，不假定提前知道未来真实天气。训练日期 `<2012-07-01` 共 13,003 行；验证日期 `2012-07-01` 到 `<2012-10-01` 共 2,208 行；最后 2,168 行测试目标在第 01–07 课封存。程序可以核日期和行数，不能据此评价封存标签。小时网格缺 165 条，未知不补 0。`weathersit=4` 只有训练 3 条，验证/测试无记录，不能声称验证了严重天气。

本课结果仅来自指定训练/验证；封存测试不参与方案选择。
