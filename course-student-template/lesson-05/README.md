# 第05课（S03）｜怎样划分数据，验证才接近实际使用

本课围绕**训练/验证/测试职责、时间与对象分组变化、训练统计来源和泄漏**改进你的作品。你可以沿用已有问题、改变它，或自拟有依据的小问题；起点代码帮助你读入数据，分析方法由你选择。先确定想研究的问题，再按需用[学习页](LEARN.md)、[支持](SUPPORT.md)与[开放代码工具](../docs/CODE_TOOLKIT.md)。本增强版不追溯增加已授课作业要求，不重算旧成绩或更改既有线上场次。

## 本课要解决什么问题

以后遇到哪些时间/对象？这一切分模拟了什么、遗漏什么？哪些记录参与计算训练数据的统计量？哪种漂亮分数其实用了不可能已知信息？ 课程共用的数据包含17,379条真实小时记录；也可以换用有明确来源的数据或自己的程序。请说明本课概念怎样帮助回答问题、数据能支持哪些判断，以及怎样用现有资源检验。你可以依据结果保留原方案、修改任务、将部分判断交由人工处理，或暂不采用当前方案。

## 本课要学会什么

理解训练/验证/测试职责、时间与对象分组变化、训练统计来源和泄漏；能追踪一条计算/记录，预先判断条件变化可能怎样影响结果，构建合理替代并说明证据限制。[LEARN](LEARN.md)给通俗解释、不同小表的已完成例题与误区，例题不完成你的正式研究。

## 课堂任务

完成一件验证设计作品：用途匹配的切分清单、训练来源追踪与对照证据。自定真正使用对象/日期；自己决定开发划分依据与模型/处理统计检查或评价范围中的至少两项。 这些选择应实际影响分析过程或结论。AI可以全程协助；你需要用具体样本核算，并在不同情境中解释自己的判断。

**基本任务：**用小例解释核心关系并使自己的程序实际读取数据。

**标准任务：**构建自己的切分与公平比较（时间、分组、随机对应不同用途，均为核心关系），完整追踪记录角色和处理统计，判断本任务重复/相关记录单位及是否应一起分；Bike无站点/个人身份，不能称验证了新站/新人。随机划分只在15,211条开发记录中进行，验证集仍取2,208条，便于保持样本数量一致；自拟方法须交代新条件。

**提高任务：**围绕同用途改变一种分组/时间条件，解释不同验证样本的可比界限；或用有重复对象的新数据设计分组验证。 三类任务围绕同一件作品。使用支持材料不影响评价；不要求人人做完所有扩展或重复交三个作品。

## 完成步骤

**你的研究方案需覆盖这些证据，顺序由你决定：**

- 说明使用者、目标、预测/观测时点与实验前预期；保留至少两个重要决策及依据。
- 使用真实数据自行构建标准分析；以同用途下的合理替代作公平比较，记录变化与控制条件。
- 追踪具体记录/分组/计划，核算一项关键值，自己设计一次失败检查或条件变化。
- 据证据保留、修改或暂停，说明尚不能得出的结论；保存能重跑的程序与原/新结果。

检查边界：测试目标不参与选择；训练统计只用本方案训练行；验证样本变化时不把分数差当同记录改进；casual+registered重构是INVALID示范而非模型。 默认起点只给固定开发时间清单，不生成随机/回归完整答案。泄漏重构若自行展示应命名INVALID且不进入合法比较。 支持材料按问题选用，不要求沿固定顺序完成研究。

## 必须提交什么

提交自己的分析程序、配置/任务说明、实际结果与报告；报告格式可改，但问题/用途、数据来源、至少两个重要选择、公平比较、失败检查、核算和适用限制不能省。保留原方案与比较试验，见[练习资源](EXERCISES.md)。

默认的`submission.json`只列出起点结果，**运行起点代码不等于完成项目**。完成自己的分析后，把结果文件路径写入`artifacts`，替换或补充原清单；把`run`改成实际能够重新生成这些文件的命令。

完成研究后，才把`status`改为`complete`。在学生仓库根目录运行`python3 scripts/course.py check 05`及`python3 scripts/course.py ci`。CI（自动检查）会重新运行命令，核对清单中结果文件的内容是否一致；它不判断结论是否正确。未列入清单的比较试验须另存重跑命令。

保留旧标签，增强复习是否另提交修订依教师安排。

## 不同起点怎么做

不清楚某关系时看LEARN的完整计算，不清楚代码/输出时按SUPPORT的卡点求助；先自己尝试，再看[分级提示](HINTS.md)。基础和提高都保留实质选择。可自主换题/数据/方法/表达，只需保持本课核心概念与证据；不按模型数、代码量、AI对话长度或复杂外观加分。

## 运行限制

使用已准备的Python与NumPy，命令示例为本机`python3`；你原环境若使用`python`或`py`，统一用已经成功的启动命令，不安装新环境。默认起点从学生仓库根目录的`data/bike/hour.csv`离线读取数据，只准备文件检查和样本预览，不能作为正式分析已完成证据。AI可帮助提出问题、写代码、核算和解释，不要求提交提示词记录、不要求所有人同路线或强制逐人答辩。

数据/依赖错误保留命令、工作目录和完整报错；先用不同数据的完整小例继续理解，明确写未实跑，再找教师修复。用`--output`指定的目录若已存在，程序会拒绝覆盖；请换新目录保留旧结果。不指定`--output`时，默认的`artifacts/starter`允许重新生成。正式程序和输出由你决定；`submission.json`中的`run`必须能重新生成`artifacts`列出的分析结果。未列入清单的比较试验，另存配置和重跑命令。

默认起点只给固定开发时间清单，不生成随机/回归完整答案。泄漏重构若自行展示应命名INVALID且不进入合法比较。 数据来源、字段/时间边界和许可见[data/DATA](data/DATA.md)。普通CPU离线，概念检查与AI接入由教师安排；不能将不可用资源藏到必做要求。
