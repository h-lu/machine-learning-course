# S03 实验报告

完成实验后，用实际数据说明：

把下面提示替换成自己的回答，每项几句话即可。程序结果来自实际运行，不手填一个期望的分数。

## 1. 两个可能的使用问题与预计

分别说明“预测已有窗口的未来日期”和“预测训练中没有出现的新窗口”这两个问题。对每个问题写下你预计更接近 time 还是 group，以及理由。指向对应配置、结果文件和运行命令。

## 2. 训练、验证和保留测试的证据

分别列出 time、group 的训练编号、验证编号、`train_n`、`n` 和 `shared_sites`。说明第 7–8 天的测试编号是否进入训练或验证，并指向对应配置、结果文件和运行命令。

## 3. 一项 MAE 手算和一条泄漏反例

用 time 方案的六条验证记录手算一次 MAE：列出六个 `absolute_error`、分母和结果，并与 `comparison.csv` 核对。再选 B05 或其他一条记录，说明正常预测和泄漏示范分别使用什么信息，以及为什么泄漏示范不能采用。

## 4. 我的检查与选择理由

如果改日期，列出训练/验证编号和分母怎样变化；如果改种子，至少列出三个种子的结果。解释为什么不能只看最低 MAE，并指向对应配置、结果文件和运行命令。

## 5. 结论的范围和下一步

说明你保留的划分主要对应哪个用途，还有哪些时间、窗口或对象变化没有单独检查。写出一条有证据的保留、修改或暂停建议；不要把开发验证结果写成最终测试结论。
