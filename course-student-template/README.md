## 数据与作品

前八课使用离线[UCI Bike Sharing小时数据](data/bike/LICENSE_AND_SOURCE.md)，从输入、模型比较、用途、数据审计、划分、评价、补样到诊断形成连贯作品。真实CSV保持原字节。人工小表只用于讲解计算，不能当真实证据。前1–7课保留最后测试部分；第8课事先选择后才评价测试。

每次实验保留配置、命令和新输出目录。起点程序只准备数据与必要基线；你可以自拟等价任务、改变方法并调整报告结构，标准证据不能省。可选计算示例不是必选菜单。报告中的选择、失败解释和建议由你完成。AI可以协助，但需要核对具体记录和关键计算。
