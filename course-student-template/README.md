# 把机器学习做成一件能检查的作品

你要用数据解决一个自己能说清的问题。它可以是预测数量、安排复核、发现异常、查找资料，或在模拟环境中选择下一步。每次课完成一个小实验，看看学到的方法是否真的有用。

请提交能运行的程序、程序生成的结果，以及说明选择和结论的报告。结果不好时，先保留它，检查数据与评价方法，再说明应该修改什么或为什么暂时停止使用。你不需要把每次实验写成成功故事。

## 从哪里开始

1. 第一次上课读 [环境准备](docs/GETTING_STARTED.md)，运行 C01 的入门示例。
2. 在 [32 课入口](docs/LESSON_GUIDE.md) 找到当课，先读任务，再读学习卡中的例子。
3. 决定自己的问题。可以沿用示例，也可以按 [选题办法](docs/PROJECT_CHOICES.md) 换数据或用途。
4. 按当课步骤实验，再看 [提交说明](docs/SUBMISSION.md)。

## 你能自由改什么

数据、特征、模型、指标、图表、报告结构和运行入口都可以改。每课会说明必须学会的概念和必须完成的检查。新方案只要覆盖这些要求、能在课堂资源内运行，就不必和示例长得一样。

每个 `analysis.py` 都能运行，但它只是入门示例。你至少需要作出一个会影响结果的选择、完成一次合理比较，并自己设计一个检查。程序产生的 `example_only` 表示示例结果；它不代表你已经完成项目。

## AI 怎样参与

AI 可以解释、写代码、做计算和整理报告。你先写下预计结果，再运行 AI 协助完成的程序，核对一个样本和主要指标，最后用实际结果修改判断。不要求提交完整对话。具体例子见 [AI 协作](docs/AI_USAGE.md)。

## 普通电脑就能开始

Python 和 NumPy 在课前装好。必做实验使用仓库内的小型离线数据，不需要独立显卡、付费接口或临时下载模型。运行方法与参数见 [实验接口](docs/RUNTIME.md)。遇到安装或运行问题，看 [故障处理](docs/TROUBLESHOOTING.md)。

这些数据是教学用合成或微型样例。它们能帮助你理解计算与检验办法；若要对真实使用者提出建议，还需要适合那个场景的数据。
