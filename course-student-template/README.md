## 数据与作品

前八课使用离线[UCI Bike Sharing小时数据](data/bike/LICENSE_AND_SOURCE.md)，从输入、模型比较、用途、数据审计、划分、评价、补样到诊断形成连贯作品。数据审计指检查记录、字段和时间覆盖是否符合说明。真实 CSV 保持原始文件内容。人工小表只用于讲解计算，不能当真实数据的研究证据。前1–7课不使用最后测试部分；第8课先根据验证结果选定方案，再评价测试部分。

每次实验保留配置（程序的参数或选择）、命令和新输出目录。起点程序只准备数据与必要的基线模型，即供比较的简单参照。你可以自拟等价任务、改变方法并调整报告结构，但仍需满足本课的证据要求。可选计算示例供按需使用。报告中的选择、失败解释和建议由你完成；AI 可以协助，但需要核对具体记录和关键计算。
