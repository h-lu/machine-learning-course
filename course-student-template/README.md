# 现代机器学习项目课：从问题到可检验的作品

本学期完成 32 次课堂项目：提出机器学习问题、准备数据、比较基线与模型、检查失败案例，并根据结果决定继续、修改或停止使用。你可以全程使用 AI 完成编程、计算、分析和写作；提交前需要说明问题、评价依据、结果限制和适用范围。

每节课先阅读对应目录的 `README.md`，了解项目背景和任务，再阅读 `LEARN.md` 中的基础知识并运行示例。最后整理报告、程序和结果，并用 [ml-check](https://hblu.top/ml-check/) 完成 A 版基础题、AI 学习和 B 版变式题。项目允许有依据的不同方法和结论，不以代码量、模型数量或页面复杂程度评分。

## 第一次使用

按[操作与提交步骤](docs/WORKFLOW.md)检查 Python 与 Git，并从第 1 课开始：

```bash
python scripts/course.py start 01
python scripts/course.py run 01
```

若系统使用 `python3`，替换命令中的 `python`。基础工具需要 Python 3.10 或以上；额外依赖和排障方法见[环境与排障](docs/TROUBLESHOOTING.md)。

## 本学期项目

课程按 16 周、32 课组织，完整课次和每课任务见[32 课入口](docs/LESSON_GUIDE.md)。目录 `lesson-01` 至 `lesson-32` 与发布标签 `v2-l01-final` 至 `v2-l32-final` 一一对应。

每课都要完成一个实质分析、一次合理比较和一次自己设计的失败或边界检查。示例程序用于理解接口；只运行示例、生成文件不等于完成项目。

## 作品应包含什么

每课提交分析报告、支持结论的图表或数据，以及能重新生成结果的代码。默认在当课 `report.md` 写报告，在 `artifacts/` 保存结果；也可在 `submission.json` 中填写其他报告路径、结果路径和运行命令。报告应说明：

- 使用者、输入、输出和实际用途；
- 数据处理、基线、模型或规则选择及比较办法；
- 主要指标的分母、失败案例、稳定性或不确定性；
- 根据结果采取、修改、暂停或停止行动的条件；
- 运行命令、依赖和结果文件，使他人能够复核。

## 平时成绩 50 分

评分对象是项目成果和分析说明。期末考试 50 分由教师另行安排。

- **课堂项目完成 25 分**：C01、C02 为入门课，不计入平时分但必须完成。S01—S30 分为五个模块，每模块六课取最好五次，每课最高 1 分：课堂结束前提交可复现程序、报告和结果并通过 `ml-check` 结构检查得 0.8 分；完成 A 版得 0.1 分；完成学习和 B 版得 0.1 分。下一次课开始前补齐，项目部分最高 0.5 分，已获得的自查分保留。
- **代表作品质量 25 分**：每个模块选一件作品，每件 5 分。教师按问题与用途、数据与方法、分析依据与不确定性、建议与适用范围、可复现性与表达五个维度评分，每项 0、0.5 或 1 分。

模型复杂度、图表数量、网页外观、代码量和 AI 对话长度不自动加分。有依据地采用简单规则、保留基线或停止使用模型，同样可以获得高评价。完整细则见[成果与评分](docs/ASSESSMENT.md)和教师版[评分标准](../course-instructor/GRADING.md)。

## AI、数据与结论的限度

AI 可以解释、写代码、做计算和整理报告。你需要核对样本和主要指标，并用实际运行结果修改判断。不要求提交完整对话。课堂数据为合成或微型离线数据，不能直接证明真实业务、真实用户或大模型效果；使用新数据或新用途时，应重新设计评价和检查。

## 运行与求助

必做实验面向普通 CPU 和约 8 GB 可用内存，不需要独立显卡、付费接口或临时下载模型。运行方法见[实验接口](docs/RUNTIME.md)，提交格式见[提交说明](docs/SUBMISSION.md)，概念自查见[知识自查说明](docs/KNOWLEDGE_CHECK.md)。
