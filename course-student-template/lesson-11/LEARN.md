# 表示决定了模型眼中的“接近”

## 原始记录不会自动成为合适输入

**数据表示（representation）**是把原始记录转成模型实际计算的数值。例如消息长度是数值，渠道是类别，缺失长度不是数字 0。表示方法决定模型能看到哪些区别。

本课使用近邻方法。它先计算新记录与训练记录的距离，再由最近记录投票。方法保持不变时，预测变化来自表示变化。

## 尺度为什么重要

两条记录在两个字段上的差异为：消息长度 20 个词，历史次数 2 次。直接欧氏距离为：

```text
sqrt(20² + 2²) = sqrt(404) ≈ 20.10
```

消息长度几乎完全决定距离。**特征缩放**可用训练均值和标准差把字段转为相对偏离：`缩放值=(原值-训练均值)/训练标准差`。若长度差是 1 个标准差、历史差也是 1 个标准差，两项对距离的贡献才更接近。

均值和标准差只能从训练集计算。若先查看验证集再计算，会把评价数据的信息带入处理过程，形成**数据泄漏**。

## 缺失和新类别需要明确位置

消息长度缺失不能默认等于 0 个词。可以用训练中位数填补，并增加一个“原本是否缺失”的指示变量。前者让程序得到数值，后者保留缺失本身的信息。

渠道 `social` 在训练中没有出现，是**未见类别**。把它静默当作 `web` 会制造不存在的相似性；更稳妥的起点是使用“其他类别”位置或转人工处理，并记录发生频率。

## 相似不等于同类

距离只由选定表示定义。两条记录输入接近，标签仍可能不同；一个少见但正常的记录也可能离多数正常记录很远。因此异常或远距离不能自动解释为正类。

## 常见误区

- 所有数值直接放在一起，忽略单位和范围。
- 用全体数据计算缩放参数。
- 用 0 同时表示真实的 0 和缺失。
- 给类别随意编号后把编号差当作类别距离。
- 准确率提高就断言每条挑战记录处理正确。

## 何时适用，何时不够

近邻适合用小数据直观看表示如何改变相似性。数据很大、字段很多或相似含义不清时，它未必是最终模型；本课重点是表示选择，而不是推荐近邻用于所有任务。

## 换情境判断

商品相似度同时使用价格（元）、重量（千克）和品类。若直接计算距离，哪一项可能主导？新品类第一次出现时怎样表示？写出一个不能仅凭“距离最近”判断为同类的例子。
