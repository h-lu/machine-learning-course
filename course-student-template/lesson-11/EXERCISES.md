# 换一个输入检查理解

这些练习用于学习，按自己的卡点选择；答案和教师推导单独保留，不替代真实短信比较。

1. 用人工训练文本`["small box", "big box", "small bag"]`拟合词表，设置min_df=1、max_features至少为4，默认按行L2归一化。选择一个新输入`"big bag bag unknown"`，分别写出词频、每个词的训练DF和TF–IDF的非零坐标。最后再用程序核对。
2. 对同一个词表比较`"big box"`与`"box big"`。在当前拆词和计数规则下会得到什么？这个结果说明什么，不能说明什么？
3. 比较一个空文本和一个只含训练词表外新词的文本。追踪它们到分类器的输入；解释预测还受到什么影响。
4. 只改变`min_df`，检查一个训练稀有词是否仍在表示中。说明排除它可能减少什么，也可能损失什么；不要用开发集重新计算DF。
5. 选做：在自己的真实SMS比较中，再检查一个你关心的错误子组。给出子组样本数、两份同ID结果及限制；小子组改善不能自动推广到全部未来短信。

6. 把结论用到新情境前：若某TF–IDF方案在历史英语SMS的dev上优于几项人工计数，能否据此说它已理解语义，并直接用于今天的中文短信？分别说明当前证据支持什么，还需要哪些目标语言、时期、覆盖与效果证据。
