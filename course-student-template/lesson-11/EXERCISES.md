# 练习：换一个输入检查理解

前3题用于巩固概念，第4–6题任选拓展。正式两方案实验见 [README](README.md)。

1. 用 `small box`、`big box`、`small bag` 建立训练词表，设置 `min_df=1`、`max_features` 至少为4，使用L2归一化。对新文本 `big bag bag unknown`，写出词次数、训练DF及BoW/TF–IDF非零坐标，再用程序核对。
2. 比较 `big box` 与 `box big` 的向量和模型得分。哪一步丢掉了顺序？
3. 比较空文本与只含未知词的文本。它们进入分类器时是什么向量？此时概率由什么决定？
4. 只改变 `min_df`，观察一个训练稀有词是否留在词表中，并讨论保留和删除它的取舍。DF仍从train计算。
5. 在正式SMS实验中选择一个错误子组，报告样本数，按ID比较两种表示的预测，并解释改善或未改善的原因。
6. 若要把本课方法用于中文短信，需要重新准备哪些文本、分词规则和评价数据？列出一份简短验证计划。
