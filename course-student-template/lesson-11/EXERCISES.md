# 练习：先算清一个向量，再比较真实短信

第1—3题用于巩固概念，可以帮助完成README中的小检查；正式任务是两种表示的SMS比较。第4—6题为选做拓展。

## 1. 手算词袋和TF–IDF

训练文本只有三条：`small box`、`big box`、`small bag`。设 `min_df=1`、`max_features=4`，采用L2归一化。

1. 按字母顺序列词表，数出每个词出现于几篇训练文本。
2. 转换新文本 `big bag bag unknown`：先写原始次数，忽略不在词表中的词，再分别计算归一化BoW和TF–IDF。
3. 如果两个结果相同，检查非零词的DF和IDF，解释共同倍数如何被归一化消去。
4. 再转换 `big box`。这次两个词的DF是否相同？比较两种表示，让计算结果说明区别。

用SUPPORT中的小工具核对。新文本只转换，不加入训练集合重算DF。

## 2. 换词序

沿用第1题的词表，比较 `big box` 与 `box big` 的向量。它们进入同一个已经训练好的分类器时，得分为什么相同？本题无需另行训练分类器或编造数值系数。

## 3. 空文本与未知词

沿用第1题的词表，比较空字符串与 `unknown` 的向量。若向量全零，“特征值×分类系数”之和是多少？此时逻辑回归的概率由什么决定？

## 4. 词表大小（选做）

在正式SMS实验中只改变 `min_df`，检查一个训练稀有词是否被保留，讨论保留和删除的取舍。DF仍从train计算。

## 5. 看一个错误子组（选做）

选择一个明确的错误子组，报告记录数，按id比较两种表示。区分实际观察到的变化与可能原因；改善和未改善都可讨论。

## 6. 用于中文之前（选做）

如果改用于中文短信，需要什么文本、标签、分词规则和评价数据？写一份简短验证计划，不导入个人短信。
