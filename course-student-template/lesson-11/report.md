# 第11课：我的文字表示比较

## 1. 比较问题

说明选择哪两种表示、想检查什么信息，以及保持相同的实验条件。

## 2. 一条真实预测

从BoW或TF–IDF结果中选择一个dev编号，记录原文哈希、分词、未知词和非零坐标。手算一个坐标，并核对得分与概率。

## 3. 两方案结果

列出配置、运行命令和指标表。按ID比较预测，挑选有代表性的改变或错误进行解释。

## 4. 检查与结论

展示一次未知词、空输入或词序检查，给出保留或调整方案的建议，并说明数据和训练条件的限制。

## 5. 复现

列出程序、运行命令、结果路径和未完成部分，同步更新 `submission.json`。
