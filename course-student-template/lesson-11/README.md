# 第11课 · 同一条短信，换一种记法会怎样？

我们要从英语短信中找出可能的垃圾短信，交给人工复核。本课比较：把一条短信记成六个人工特征，和记成词向量，预测会有什么不同？

## 先看懂数据，再做比较

打开 `data/sms/dev.csv`，每行是一条短信。先看三列：`id` 是编号，`text` 是英文原文，`label` 是已有标签；`ham` 表示正常短信，`spam` 表示垃圾短信。例如 `sms-00004` 是一条正常短信。

- `data/sms/train.csv`：3877条训练短信，用来建立表示和训练分类器。
- `data/sms/dev.csv`：807条开发短信，用来比较两个方案。两次使用完全相同的记录。

两份文件都含标签。预测时模型只接收由英文原文变成的数字；dev标签用于事后核对预测。来源与其他字段见[数据说明](../data/sms/DATA.md)。不要导入个人短信。

先读[LEARN](LEARN.md)：从一条短信怎样变成六个数开始，再学习词袋、TF–IDF，以及怎样解释比较结果。

## 第一次动手：完成一个两方案示范

在前课已经使用的学生仓库根目录运行；若缺材料，先按[首次使用指引](../docs/LESSON11_UPDATE.md)取得：

```sh
python3 scripts/course.py start 11
python3 lesson-11/compare.py
```

程序用相同train/dev、相同逻辑回归训练设置，分别训练：

1. `first`：六个人工特征。
2. `second`：TF–IDF词向量。

结果在 `lesson-11/artifacts/comparison/`。先打开两个文件：

- `comparison.csv`：两行分别是两个方案，看找对多少垃圾短信、误选多少正常短信、漏掉多少垃圾短信。
- `paired_predictions.csv`：按相同id排好两套预测，`changed=1` 表示这条短信是否进入复核的决定变了。

再打开 `second/prediction_trace.json`，看一条短信的词怎样变成预测。完整操作、字段解释和示范数字见[SUPPORT](SUPPORT.md)。程序拒绝覆盖旧结果；再实验时换一个输出目录。

## 本课必做：完成两方案比较

选两种表示：人工特征 `manual`、词袋 `bow`、TF–IDF `tfidf` 中任选两种，至少包含一种词表示。可以沿用示范组合，但要自己完成以下分析，不能只交程序输出。

1. **解释一条真实短信。** 从词表示输出选择一个dev编号，对照原文说明分词和未知词；手算一个非零坐标，再核对各项贡献加截距如何得到得分与概率。
2. **比较两个方案。** 填写报告中的比较表，按id找到至少一条预测变化或错误记录，回到原文解释。保持数据划分、分类器、训练预算、阈值和复核容量相同。
3. **做一个小检查。** 在未知词、空文本、词序改变中选一种，验证表示保留或丢失了什么。
4. **给出建议。** 根据证据说明是否保留新表示。查准率高但漏选多，也需要纳入判断；新表示没有改善同样可以成为有依据的结论。
