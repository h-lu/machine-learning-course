# 第11课 · 同一条短信，换一种记法会怎样？

上一课把英语短信记成六个人工特征，再把概率转为复核名单。本课保持短信任务不变，研究模型得到概率以前的一步：原文怎样变成数字？

你要解释一种表示保留和丢失了什么，再用同一批开发短信比较两套表示方案。AI可以帮助理解、编程和分析，不要求提交对话记录。

## 1. 先学哪几件事？

[LEARN](LEARN.md)用三段人工文字说明固定词表、词次数、文档频率、IDF和L2归一化，再讨论未知词、词序和公平比较。小例没有垃圾标签，不是正式短信实验。

可以先看小例，也可以按问题回来查。[SUPPORT](SUPPORT.md)说明配置、结果和单条追踪；[HINTS](HINTS.md)提供遇阻时的可选提示。

## 2. 数据与工具

沿用第10课相同的历史英语SMS训练集train与开发集dev。词表、DF、IDF、人工特征均值和标准差只在train拟合，dev使用保存的转换。最终留出集仍留到第14课，不能用来选表示或参数。

本课工具支持六项人工特征、词袋计数BoW与TF–IDF。词表示可选择拆词、最低训练文档频率`min_df`、词表上限及归一化。正式程序先按训练DF筛选保留词，最终坐标写在`representation.json`的`names`中；真实追踪以这个列表为准，不用手算小例的位置猜测。

程序只需普通CPU和既有NumPy，不下载模型。原英文是模型输入，中文释义仅帮助阅读。来源、许可和划分见[数据说明](../data/sms/DATA.md)。历史英语短信结果不能直接代表今天的中文短信；不导入个人短信。

## 3. 课堂任务

先选择你想解释的现象，例如某类漏选、未知词多，或相近人工特征把不同文本记成同一点。再确定一项有依据的两方案比较；可以比较人工特征与词袋，也可以比较词袋与TF–IDF，不要求把所有组合跑完。

你要自主决定研究问题和表示选择，例如保留什么词、怎样拆词或是否加权。比较中保持train/dev记录、分类器类型、训练或调参预算、评价指标、阈值和复核容量相同，每套表示在train上分别拟合转换和分类器。

标准作品应包含：

1. 从所选BoW或TF–IDF一方完成一条真实dev短信的追踪：原文、tokens、词表内外词、几个非零坐标怎样得到，再核对贡献之和加截距、得分与概率。人工特征对照查看raw_value、training_mean、training_scale及标准化后的value；它不建立词表，没有DF/IDF，unknown_tokens为空也不表示词表完整覆盖。
2. 同条件两方案的配置、运行命令及结果。按相同ID对齐预测，比较复核人数、TP/FP/FN/TN、查准率、召回率；解释哪些记录改变或没有改变。
3. 一项未知词、空文本或词序改变的失败检查，说明表示没有保留什么信息。
4. 保留、修改或暂不采用的建议，以及历史语料、表示覆盖和训练预算的局限。

同样训练步数不代表双方都达到各自最优；相同正则系数也不保证有效复杂度相同。记录这些限制，不要求复杂表示胜出。有依据地保留原方案可以合格。

## 4. 从可运行的起点开始

先按教师提供的[第11课更新说明](../docs/LESSON11_UPDATE.md)取得新材料。在学生仓库根目录运行：

```sh
python3 scripts/course.py start 11
python3 lesson-11/analysis.py
```

默认只运行一份人工特征起点，结果位于`lesson-11/artifacts/baseline`。它不会替你选择第二方案、形成完整比较或写结论。

先读`representation.json`确认表示类型，再看`prediction_trace.json`的一条真实记录、`records.csv`的逐条结果和`summary.json`的指标。默认人工特征追踪给出原始值、训练均值和标准差，不会出现词次数、DF或IDF；正式作品要求的词表示追踪应从你所选的BoW或TF–IDF运行中取得。自己的设置从`config.json`另存修改，重跑用新的`--output`目录；旧结果不会被静默覆盖。字段与命令见SUPPORT。

## 5. 不同完成程度怎样选择？

- **基础练习**：核对三段人工文本的词袋、DF、IDF与归一化，解释未知词和词序信息。这不是完整正式作品。
- **标准完成**：完成上述四项证据，形成可复跑的两方案比较。
- **提高与拓展**：从[EXERCISES](EXERCISES.md)选择表示覆盖或敏感性问题，进一步诊断取舍；无需全部完成。

## 6. 怎样检查自己的证据？

一个词重复两次不等于DF增加两篇；IDF不是分类器系数或垃圾概率。真实向量的列序和训练来源应能核对，未知词不能临时接到既有分类器后面。

按ID比较同一批dev记录，不能把分别排序后的不同行相减。保存配置和数据哈希，说明计算预算、尺度与维数差异。开发结果用于选择，不能称为独立最终评价，更不能据此宣称模型理解了语言。


可用[report.md](report.md)作提示，也可以自定报告结构。教师开放本课后使用最终标签`v2-l11-final`；评分与修订制度保留。只运行起点或文件检查通过不等于完成分析。课末按教师开放场次完成A题、AI辅助学习和B题，无需另交AI对话记录。
