# 第11课 · 同一条短信，换一种记法会怎样？

上一课用六个人工特征表示短信。本课换一种记录方式：让模型看到词及其出现次数，再比较预测发生了什么变化。

## 本课怎么学

[LEARN](LEARN.md)从三段文字讲起，依次介绍词袋、TF–IDF、归一化和一条真实预测。完成小例后，选择两套表示作正式比较。操作查 [SUPPORT](SUPPORT.md)，遇到思路问题可看 [HINTS](HINTS.md)，拓展练习见 [EXERCISES](EXERCISES.md)。可以使用AI协助学习和编程，无需提交对话记录。

## 数据和比较条件

沿用第10课的历史英语SMS及相同 train/dev 划分。模型输入为原英文，中文释义用于阅读。来源和许可见 [数据说明](../data/sms/DATA.md)，请勿导入个人短信。

工具支持三种表示：六项人工特征、词袋计数（BoW）、TF–IDF。只需选两种，例如人工特征与词袋，或词袋与TF–IDF。

比较时保持训练/开发记录、分类器、训练或调参预算、评价指标、阈值和复核容量相同。每套表示都在train上拟合转换和分类器，dev用于比较；最终留出集留到第14课。

## 课堂任务

先选一个问题：人工特征漏掉了哪些词信息？常见词是否掩盖了差别？未知词怎样影响表示？再用两套方案检验你的想法。

报告完成四件事：

1. **追踪一条真实短信。** 从BoW或TF–IDF结果中选一个dev编号，展示原文、分词、未知词和几个非零坐标；手算一个坐标，并核对贡献之和、截距、得分与概率。
2. **比较两套方案。** 保存配置、运行命令和结果。按相同ID对齐，比较复核人数、TP/FP/FN/TN、查准率和召回率，并查看哪些记录的预测变了。
3. **检查一个边界情况。** 选择未知词、空文本或词序改变，观察表示保留或丢失了什么。
4. **给出判断。** 是否保留新方案？说明数据、词表覆盖和训练预算对结论的限制。

同样的训练步数比较的是固定预算下的表现；相同正则系数也未必对应相同复杂度。记录这些差别，依据结果作判断即可。

## 开始运行

在学生仓库根目录运行以下命令。若缺少本课材料，先按[首次使用指引](../docs/LESSON11_UPDATE.md)取得：

```sh
python3 scripts/course.py start 11
python3 lesson-11/analysis.py
```

这会生成一份人工特征基线，保存在 `lesson-11/artifacts/baseline`。接着另存 `config.json`、选择第二种表示，并使用新的输出目录运行。

主要看四份文件：

|文件|看什么|
|---|---|
|`representation.json`|表示类型和训练得到的转换参数|
|`prediction_trace.json`|一条短信怎样得到预测|
|`records.csv`|同ID记录的概率和复核结果|
|`summary.json`|整体指标|

人工特征的追踪显示原始值、训练均值和标准差；BoW/TF–IDF显示词次数、DF、IDF和未知词。正式任务的词表示追踪从后一类输出中选择。配置与命令见 [SUPPORT](SUPPORT.md)。
