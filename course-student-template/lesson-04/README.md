# 第04课（S02）｜收到的数据能代表全部记录吗

本课围绕**标签来源、独立复核、未知与真实零、覆盖和选择偏差**改进你的作品。你可以沿用已有问题、改变它，或自拟有依据的小问题；起点不是唯一方法菜单。先看想解决的卡点，再按需用[学习页](LEARN.md)、[支持](SUPPORT.md)与[开放代码工具](../docs/CODE_TOOLKIT.md)。本增强版不追溯增加已授课作业要求，不重算旧成绩或更改既有线上场次。

## 本课要解决什么问题

我想审查什么测量？代理和独立复核改变哪个判断？哪些时段代表性不足？什么外部证据能改变我的建议？ 贯穿资源是17,379条真实小时记录；也允许换有来源的数据与实现，只须说明本课关系为什么必要、数据能支持什么、怎样在当前资源检验。可以保留简单原方案、修改任务、交人工或有依据地暂不使用。

## 本课要学会什么

理解标签来源、独立复核、未知与真实零、覆盖和选择偏差；能追踪一条计算/记录，预计条件改变，构建合理替代并说明证据限制。[LEARN](LEARN.md)给通俗解释、不同小表的已完成例题与误区，例题不完成你的正式研究。

## 课堂任务

完成一件数据审查作品：标签来源/复核建议、真实记录覆盖与结论边界。自定需要研究的观测范围与目标定义；自己决定复核优先规则、容差、未知处理或覆盖审查方法中的至少两项。 这些选择要改变实验或结论，不能只换表述。AI可全程帮助，理解通过样本核算和换情境判断检验。

基本任务：用小例解释核心关系并使自己的程序实际读取数据。标准任务：在真实小时元数据上构建自己的覆盖审计，并借小表研究代理值/复核/延迟怎样改变建议。不能只抄全文件165这个数；要定位自选范围的证据与失败。 提高任务：将来源与复核建议同覆盖分析联结，评估补查优先级；或者换一份有来源的数据重新定义测量对象。 三层围绕同一作品，支持不单独计低分，不要求人人做完所有扩展或重复交三个作品。

## 完成步骤

**你的研究方案需覆盖这些证据，顺序由你决定：**

- 说明使用者、目标、预测/观测时点与实验前预计；保留至少两个重要决策及依据。
- 使用真实数据自行构建标准分析；以同用途下的合理替代作公平比较，记录变化与控制条件。
- 追踪具体记录/分组/计划，核算一项关键值，自己设计一次失败检查或条件变化。
- 据证据保留、修改或暂停，说明尚不能得出的结论；保存能重跑的程序与原/新结果。

检查边界：目标cnt记录租赁次数而非所有潜在需求；空字段、重复时点、缺整小时的检查不同；分母与自选范围一致；未观测不填0；独立复核一致也不必然正确。 本课不开模型目标评价；可审全文件日期/小时元数据，不输出封存目标统计。标签延迟/复核小表明确为人工模拟，不能称Bike实际复核结果。 不必沿SUPPORT顺序完成研究，它是按卡点选用的资源。

## 必须提交什么

提交自己的分析程序、配置/任务说明、实际结果与报告；报告格式可改，但问题/用途、数据来源、至少两个重要选择、公平比较、失败检查、核算和适用限制不能省。保留原方案与比较试验，见[练习资源](EXERCISES.md)。

默认submission仅列起点文件，**起点不构成项目完成**；你须把自己的科学结果加入/替换artifacts，并把run改成能重建这些文件的真实命令。完成实际研究后再标complete，学生仓库根可运行`python3 scripts/course.py check 04`及`python3 scripts/course.py ci`。CI核列出的文件字节；没有列入的比较另保存独立重跑命令。保留旧标签，增强复习是否另提交修订依教师安排。

## 不同起点怎么做

不清楚某关系时看LEARN的完整计算，不清楚代码/输出时按SUPPORT的卡点求助；先自己尝试，再看[分级提示](HINTS.md)。基础和提高都保留实质选择。可自主换题/数据/方法/表达，只需保持本课主要关系与证据；不按模型数、代码量、AI对话长度或复杂外观加分。

## 运行限制

使用已准备的Python与NumPy，命令示例为本机`python3`；你原环境若使用`python`或`py`，统一用已经成功的启动命令，不安装新环境。默认起点离线读取`data/bike/hour.csv`，只准备审计/样本预览，不能作为正式分析已完成证据。AI可帮助提出问题、写代码、核算和解释，不收集prompt记录、不要求所有人同路线或强制逐人答辩。

数据/依赖错误保留命令、工作目录和完整报错；先用不同数据的完整小例继续理解，明确写未实跑，再找教师修复。显式输出已存在拒覆盖，换新目录保留旧证据。默认`artifacts/starter`可重算。学生正式程序与输出由自己确定；submission.json的run必须真实重建其artifacts中列出的科学结果。比较试验若未列入CI，另保存配置和独立重跑命令，不宣称CI全核。

本课不开模型目标评价；可审全文件日期/小时元数据，不输出封存目标统计。标签延迟/复核小表明确为人工模拟，不能称Bike实际复核结果。 数据来源、字段/时间边界和许可见[data/DATA](data/DATA.md)。普通CPU离线，概念检查与AI接入由教师安排；不能将不可用资源藏到必做要求。
