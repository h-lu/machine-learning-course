# 第04课（S02）｜收到的数据能代表全部记录吗

## 从哪里开始

少了一小时的记录，能不能把租借次数填成0？请先在[学习页](LEARN.md)用24小时与22条记录的小例子判断，再检查真实单车资料里哪些时段没有被记录。本课还会区分原始测量、代用数值和独立复核。

**2026-10-09 新版教材；已完成前七次作业无需重交。**

本页说明正式项目要完成什么；[学习页](LEARN.md)讲概念和手算，[操作支持](SUPPORT.md)帮助读取数据、运行和保存结果。已完成的作业与评分仍按原安排。

## 本课要解决什么问题

表里记录的数，是否就是你真正想预测的数？某些小时没有记录，是否会影响结论？本课先检查测量与覆盖，再讨论值得补查什么。

正式项目使用17,379条单车小时记录。你可以选择一个时期或时段，检查应有多少条、实际有多少条、具体缺在哪些时点；再用学习页的小例说明怎样复核测量。若改用其他数据，应交代来源，以及它怎样支持同样的问题。最后根据结果提出保留、修改、缩小用途或暂不采用的建议。

## 本课要学会什么

能区分实际测量、用于近似目标的数值，以及独立复核的结果；能算清记录覆盖比例，解释“没有记录”为什么不等于零。用一条具体记录核算，再说明现有资料还不能回答什么。

[学习页](LEARN.md)提供完整手算例子；它们用于理解，正式任务仍使用你选定的数据与方案。

## 课堂任务

完成一份数据检查报告，说明标签来自哪里、哪些记录没有被覆盖，以及这些问题怎样限制结论。你需要自行确定检查范围和目标，并至少作出两个有理由的选择，例如优先复核谁、允许多大的测量差异、如何报告未知值或怎样检查覆盖。

AI可以协助实现；你需要核对具体记录，并说明为什么这样选择、结果支持什么。

**基本任务：**用小例解释核心关系并使自己的程序实际读取数据。

**标准任务：**用真实记录的日期、小时和编号等元数据构建自己的覆盖检查，并借小表研究代理值/复核/延迟怎样改变建议。不能只抄全文件缺165条小时记录这个总数；要定位自选范围的证据与失败。

**提高任务：**将来源与复核建议同覆盖分析联结，评估补查优先级；或者换一份有来源的数据重新定义测量对象。 三类任务围绕同一件作品。使用支持材料不影响评价；不要求人人做完所有扩展或重复交三个作品。

## 完成步骤

下面几项都需要在报告中说明，可以按自己的分析顺序组织：

- 写清谁使用结果、想解决什么问题、预测或观察发生在什么时候，以及运行前预计会看到什么。解释至少两个重要选择的理由。
- 用真实记录完成分析，再与另一种适合相同用途的方案比较。说明改了什么、哪些条件保持不变。
- 从具体记录或分组中独立核算一个关键数字，再检查一种可能失败的情形，或改变一个合理条件观察影响。
- 根据结果建议保留、修改或暂停方案，说明还不能得出哪些结论。保存代码与比较前后的结果，让别人能够重新计算。

检查边界：目标cnt记录租赁次数而非所有潜在需求；空字段、重复时点、缺整小时的检查不同；分母与自选范围一致；未观测不填0；独立复核一致也不必然正确。 本课不评价模型对租赁次数的预测；可审全文件日期/小时元数据，不输出封存目标统计。标签延迟/复核小表明确为人工模拟，不能称Bike实际复核结果。 支持材料按问题选用，不要求沿固定顺序完成研究。

## 必须提交什么

提交自己的分析程序、配置/任务说明、实际结果与报告；报告格式可改，但问题/用途、数据来源、至少两个重要选择、公平比较、失败检查、核算和适用限制不能省。保留原方案与比较试验，见[练习资源](EXERCISES.md)。

默认的`submission.json`只列出起点结果，**运行起点代码不等于完成项目**。完成自己的分析后，把结果文件路径写入`artifacts`，替换或补充原清单；把`run`改成实际能够重新生成这些文件的命令。

完成研究后，才把`status`改为`complete`。在学生仓库根目录运行`python3 scripts/course.py check 04`及`python3 scripts/course.py ci`。CI（自动检查）会重新运行命令，核对清单中结果文件的内容是否一致；它不判断结论是否正确。未列入清单的比较试验须另存重跑命令。

保留原来的提交标签。是否需要提交复习后的修订版，按教师通知执行。

## 不同起点怎么做

概念不清楚时，先看LEARN中的手算过程；程序或结果看不懂时，查SUPPORT对应问题，也可以看[提示页](HINTS.md)。先完成基础理解和标准任务，再选与自己作品有关的扩展。可以自行选择题目、数据、方法和呈现形式，但要回答本课核心问题并提供依据；不因模型更多、代码更长或AI对话更多而加分。

## 运行限制

使用已准备的Python与NumPy，命令示例为本机`python3`；你原环境若使用`python`或`py`，统一用已经成功的启动命令，不安装新环境。默认起点从学生仓库根目录的`data/bike/hour.csv`离线读取数据，只准备文件检查和样本预览，不能作为正式分析已完成证据。AI可帮助提出问题、写代码、核算和解释，不要求提交提示词记录、不要求所有人同路线或强制逐人答辩。

遇到数据或软件报错，保存执行的命令、当前目录和完整报错。可以先继续手算学习页例子，并在报告中写明程序尚未成功运行，排查后再补跑。用`--output`指定的目录若已存在，程序会拒绝覆盖；请换新目录保留旧结果。不指定`--output`时，默认的`artifacts/starter`允许重新生成。正式程序和输出由你决定；`submission.json`中的`run`必须能重新生成`artifacts`列出的分析结果。未列入清单的比较试验，另存配置和重跑命令。

本课不评价模型对租赁次数的预测；可审全文件日期/小时元数据，不输出封存目标统计。标签延迟/复核小表明确为人工模拟，不能称Bike实际复核结果。 数据来源、字段/时间边界和许可见[data/DATA](data/DATA.md)。程序可在普通CPU上离线运行；课堂选择题和AI访问按教师安排。遇到资源无法使用的情况，请保留说明并向教师反馈。
