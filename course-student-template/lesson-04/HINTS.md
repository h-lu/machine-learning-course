# 第04课分级提示（按需）

先写自己的问题和预计；如果卡住再选择以下方向，不必逐条完成。

1. 核对象：标签来源、独立复核、未知与真实零、覆盖和选择偏差中你到底在比较哪个量？用LEARN小例区分它与相近概念。
2. 核证据：不知道缺什么时，比较“应有时间集合”和“已记录集合”；不知道目标含义时，从租赁次数与未成功请求是否被记录区分。
3. 核边界：目标cnt记录租赁次数而非所有潜在需求；空字段、重复时点、缺整小时的检查不同；分母与自选范围一致；未观测不填0；独立复核一致也不必然正确。
4. 核建议：如果两条合理路线结论不同，哪项检查最能区分原因？可以保留原方案；当前没有证据的条件写未知。

这里不提供正式研究的答案或正式选择题答案。
