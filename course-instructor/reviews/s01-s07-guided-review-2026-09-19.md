# S01–S07 初学者模拟冷读与分层支持复核

## 范围和方法

基于 `93b5bdc99802170e2884e4d9535beebe80b28317`，对 `lesson-03` 至 `lesson-09` 的学生 README、LEARN、数据说明、报告、配置与输出按顺序阅读。模拟对象已接触 C01–C02，但不会独立写训练代码、并不熟练使用 JSON 或 Git。先只用学生页面完成操作，再对照源码、教师参考与概念题核对。

这是模型模拟冷读、文案审查与实际命令演练，不是真人学生实验，没有招募参与者或测量学生完成时间。本次不合并 main、不部署服务、不切换课堂题库。

S01–S06 继续使用已重写的问题与评价模块。S07 本轮保留旧版多元线性回归实验，只重写阅读指导并补充结果表；没有把它宣布为新地图“简单模型与复杂模型”全部内容的实现。

## 发现的问题与直接修改

| 位置 | 冷读障碍 | 修改与核对方式 |
|---|---|---|
| 七课的入门分层 | “使用现成程序”没有说明该做什么，且容易以为五层都要完成 | 每课首屏链接独立 SUPPORT.md；明确支持路径可完成 Core，其他层为选做；不因使用支持设置分数上限 |
| 第一次运行 | 需要先抄改 JSON 并在很多输出字段里自己找重点 | 提供起始与单因素对照配置；逐步给目录、命令、文件、列、编号和手算例子 |
| S01 预测与行动 | 把提醒阈值当作模型参数，或把提醒数解释为效果 | B05 核对预测3、实际8；阈值8改10使线性模型提醒3变1但预测/MAE不变 |
| S02 标签审查 | 零、未知和不同日期的分母混淆 | 第4天4/8有标签、均值5；第7天7/8、均值43/7；明确大于分歧阈值才计入 |
| S03 数据划分 | 切换主显示方案不等于真正改变划分；用最低MAE选划分 | 对照将时间截止4改3，训练12变9、验证6变9；保留测试集不进入开发；按未来对象解释而非按分数排名 |
| S04 指标与后果 | MAE解释漏写先求和；非对称损失与预测变化混为一谈 | 修正公式叙述；权重3改1，预测与提醒不变；自己的容量检查核对误报漏报及分母 |
| S05 抽样 | “优先补晚间”被误当通用算法；样本数被当有效信息量 | 明确具体优先规则，不冒充随机分层抽样或主动学习；同预算核对新增样本、时段与标签来源 |
| S06 修订 | 把两种候选连改后误称单因素；最终测试覆盖选择证据 | 两种候选分别对照同一原方案；核对训练均值13/9；验证配置与结果另存后才用测试集 |
| S07 术语与材料衔接 | x1/x2没有情境和单位说明；把前课分钟沿用；只有嵌套JSON | 明确两个无量纲特征、多元回归与系数；新增比较、逐条残差和人工外推CSV，保留原计算 |
| S07 残差与正则化 | 不区分残差符号与绝对误差，惩罚越大被理解为越好 | 使用真实值减预测值；S07-000预测约2.783197、残差+0.175263；ridge10的MAE反而大于ridge0 |
| S07 时间安排 | 课堂写15分钟概念题而旧服务实际10/15/10，共35分钟 | 学生和教师同步按现行35分钟记录；不偷偷改题库时长；真实课堂可完成性仍待验证 |

通用规范同步要求：入门路径应给出第一项具体动作、准备好的材料、输出核对、单因素对照、自己的判断、报告提示与失败支持；不能只写“让AI解释”或“运行示例”。工具操作的帮助不取消机器学习理解，支持路径也不是额外作业。

## 术语与文字

使用样本、特征、目标值、训练集、验证集、测试集、基线、数据泄漏、残差、多元线性回归、岭回归和缺失值填补等通用名称，并在需要时解释。标签覆盖率明确为本课定义的统计量，优先补某时段明确为本课选择规则，避免把课程自定义指标或策略包装成通用算法。

概念对照 [Google 机器学习术语表](https://developers.google.com/machine-learning/glossary)、[scikit-learn 线性模型](https://scikit-learn.org/stable/modules/linear_model.html)、[缺失值填补](https://scikit-learn.org/stable/modules/impute.html)和[常见错误](https://scikit-learn.org/stable/common_pitfalls.html)。本课小计算由实际数据重算；这些来源不是课堂效果实验证据。

## 尚不能证明什么

命令通过不代表学生已经理解，也不证明所有初学者能在90分钟完成。仍需真人试读观察学生是否找到第一项任务、理解分母与单位、提出自己的理由并保存结果。自动测试不评价报告的推理质量；服务部署与旧题库场次隔离仍按原发布要求处理。
