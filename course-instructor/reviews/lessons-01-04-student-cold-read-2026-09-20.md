# 第 01–04 课学生冷读与操作记录

## 方法

从 `course-student-template` 的全新副本开始，按学生实际顺序阅读每课 README、SUPPORT、LEARN 和数据说明，再照做入门路径。检查对象是第一次接触本课、不会自行修改程序的学生；这是模型模拟冷读和命令演练，不是真人试教，也不把本次运行时间当作课堂完成时间。

## 实际操作

以下命令在全新副本中成功运行，并生成文档指定的结果文件：

- C01：`scripts/course.py start/run 01`、规则斜率对照和新人数检查；
- C02：验证集起点、规则参数对照和验证结果保存；
- S01：`config-start.json` 起点、提醒阈值单因素对照和个人配置；
- S02：第 4 天起点、第 7 天标签可见性对照和容差检查。

四课都能找到指定样本、按单位和分母重算示例，并区分没有标签的新输入、未知标签和真实的 0。运行结果与 SUPPORT 中给出的数值一致。README 中的链接均能在仓库内找到。

另从第二份全新副本模拟提交：逐课执行 `start`、`run`，在完成报告和结果后把 `submission.json` 标为 `complete`，四次 `scripts/course.py check` 均通过；随后暂存四课材料和被默认忽略的结果目录，创建学生提交并推送到一个新的空 Git 远程仓库。这个测试证明本地提交链路可运行，不代表任意 Gitea 账号都已有仓库写入权限。

## 冷读中发现并已修正

1. 第 03 课 SUPPORT 前面把起点结果写到 `artifacts/support-start`，后面比较时却写成打开 `original`。已统一为 `support-start`，避免学生按文字寻找不存在的目录。
2. 第 01 课 LEARN 追加背景字段说明时重复使用“第 6 节”标题。已改为第 10 节，避免目录和阅读顺序混乱。
3. 第 04 课 SUPPORT 原先把“来源质量”放在操作流程之后，且说明中提到的 `record_source`、`review_source` 和 `clock_quality` 没有出现在生成的 `records.csv`。已将来源检查移入运行流程，并让分析结果保留这三列；同时补充 `split_plan` 的含义，明确它是本课的日期对照安排，不是训练集、验证集和测试集划分。
4. 第 04 课 README 首屏没有明确提交文件和运行失败时的处理方法。已补充报告、最终配置、三份结果表的提交要求，以及保留报错并标记“尚未运行”的补做办法。

## 保留的设计判断

- C01–C02 的题目和基础任务保持不变；新增的背景字段只作为“可能的解释”练习，默认规则和模型没有偷偷使用它们。
- S01–S02 的标签来源、缺失值、分母、标注分歧和选择偏差在题目与实验中使用同一套数字。
- `scripts/course.py check` 在学生还没有填写 `submission.json` 为 `complete` 时会明确提示未完成，这是提交前检查，不是运行失败；材料已在前文说明先保存报告、结果和配置，再改状态并检查。

## 验证范围

- 四课入门命令和单因素对照已实际执行；结果文件存在且可读取。
- 学生模板测试、结构检查和课程验证在本轮改动后重新运行。
- 本次冷读不能证明真人学生一定能在 90 分钟内完成，仍需真人试读观察。

本轮再次从学生模板副本冷读第 04 课，并实际运行 `config-start.json`、`config-support.json` 和只改容差的个人配置。第 4 天结果为 4/8、均值 5 分钟、覆盖率 50%；第 7 天结果为 7/8、均值约 6.143 分钟、覆盖率 87.5%；容差改为 3 后 A04 不再标为分歧。三份 `records.csv` 均包含来源质量列，结果与页面说明一致。

## 2026-09-21 再次冷读：文字与概念题

这次先不看教师答案，只按学生入口阅读 README、SUPPORT、LEARN 和数据说明，再模拟三种起点：入门学生沿 SUPPORT 逐步操作；能够独立运行命令的学生完成 Core 并解释两个分母；已有数据分析经验的学生完成 Upgrade，按 A、B 窗口拆分覆盖率并判断整体覆盖率是否足以支持代表性结论。三条路径都能找到下一步动作、预期结果和提交证据；Upgrade 增加的是分组比较和来源优先级判断，没有把新的模型或后续课程概念偷偷放进必做任务。

概念检查的 A 版逐步检查目标值与代理标签、缺失与真实零值、分歧容差、标签到达时间造成的可见子集变化，以及 AI 标签的独立核对；B 版分别换成视频完成率、设备维修工时、图片分类、满意度调查和自动生成标签，考查同一关系在新情境中的迁移。模拟作答结果为 A 5/5、B 5/5；另模拟把 A02 答错后，系统应显示 A 需要复习而 B 可以单独保留，符合 A/B 分开评价的设计。题目、选项、解释和学习说明使用目标值、标签、代理标签、缺失值、标签覆盖率、标注分歧、选择偏差和独立核对等标准机器学习术语，并在题干中提供计算所需的分母或时间条件。

本轮主要修改 README 的连贯性：把原来连续的短句改成带有“为什么做—怎样做—看什么—能得出什么”的完整段落，补充命令读取的文件、结果变化的原因和报告需要保留的证据。SUPPORT 与 LEARN 的数值、字段名和题库解释未发现矛盾。模拟冷读和本地命令测试不能替代真人试教，因此仍需观察真实学生是否能在规定时间内完成。
