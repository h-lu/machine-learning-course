# C01–C02 初学者模拟冷读与修订

## 范围与方法

基线提交为 `c557c9021af81603c5ef9a6ef1090d1c3566dea1`，提交前合入该分支并发更新 `021a9441245333224bc5a3a13fa656196ff311b5`，保留新报告模板、教师设计和发布记录，并修正其中误写成可见字符的段落换行。修改保存在 `course/intro-c01-c02`。这是模型模拟冷读和实际命令演练，不是真人学生试读；没有招募参与者，也没有测量学生完成时间。

## 发现的问题和修改

| 阅读或操作位置 | 原来的障碍 | 修改 |
|---|---|---|
| 第一次打开学生仓库 | 先读整份术语表、运行目录和依赖准备不明确 | 改为先读当课情境，新增 FIRST_RUN 操作指南，术语表按需查阅 |
| 修改配置与填写任务 | 默认学生会另存 JSON、知道六个英文字段及完成状态的含义 | 提供完整配置副本、标点规则、字段对照、格式检查与报告提示替换说明 |
| C01 从术语到计算 | 参数、截距、斜率和绝对误差尚未解释；汇总先显示 MAE | 学习卡补最小解释，终端先显示一条可手算预测；说明 null 不代表零 |
| C02 学习顺序与示例表 | 先用训练集算基线，再解释训练集；表格缺输入人数 | 先解释三份数据用途，表格补齐人数和单位，区分拟合用平方误差与评价用 MAE |
| C02 的晚间结论 | 将简单基线与默认人工规则混用，好像换回规则就能修复回归错误 | 指明默认规则与回归预测相同；晚间误差为零的是均值基线，但一条样本不支持推广 |
| C02 修改后的读取 | MAE 相同可能被误认为参数没生效；终端只突出回归指标 | 同时显示方法名、MAE、单位和分组样本数；核对逐条预测，说明默认指标不是推荐 |
| C02 验证与测试 | 切换测试集可能覆盖验证材料，重算仅给参数片段 | 分开保存各次配置与结果；保留 config-validation.json，给出两阶段完整命令 |
| 输入错误与旧输出 | stress_queue 报错却指向 queue_length，旧文件易被误当新结果 | 报错指明实际配置字段；JSON 错误给文件及行列；提醒失败后旧输出不算新结果 |
| 提交 | artifacts 被忽略，照原 git add 命令会漏交结果 | 给出两课各自的 git add -f 命令，核对暂存文件；从本地新克隆验证重跑 |

通用编写标准补入初学者阅读顺序、命令与结果逐项对应、保存及提交检查，并要求区分模拟冷读和真人试读。保留社区术语，没有用自造名称替代训练集、验证集、测试集、基线、回归和 MAE。

## 仍需真人试读

命令跑通不能证明初学者会在 90 分钟内完成。仍需观察真实学生能否在没有口头补充的情况下找到运行目录、解释一条预测、区分三种方法、保存验证结果并提交文件。自动测试不评价学生的推理质量，不据此宣布课包完成教学验收。
