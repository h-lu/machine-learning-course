# S13–S18 预训练模型复用模块：模拟冷读与命令验收

## 范围和方法

本次把新地图 S13–S18 落到学生 `lesson-15` 至 `lesson-20`，并同步教师 `lessons/S13` 至 `S18`。受检工作区基线为根仓库 `8c07136`、学生仓库 `d72bfd8`、教师仓库 `8c1bd8a`；这些是修改前基线，最终受检提交需在合并后补记。本次环境为 Python 3.14.4、普通 CPU、无网络和无模型服务。

冷读只先使用学生 README、SUPPORT、LEARN、数据说明、配置和程序，不查看教师答案。顺序为 README 首屏 → SUPPORT 第一项 → 按需阅读 LEARN → 实际执行命令 → 打开指定 CSV 行 → 做单因素配置 → 运行 final → 填写模拟报告和任务说明 → `scripts/course.py check/run`。随后才核对教师参考和 A/B 题。这里的“学生”是模型模拟视角；没有真人参与，不能把命令成功写成真实学生已经掌握或能在 90 分钟完成。

## 连续作品和每课实际操作

六课使用同一个“离线课程问答助手”，但每课只增加当前需要的关系。

| 课次 | 第一个可执行动作 | 实际生成并核对的证据 | 个人单因素或新输入 |
|---|---|---|---|

| S14 | 画可见位置后运行遮罩实验 | attention weights、因果/无遮罩前后输出 | 未来 value 改为 6，只改一个值 |
| S15 | 在开发问题上运行原提示 | 三次响应、问题数和四项比例 | 删除“先写依据”要求，生成匹配新输出；锁定后运行 final |
| S16 | 数检索词重合并运行阈值 1 | retrieval、answers、failure stage | 新增“程序运行能否证明理解”查询并重跑；再运行 final |
| S17 | 相同 6 案例比较提示/上下文 | 任务、支持、格式、参数/资料/样例/时间元数据 | 改为上下文与参数两个固定候选 |
| S18 | 手算 dev-01/A 加权总分 | 四维度、两位评分、分歧、顺序 proxy | 提高事实和支持权重，锁定后运行 final |

fresh-copy 演练覆盖每课 start、support、personal、需要时 final、默认 artifacts、提交文件检查和默认入口重跑，全部成功。六个默认入口各约 0.02 秒；这只是程序运行耗时，不是课堂用时。

## 冷读中发现并修正

1. S16 的复制命令原先只写 `cp`，Windows 初学者可能停住。已补文件管理器复制和编辑器“另存为”的等价做法。
2. S16 原先写“选好阈值后运行 final”，没有明确把所选阈值写入 final 配置。现已补充保持 `evaluation_split=final`、复制采用的 `min_overlap` 后再运行。
3. 六课命令原先并非每处都重复说明执行目录。README 和 SUPPORT 现统一说明在能看到 `scripts` 与本课目录的仓库根目录运行，不能在 `>>>` 中输入，并说明 `python3` 替换办法。
4. 独立脚本最初会让 JSON 字段错误直接产生 Python 追踪信息。现捕获常见读取和字段错误，提示检查配置、数据和旧输出；明确旧输出不能证明本次成功。
5. 输出中的来源路径最初可能包含克隆绝对路径，导致新副本重跑哈希不同。现只保存文件名与内容摘要，默认产物在全新副本可逐字重建。

通过：

```text

python3 -m pytest -q course-student-template/tests/test_pretrained_module.py
```

结果分别为学生 32 课 0 项、教师 32 课 0 项、专属回归 8 passed。专属回归覆盖单字段配置、参数更新范围、因果遮罩、提示新输出、检索/回答失败、未知固定路线拒绝、评价顺序和新副本确定性重建。

共享 `tests/test_runtime.py` 与 `course-instructor/scripts/validate_reference_coverage.py` 仍硬编码旧 S13–S18 的网络、卷积、固定表示、注意力和微型 Transformer 数据结构；教师 `reference/S13` 至 `S18` 也仍是旧变体。按照并行改造的范围约定，本次没有修改这些共享文件。全量旧学生测试同时受正在改写的 S07–S12 影响；本轮记录到 95 passed、6 failed、10 errors，不能将该结果称为完整通过。根任务需统一迁移共享验证后再运行 `tools/validate_course.py`。

## 仍需真人验收

模拟冷读证明页面给出的路径和数字能接起来，不能证明不同基础学生在 90 分钟内完成。真人试教需要分别记录：首次找到结果、完成手算、作出个人选择、解释证据边界、完成概念题和提交所用时间；还要观察学生是否把规则生成器、人工注意力值、固定候选或模拟评价器误写成真实大模型能力。发现这种误写时，应先调整讲解和材料，再决定是否正式切换该模块。
