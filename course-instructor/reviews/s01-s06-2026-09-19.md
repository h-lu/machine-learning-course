## 先按学生页面阅读

检查六课情境、术语与计算的先后，逐个运行 README 的原始命令和 JSON 配置副本。保留原始与试验输出，核对分母、样本编号和单位，再检查 task/report/submission 的保存及新副本重跑。第一遍不依赖教师答案补全操作；之后用教师参考和独立计算核对。

发现并修正：S06 已知训练人数之和应为 13 而非 12；均值填补为 13/9。S03 的三种开发划分必须先排除同一批保留测试行，且不同验证对象不能按最低误差排名。S02 未知标签与零分开，截止日不能早于该审查批次最晚的事件日期。S06 验证配置与结果另存，再进行最终测试，不覆盖选择依据。每课参数副本完整给出，实际 `artifacts` 保存也纳入命令演练。

## 验证记录

本地 Python 3.13.5、NumPy 2.3.5。实际执行 `python tools/validate_course.py`，学生测试 **67 项**、检查器与服务测试 **41 项**、教师状态测试 **8 项**全部通过；32 课教师变体的 **53 项独立检查**通过；学生、教师和规划严格检查均为零问题。另运行 `PYTHONPATH=ml-check python -m pytest -q ml-check/tests`，41 项通过。

新增模块测试 22 项，覆盖标签截止日与未知值、三种划分的测试隔离、非对称误差、容量与标签隔离、抽样预算、单因素修改、数据重建、六份 README 配置与命令，以及把结果显式加入 Git 后从新的本地克隆重跑。另新增 5 项服务测试，覆盖 30 个概念及 60 道题、源文件同步、阶段时长、两种公开读取路径不返回答案。

对本地基线逐项比较，C01–C02 和 S07–S30 的汇集题库对象完全一致；它们的学生学习卡和原始数据未重写。没有覆盖旧作业或改动成绩权重。新增表格输出保留原运行接口，自动运行结果仍为 `example_only`。

这次数据、配置、问题和正文的格式与本地链接均经严格检查；`git diff --check` 无问题。最终远程提交仍须核对树哈希和该提交的只读 Actions 结果，不能借用上一批 CI。
