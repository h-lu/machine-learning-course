## 新目标与历史材料的对应记录

“目标课次”指当前学习地图；“旧课次”指固定提交 84aa171 中的历史材料，而不是当前同编号文件。下表保留重组来源，便于教师追溯哪些机制被复用、哪些缺口已经在新课包中补齐。它不是当前入口清单，也不能用来混搭新旧课包。

| 目标课次 | 新目标（与目标地图一致） | 可参考的旧课次 | 必须补齐或重新核对的内容 |

| C02 | 一个结果能说明方案有用吗 | C02、S01 | 沿用 C01 作品加入替代路线、用途评价和具体失败，不另起无关示例 |
| S01 | 怎样把模糊需求变成可研究的问题 | S01、C02 | 同一小数据运行两种处理办法，区分预测关联与行动的因果效果 |

| S04 | 什么算做好了，失败会造成什么后果 | S04、S05 | 在同一结果上比较用途不同的评价与工作量，保留关键小计算 |

| S07 | 简单模型与复杂模型各自假设了什么 | S07、S09、S10 | 选两个代表性模型作公平比较，不堆三套算法；补泛化与成本解释 |

| S09 | 数据怎样表示，模型才容易使用 | S06、S11、S12 | 固定评价比较两种表示，覆盖缺失、新类别或少见正常输入 |

| S14 | 输入怎样影响模型能够利用的信息 | S17、S18、S19 | 保留可查看数值的遮罩实验，改变未来词元核对较早输出，不以黑箱回答证明机制 |
| S15 | 提示改进了，还是只适配了见过的例子 | S21、S20 | 需接收学生新提示的离线生成方案、重复输出与未见例子；旧缓存不足以发布 |
| S16 | 怎样补充资料，而不是期待模型猜对 | S22、S23 | 让生成接收实际检索结果，分别评价检索和回答，缓存失配明确无结果 |
| S17 | 该改提示、补上下文，还是改参数 | S16、S21、S23 | 新增同一任务的两条适配路线比较，区分更新与输入变化，不宣称未执行的微调 |
| S18 | 没有唯一答案时，怎样判断真的变好了 | S20、S21、S23 | 补开发样本校准评价、争议与顺序偏差、独立最终样本，避免生成评价自证 |
| S19 | 怎样把任务拆成模型、程序和人的协作 | S23、S24 | 新增真正可修改的分步流程与中间产物，比较直接生成，不只分析已有答案 |
| S20 | 什么时候应调用工具，而不是继续生成 | S24 | 旧课偏应用测试；需新增实际本地工具调用、参数校验、返回值核对和失败处理 |
| S21 | 固定流程还是由模型选择下一步 | S26 | 仅可参考环境定义；动态决策来源、轨迹和预算需新建，规则模拟不算模型决策 |
| S22 | 输入里的指令可以改变系统职责吗 | S24 | 在无真实副作用环境测试权限和干扰，核对实际动作而非仅看回答承诺 |
| S23 | 多步方案失败，应该先改哪一步 | S22、S23、S24 | 新建分步与整体评价，替换一个步骤定位错误，后续使用改变后的输入 |
| S24 | 怎样用下一项实验改进整件作品 | S30 | 旧课仅供成果表达参考；用新 S19–S23 作品完成端到端改进与新检查 |
| S25 | 反馈怎样帮助学习，又会遗漏什么 | S25 | 补只观察已选行动的偏差，比较多次回报与覆盖，不能把反馈样本当完整人群 |
| S26 | 一个好分数会不会鼓励错误行为 | S26、S27、S28 | 复用小环境，重点比较状态或奖励改变后的长期行为；完整算法推导不是前置要求 |

| S28 | 更高效果值得多少等待和计算 | S10、S20 | 增加实际测量与重复比较，分开估算、推理、缓存重放和新方案生成 |

## 按批次落实与核对前置知识

以下顺序是编写与验收建议，不是已确定的课堂切换日期。每批都需学生任务/LEARN、数据/代码、教师运行单/参考、五知识点与 A/B 题，以及发布验证成套完成。

| 批次 | 新目标范围 | 切换前必须具备 | 本批需要留下的作品证据 |
|---|---|---|---|
| 入门 | C01–C02 | Python、Git 与运行支持已准备；不要求机器学习前置课程 | 一件最小作品的实际运行、单条核对、替代路线与第一次比较 |
| 问题与评价 | S01–S06 | 入门运行、输入输出和基本比较；数学例子随课补充 | 同一任务的数据、评价或目标修订，及一个区分原因的实验 |
| 学习与泛化 | S07–S12 | 训练/开发/测试、数据含义和指标用途已掌握 | 表示或学习方法的比较、一次参数更新与失败诊断 |
| 模型复用 | S13–S18 | 参数更新、概率、表示、泛化与公平比较 | 输入/参数改变的区分、提示新输出与校准后的独立评价 |
| 组合方案 | S19–S24 | 上下文、检索、生成评价，以及可用的生成与工具资源 | 一条真实可修改的流程、中间产物、权限检查与端到端迭代 |
| 反馈与迁移 | S25–S30 | 已有可复核作品、流程评价及条件变化检查 | 探索/奖励实验、监测恢复、成本比较与新场景重新评价 |

优先交付入门 C01–C02，不以一次重写 32 份标题替代完整小批次。新 S05、S13、S15、S17–S24 等目标不能只靠旧文件拼接；所需资源不足时暂缓切换。每次发布按班级明确实际材料提交、题库版本和前置支持，不能将相同编号的新旧模块任意拼接。

编写方法见[课程设计](COURSE_DESIGN.md)，切换与服务版本限制见[发布说明](RELEASE.md)，计分继续使用[评分规则](GRADING.md)。
