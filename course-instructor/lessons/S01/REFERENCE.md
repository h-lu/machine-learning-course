# S01 教师参考：比较依据，不规定唯一答案

## 最小计算

默认数据为人工教学样本，配置见学生目录。下列数值只用于独立核对起步实现，不是学生评分目标：

```json
{
  "n": 6,
  "mae": 2.5555555556,
  "rmse": 2.6874192494,
  "asymmetric_loss": 2.5555555556,
  "alerts": 3
}
```

先从原始样本及 `records.csv` 重算对应数量，再和汇总比较。参考脚本对本课采用不同配置，并检查训练隔离、统计分母或实际选择；不能只调用被测函数，再用其自身返回值证明正确。

## 两条合理路线

**只提供粗略分钟估计。**比较规则或基线，强调简单和可解释，不声称提醒效果。

**继续研究提醒办法。**明确阈值和用途，提出将来收集行动后结果的计划；本课不执行真实干预。

学生可以更换这些路线。评价的是用途、比较、失败检查和结论的关系，不奖励采用参考模型，也不因候选没胜出而扣学习质量分。

## 容易误判的地方

- “少排队”为什么还不是一个完整预测任务？
- 不提醒为什么没有 MAE，而不是 MAE=0？
- 提醒 3 次能否推出节省了多少分钟？
