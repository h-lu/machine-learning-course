## 参考核算入口

在包含学生仓库的工作目录运行：

```bash
python3 course-student-template/lessons/S13/analysis.py --output /tmp/ml-reference-S13
```

查看 `/tmp/ml-reference-S13/summary.json`，同时核对学生的数据说明、原始记录与配置。默认实验为一种可重算的比较起点。教师应保存实际配置和数值，不能把这份文件的例子或一条预期关系直接写成已运行结果。

`hidden` 控制隐层宽度，`steps`、`learning_rate`、`l2` 控制训练；增加规模需要用途理由。

## 需要核对的计算与含义

1. 说明用途与比较条件，先预计简单模型在哪类记录上不足，以及网络可能改善的关系。
2. 运行简单基线与小网络，核对输入、隐层、输出形状及训练预算，报告训练和验证过程。
3. 追踪一条记录的前向计算，解释激活、损失与参数更新怎样相连，不要求逐行手写代码。
4. 检查一类关键错误与自行设计的输入，判断改善是否稳定、成本是否值得，修改采用建议。

课堂核算可先使用[学习材料](../../../course-student-template/lessons/S13/LEARN.md)中的具体数字，再抽一条正式记录复核。核算时检查人数、单位、训练和评价资料的用途，以及输出是否真的回答学生选定的问题。相近数值允许因合理实现与随机条件有差异，不能按最后一位小数或默认模型评分。

## 可接受但方向不同的分析

### 路线1：采用小网络

非线性关系对目标用途重要，验证与关键组改善一致，训练和预测预算可承担。

### 路线2：保留简单模型

网络收益小或集中在无关记录，关键组退步或运行成本不合适；复杂度不应成为采用理由。

这些路线是条件式参考，不是标准答案：用途、信息条件或代价改变后，推荐也可能相反。学生可提出其他路线，只要能解释为何与相同问题相符，并提供可复核的比较。

## 最低合格与更有说服力的成果

最低合格：同条件的网络与基线结果；训练和验证曲线或逐步数值；一次前向计算核对；一类错误与新测试；采用建议。合格标准是理解计算与比较依据，不以网络层数或参数量评分。

更有说服力的分析会指出哪项结论依赖重要选择，并通过与用途相关的替代或条件变化说明依赖程度；不会靠增加模型、图表和篇幅获取质量分。补充的业务假设必须标明，合成数据不代表真实机构效果。

## 常见误判

- 声称使用了自动求导但程序实际为手写梯度，需按真实实现解释。
- 只展示训练下降，没有验证或同条件基线。

程序能够运行只说明计算链条可检查。不要把固定数值、指定关键词或与参考同样的推荐作为机器自动判定分析正确的条件。
