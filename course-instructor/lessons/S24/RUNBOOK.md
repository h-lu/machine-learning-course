# S24 教师运行单｜哪些请求可以交给语言模型

## 本课的实质问题

把“管理员”三个字放进普通请求，问它是否改变调用者权限；由此引出内容与权限来源不同。

学生可自选使用者、合法数据、方法与指标。检查这些选择是否会改变实验或采用决策；不要把“任意改一个参数后补理由”视为开放任务。学生可以让 AI 完成全部代码、计算与报告初稿，质量取决于问题、可复核证据和取舍是否一致。

## 课前准备

运行关键词与允许列表两路；准备不含常见攻击词的越权请求，以及含这些词的合法文本。明确本课没有连接真实系统，不能把局部演练写成全面安全保证。

从学生仓库根目录运行 `python3 lessons/S24/analysis.py`，打开本课数据说明、配置和生成结果。按当前实现核对字段；修改过程序或数据后重跑对应测试。示例数字来自本次程序，学习卡里的手算数字是另一个教学例子，不要混用。

为课堂准备已安装依赖的新环境或干净仓库副本。确认无需网络能运行，并保留一个可用的初始副本，避免学生调试失败后无从开始。不要安排真实外部动作或改变设备用途。

## 90 分钟带课安排

| 时间 | 教师重点 |
|---|---|
| 0–12 分钟 | 把“管理员”三个字放进普通请求，问它是否改变调用者权限；由此引出内容与权限来源不同。 学生写问题与预计结果。 |
| 12–25 分钟 | 用 LEARN 的数值例子讲四个概念，核对一个分母或信息路径。 |
| 25–52 分钟 | 学生借助 AI 实验；要求学生追踪动作执行前的检查位置。只有攻击拦截成绩时，补看正常任务误拒和停止办法；不鼓励堆砌攻击字符串代替系统设计。 |
| 52–65 分钟 | 检查学生自行提出的失败输入是否真正影响任务，并实际运行。 |
| 65–75 分钟 | 核对主要结果、干净副本复跑和提交位置，要求保留失败与改后的决定。 |
| 75–90 分钟 | 使用本课题库 A 两题，AI 学习后做 B 两题；反馈用于发现混淆。 |

概念题允许 AI，不把答对直接当作独立掌握的证据。B 题改变情境或论证重点；课后仍可查看解释。时间不足时先减少重复绘图与无关调参，不能删掉实际比较、失败检查或采用判断。

## 阅读成果时看什么

最低合格有明确权限、合法与不合法请求的实际结果和可执行的停止办法。较好成果解释信任来源与检查位置，修复一个机制缺陷，并如实限定演练能说明的范围。

要求学生追踪动作执行前的检查位置。只有攻击拦截成绩时，补看正常任务误拒和停止办法；不鼓励堆砌攻击字符串代替系统设计。

不能按是否采用教师示例模型判分，也不能把“暂不采用”自动评为较低质量。遇到证据不足，要求学生写出缺口和下一项能改变决定的检查。若自选任务需要额外接口或方法，让学生修改入口，不要求回到默认答案。
