# S04 参考分析与评价要点 · 预测错多少，要看结果用来做什么

## 参考核算入口

在包含学生仓库的工作目录运行：

```bash
python3 course-student-template/lessons/S04/analysis.py --output /tmp/ml-reference-S04
```

查看 `/tmp/ml-reference-S04/summary.json`，同时核对学生的数据说明、原始记录与配置。默认实验为一种可重算的比较起点。教师应保存实际配置和数值，不能把这份文件的例子或一条预期关系直接写成已运行结果。

`underestimate_cost` 是低估代价假设，`prediction_shift` 是预测整体调整量；要说明改变它们的依据。

## 默认配置的作者运行核算（2026-09-06）

线性预测MAE约0.250、RMSE约0.305；只给一条真实结果增加15后，MAE约0.500、RMSE约1.964。这组计算体现平方误差对大偏离更敏感。低估代价3是配置假设；它支持讨论，不是已知业务事实。

## 需要核对的计算与含义

1. 选择使用者，先写出主要误差怎样影响行动，并说明评价量和接受标准。
2. 在同一批记录上比较至少一条简单基线和一个候选办法；同时查看误差方向与严重偏离，不能只抄主指标。
3. 选一个与用途相关的分组或成本变化，实际检查原先选择是否仍合适。
4. 设计一条容易低估或高估的输入，据此解释何时增加余量、人工处理或停止使用。

课堂核算可先使用[学习材料](../../../course-student-template/lessons/S04/LEARN.md)中的具体数字，再抽一条正式记录复核。核算时检查人数、单位、训练和评价资料的用途，以及输出是否真的回答学生选定的问题。相近数值允许因合理实现与随机条件有差异，不能按最后一位小数或默认模型评分。

## 可接受但方向不同的分析

### 路线1：采用整体误差较小的办法

使用者关心长期一般估计，偶尔低估可补救；平均误差改善足以支持有限用途。

### 路线2：选择保守预测或保留余量

短缺代价重且难补救；接受多估和总体指标变差，以减少关键条件下低估。

这些路线是条件式参考，不是标准答案：用途、信息条件或代价改变后，推荐也可能相反。学生可提出其他路线，只要能解释为何与相同问题相符，并提供可复核的比较。

## 最低合格与更有说服力的成果

最低合格：同一批记录上的预测比较；可以核算的主指标和误差后果；一个分组或成本敏感性检查；一条错误输入；修改后的行动建议。合格标准是指标选择与用途一致，允许不同同学选不同办法。

更有说服力的分析会指出哪项结论依赖重要选择，并通过与用途相关的替代或条件变化说明依赖程度；不会靠增加模型、图表和篇幅获取质量分。补充的业务假设必须标明，合成数据不代表真实机构效果。

## 常见误判

- 将人为成本写成已知事实，要求注明来源或假设。
- 只报一个平均数字，忽略残差方向与高需求记录。

程序能够运行只说明计算链条可检查。不要把固定数值、指定关键词或与参考同样的推荐作为机器自动判定分析正确的条件。
