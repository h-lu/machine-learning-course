# S04 教师参考：比较依据，不规定唯一答案

## 最小计算

默认数据为人工教学样本，配置见学生目录。下列数值只用于独立核对起步实现，不是学生评分目标：

```json
{
  "n": 6,
  "mae": 2.5555555556,
  "rmse": 2.6874192494,
  "asymmetric_loss": 6.1111111111,
  "alerts": 2,
  "eligible": 3,
  "tp": 2,
  "fp": 0,
  "fn": 2,
  "tn": 2
}
```

先从原始样本及 `records.csv` 重算对应数量，再和汇总比较。参考脚本对本课采用不同配置，并检查训练隔离、统计分母或实际选择；不能只调用被测函数，再用其自身返回值证明正确。

## 两条合理路线

**分钟预估用途。**以 MAE 为主，同时解释高估低估和小组表现。

**有限提醒用途。**给出实际类别、预测阈值及容量，报告误报漏报，不只讲平均误差。

学生可以更换这些路线。评价的是用途、比较、失败检查和结论的关系，不奖励采用参考模型，也不因候选没胜出而扣学习质量分。

## 容易误判的地方

- 权重改变后是预测改变了，还是评价改变了？
- 阈值单位是分钟还是概率？
- 达到阈值有 5 条但只有 2 个名额时，谁决定排序？
