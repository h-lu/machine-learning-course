# S02 教师参考：比较依据，不规定唯一答案

## 最小计算

默认数据为人工教学样本，配置见学生目录。下列数值只用于独立核对起步实现，不是学生评分目标：

```json
{
  "n": 4,
  "total_rows": 8,
  "unknown_labels": 4,
  "coverage": 0.5,
  "mean_minutes": 5.0,
  "proxy_mae_observed": 1,
  "review_pairs": 4,
  "disagreements": 1,
  "agreement": 0.75
}
```

先从原始样本及 `records.csv` 重算对应数量，再和汇总比较。参考脚本对本课采用不同配置，并检查训练隔离、统计分母或实际选择；不能只调用被测函数，再用其自身返回值证明正确。

## 两条合理路线

**只统计已收到的标签。**报告覆盖率和选择偏差，推迟未支持的总体声明。

**保留代理值作为临时信息。**单独命名、标明来源，用已知样本抽查，并保留未知标签而不直接混合。

学生可以更换这些路线。评价的是用途、比较、失败检查和结论的关系，不奖励采用参考模型，也不因候选没胜出而扣学习质量分。

## 容易误判的地方

- 第 4 天的均值分母应为 4 还是 8？
- 两位标注者都写 5，为什么还可能错？
- 未知记录上的代理误差为什么不能用已知样本直接替代？
