# S12 参考分析与评价要点 · 没有故障标签，先检查哪些记录

## 参考核算入口

在包含学生仓库的工作目录运行：

```bash
python3 course-student-template/lessons/S12/analysis.py --output /tmp/ml-reference-S12
```

查看 `/tmp/ml-reference-S12/summary.json`，同时核对学生的数据说明、原始记录与配置。默认实验为一种可重算的比较起点。教师应保存实际配置和数值，不能把这份文件的例子或一条预期关系直接写成已运行结果。

`components` 控制保留维数，`review_capacity` 控制人工检查数量。

## 需要核对的计算与含义

1. 确定检查目的与名额，说明什么证据能够确认问题，什么只能提出疑点。
2. 比较低维重构分数与一种简单偏离或规则分数，核对主要维度、人数和实际名单。
3. 检查保留维数或缩放改变后，优先名单如何变化；说明变化对用途的意义。
4. 选一条高分但可能合理的记录，以及一条可能被遗漏的输入，决定如何补证据和修订队列。

课堂核算可先使用[学习材料](../../../course-student-template/lessons/S12/LEARN.md)中的具体数字，再抽一条正式记录复核。核算时检查人数、单位、训练和评价资料的用途，以及输出是否真的回答学生选定的问题。相近数值允许因合理实现与随机条件有差异，不能按最后一位小数或默认模型评分。

## 可接受但方向不同的分析

### 路线1：优先检查高重构误差

用途是查找关系破坏，相关方向有合理测量依据；保留高分的不同解释并进行人工确认。

### 路线2：使用直接规则或距离排序

用途关注量程违规或绝对极端，低维重构会漏掉沿常见方向的极端值；规则更直接。

这些路线是条件式参考，不是标准答案：用途、信息条件或代价改变后，推荐也可能相反。学生可提出其他路线，只要能解释为何与相同问题相符，并提供可复核的比较。

## 最低合格与更有说服力的成果

最低合格：可重跑的两种队列比较；维数与容量选择；两条需要不同解释的案例；人工核查步骤和采用建议。合格标准是区分可疑与已确认，并说明队列遗漏的可能性。

更有说服力的分析会指出哪项结论依赖重要选择，并通过与用途相关的替代或条件变化说明依赖程度；不会靠增加模型、图表和篇幅获取质量分。补充的业务假设必须标明，合成数据不代表真实机构效果。

## 常见误判

- 用合成数据提供的标签无说明地评成真实无标签方法准确率。
- 异常分数高就删数据，需先明确检查目的与确认依据。

程序能够运行只说明计算链条可检查。不要把固定数值、指定关键词或与参考同样的推荐作为机器自动判定分析正确的条件。
