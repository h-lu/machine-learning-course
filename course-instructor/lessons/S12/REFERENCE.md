# S12 教师参考：泛化诊断

## 独立核算

```bash
python3 course-student-template/lesson-14/analysis.py --config course-student-template/lesson-14/config-start.json --output /tmp/S12-reference
```

增加轮数时训练损失约从 0.30075 降至 0.25251，验证损失约从 0.23664 升至 0.24860，准确率不变。这削弱“只需更多训练”的解释，但差异小。默认更强参数限制验证损失约 0.345、准确率 1.0，正好说明小样本准确率与概率损失可能给出不同排序。

## 两条合理路线

可优先简化表示或加强限制并收集更多验证数据；也可保留起点，先补充与挑战输入相似的数据。选择取决于 S09–S11 具体失败证据。不得把任一路线设成唯一答案。

## 反例与评价

若训练和验证损失都高且随更多轮数同步下降，更像训练不足；若训练下降而验证上升，更支持过拟合迹象。评价学生是否事先写出两种解释、一次只改一项、正确读取训练/验证、说明 12 条样本的波动，并在测试前决定。

## 限度

本数据不能确定唯一真实原因。诊断实验的价值包括排除方向，不要求候选胜出。
