# S09 教师参考：表示与距离

## 独立核算

```bash
python3 course-student-template/lesson-11/analysis.py --output /tmp/S09-reference
```

默认 raw 验证准确率 10/12，prepared 为 11/12。起点 scaled 为 9/12，说明缩放本身并不保证改善。P02 在默认两种表示下仍可能误判；这正好用于说明明确表示新类别不等于模型必然正确。

## 两条合理路线

路线一采用 prepared，因为处理规则可重复且主验证略好。路线二保留更简单表示并对缺失/新类别转人工，适用于这些情况极少且人工容量足够。不能静默把缺失当 0 或把 social 当 web。

## 独立小计算与反例

差异 20 与 2 的原始距离约 20.10，展示大尺度字段主导。构造两个相同输入但不同标签的训练记录，即可反驳“距离近必然同类”。评价学生是否只用训练集统计量、追踪实际近邻并解释挑战记录。

## 限度

近邻仅承载表示机制；不应把本课写成近邻算法推荐。
