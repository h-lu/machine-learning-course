# S07 教师参考：模型假设与复杂度

## 独立核算

运行：

```bash
python3 course-student-template/lesson-09/analysis.py --output /tmp/S07-reference
```

默认配置只输出验证证据：简单模型训练/验证 MAE 约 1.027/1.351 分钟，二次候选约 0.290/0.307 分钟。将同一配置的 `evaluation_split` 改为 `test` 后，测试 MAE 约为 1.073/0.227；必须先记录选择再运行。R21 简单模型误差约 2.800 分钟。输入 15 时两模型预测约 37.006 与 51.065 分钟，但无真实标签，因此不能判定谁更准。

## 两条合理路线

路线一采用二次候选：验证改善明显，且只限于 0–10 的已见范围。路线二保留直线：实际系统若更看重维护和范围外保守性，可先收集高输入记录。第二条路线需承认当前验证误差较高，不能伪称性能相同。

## 反例与评价

训练误差更低不保证验证更好；本数据恰好支持二次关系，教师应另用一个带噪小样本说明复杂模型可能追随噪声。评价学生是否保持同划分、正确计算分钟 MAE、区分有标签验证与无标签外推，并在测试前选择。

## 限度

人工公式故意弯曲，只验证机制。没有真实学生 90 分钟试教时，不将作者运行写成完成性证明。
