# 发布与验证

完整课程以一个公开 GitHub 仓库发布，包括规划、学生材料、教师参考、题目答案和检查器。Gitea 保留学生模板、教师材料、检查器三个独立仓库及其历史。学生模板不嵌入教师答案；教学反馈仍依据学生自己的任务与实验，不以答案文件是否公开作为评分机制。

发布前从总工作区根目录运行：

```bash
python3 tools/validate_course.py
```

它运行学生测试、32 课教师参考覆盖测试、检查器测试，以及三个材料仓库的严格检查。程序耗时、内存环境与验证结果写进本地验收报告。严格检查验证结构和可追溯条件，不代表文案已经通过真实课堂试教。

教师还应阅读当课 README 的前几段，确认学生能知道要做什么、为什么做、提交什么、失败后如何继续。抽一个不同于示例的方案，确认它可以完成必做判断，且不会被格式工具误判为错误。

概念题的源文件在 `lessons/ID/questions.json`，含答案与解释。运行 `python3 ../tools/sync_question_bank.py` 更新检查器的题库。服务默认只向学生返回题干与选项；答案保留在教师/服务侧。题库版本与发布内容一同记录。

发布前保留旧提交的归档标签，以可快进方式更新 Gitea 默认分支，不改写已有历史。GitHub 发布包不包含嵌套 `.git`、本机环境、临时输出或完整旧版压缩包。发布位置与版本见 [GitHub 课程入口](https://github.com/h-lu/machine-learning-course)。本流程发布课程仓库；概念题读取服务的生产运行需单独配置，不能把代码推送称为服务已上线。
