# 第 27–32 课反馈、运行与迁移模块发布记录：2026-09-21

## 范围与版本边界

本记录适用于学生 `lesson-27` 至 `lesson-32`，对应 S25–S30。第 01–04 课已授课并冻结，本模块不追溯改变其作业、概念题或成绩依据。

六课依次处理反馈遗漏、奖励错设、运行监测与恢复、效果/延迟/成本、场景迁移和可重跑交付。最终汇集题库目标版本为 `ml-v13-course-map-2026-09-21`；最终提交、题库摘要和生产信息在整仓验收后补记。

| 课次 | 标题 | 主要可复核证据 |
|---|---|---|
| S25／第 27 课 | 反馈怎样帮助学习，又会遗漏什么 | 多个随机种子下的已选反馈、平均回报和回答覆盖；未选反馈不进入策略输出 |
| S26／第 28 课 | 一个好分数会不会鼓励错误行为 | 即时分、延迟后果、长期回报及可见状态改变后的轨迹 |
| S27／第 29 课 | 运行条件变了，怎样发现并处理 | 参考/当前批次、模型版本、延迟标签、报警和旧版本恢复 |

| S29／第 31 课 | 换一个场景，原来的方案还能用吗 | 相同八条新场景请求上的公平比较及新增未覆盖英语请求 |
| S30／第 32 课 | 怎样交付作品，并说明下一轮该学什么 | 运行前固定候选、最后评价、输入/配置/产物摘要和可重跑命令 |

## 学生路径与产物

每课的 [S25](../lessons/S25/COLD_READ.md)、[S26](../lessons/S26/COLD_READ.md)、[S27](../lessons/S27/COLD_READ.md)、[S28](../lessons/S28/COLD_READ.md)、[S29](../lessons/S29/COLD_READ.md)和[S30](../lessons/S30/COLD_READ.md)记录都按 README 首屏 → SUPPORT → 所需 LEARN → 起点 → 支持配置 → 个人设置 → 最终运行 → 提交检查的顺序完成，没有先读取教师答案。

两轮临时副本演练覆盖六课共 34 个开始、起点、支持、个人检查、最终运行、提交检查和整仓重跑步骤，全部退出码为 0。`scripts/course.py ci` 可以重新生成六课确定性提交产物。

S28 将机器实测时间只保存在 `timings.csv`；`summary.json`、`records.csv` 和 `changed_records.csv` 保持确定性，并实际验证了替换一条输入会改变缓存命中。S29 将原八条共同分母与加入第九条请求后的比较分开保存。S30 要求在打开最后评价前固定候选；`manifest.json` 使用仓库相对路径、`<OUTPUT_DIR>` 占位符和 SHA-256，替换输出目录后，两个目录的确定性产物逐字节一致。

## 证据边界

冷读是模型模拟；34 个步骤和整仓 CI 是实际命令运行。没有真人学生试读，也没有 90 分钟课堂计时。毫秒耗时只代表验收机器，不能作为学生设备应达到的固定值；离线模拟的反馈、奖励、报警和成本也不能直接说明真实部署效果。
