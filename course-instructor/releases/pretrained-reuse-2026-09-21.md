# 第 15–20 课预训练模型复用模块发布记录：2026-09-21

## 范围与版本边界

本记录适用于学生 `lesson-15` 至 `lesson-20`，对应 S13–S18。第 01–04 课已授课并冻结，本模块不会改变其学生要求、题目解释或成绩依据。

六课共用“离线课程问答助手”情境，依次区分能力来源、输入信息路径、提示比较、检索增强、适配路线和开放结果评价。实验使用人工构造的小数据、规则生成器、微型机制或固定候选；材料明确这些证据不能冒充真实预训练大模型的新能力。最终汇集题库目标版本为 `ml-v13-course-map-2026-09-21`。

| 课次 | 标题 | 实际核对的对象 |
|---|---|---|
| S13／第 15 课 | 预训练模型的能力来自哪里 | 三条能力变化路线、参数更新范围和能力边界 |
| S14／第 16 课 | 输入怎样影响模型能够利用的信息 | 注意力权重、因果遮罩及改变未来值对较早输出的影响 |
| S15／第 17 课 | 提示改进了，还是只适配了见过的例子 | 开发问题上的重复响应、匹配新提示的新输出及锁定后的 final |
| S16／第 18 课 | 怎样补充资料，而不是期待模型猜对 | 检索结果、回答支持、失败阶段和无法回答请求 |
| S17／第 19 课 | 该改提示、补上下文，还是改参数 | 相同案例上的两条固定适配路线及其改变环节 |
| S18／第 20 课 | 没有唯一答案时，怎样判断真的变好了 | 四维评价、两位评分、分歧、顺序偏差代理和独立 final |

## 学生路径与产物

[模块冷读记录](../reviews/s13-s18-pretrained-module-cold-read-2026-09-21.md)按 README → SUPPORT → 所需 LEARN → 实际命令 → 指定 CSV 行 → 个人单因素配置 → 必要时 final → 报告与提交检查的顺序执行。全新副本演练覆盖六课的 start、support、personal、必要时 final、默认产物、提交文件检查和默认入口重跑，均成功；六个默认入口各约 0.02 秒，这只是程序运行耗时。

本轮还修正了 Windows 学生复制配置的替代说明、final 配置必须带入已采用阈值、命令执行目录、常见 JSON 错误提示，以及输出中绝对路径造成的新副本哈希差异。

## 已有验收证据

- 模块记录中的学生和教师严格材料检查均为 32 课、0 项需处理。
- `course-student-template/tests/test_pretrained_module.py` 在该次模块验收中为 8 项通过，覆盖单字段配置、参数更新范围、因果遮罩、提示新输出、检索与回答失败、未知固定路线拒绝、评价顺序和新副本确定性重建。
- 每课五个知识点和 A/B 各五题已逐对人工阅读；同编号检查同一关系，B 使用不同情境，学习说明没有复述题目情境。模块记录中的 S14、S15、S18 数值答案已经独立重算。
- 模块记录写成时，共享旧运行测试和教师参考尚未全部迁移，因此当时的全量旧测试存在失败，不能把那次结果写成整仓通过。最终发布必须以本轮所有并行修改完成后重新运行的 `tools/validate_course.py` 和完整 `ml-check` 测试为准。
- 模块开发记录曾使用 `ml-v10-pretrained-2026-09-21` 标识源题；生产发布以最终汇集的 v13 文件、摘要和历史场次快照为准，不用旧开发标识解释线上状态。

## 证据边界

冷读由模型模拟，没有真人参与，也没有课堂计时。命令运行证明页面、字段和数字能接起来，不能证明学生能在 90 分钟内完成，也不能证明学生不会把人工注意力值、固定响应、规则生成器或模拟评分器误解为真实大模型能力。真人试读必须把这类误解作为单独观察项。
