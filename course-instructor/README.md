# 教师工作区

课程目标是让学生掌握借助 AI 提出问题、构建方案、获得证据和持续改进所需要的知识。教师用必要关系、小实验与实质选择组织课堂，不按模型名单逐一讲解，也不让学生只负责检查 AI 输出。

2026 班第 01–04 课已经授课，继续按当时采用的学生材料、题目和成绩依据解释，本轮不追溯修改。第 05–32 课已按新学习地图形成完整课包；采用范围、题库版本、冷读和部署状态见[发布说明](RELEASE.md)。成绩权重和提交接口保持不变。

## 教师需要核对什么

每课规定主要关系、最小比较、自设计检查与资源条件，同时保留问题、数据、方法和结论的选择。起步实验只帮助开始；参考分析提供合理替代路线与独立核算，不规定唯一答案。五个正式模块各保留一次原方案与修订候选比较，有理由保留简单方案也是有效成果。

作品与理解分别审查：能运行不等于理解；用样本解释、短计算、条件变化或换情境题检查关系。保持课堂项目完成 25 分、代表作品质量 25 分与期末考试 50 分，具体按评分规则执行。

完整 GitHub 仓库公开教师参考和答案，学生目录不嵌入答案。`ml-check` 提供登录后的 A/B 概念练习；历史场次读取创建场次时保存的题目快照，新场次读取当前发布题库。题库切换与恢复办法见发布说明。

实验耗时与结构检查可由程序验证；学生能否在 90 分钟内作出实质选择并解释结果，需要真实试教。教师应同时记录通过的项目与尚未验证的部分，不把规划合并、代码推送或单次软件测试称为课程已经上线。

## 第 01–04 课：已授课版本

这四课已经完成教学并经过多轮调整。学生仓库中的 `lesson-01` 至 `lesson-04` 保持实际授课版本；旧场次分别保存当时使用的 C01、C02、S01、S02 题目，后续题库更新不改变旧记录的含义。

## 第 05–32 课：本轮课包

后续 28 课按五条连续主线组织：问题与评价，学习、表示与泛化，预训练模型复用，模型、工具与人的协作，以及反馈、运行与迁移。每课包括学生 README、LEARN、SUPPORT、数据、配置、程序、报告提示，教师 RUNBOOK、REFERENCE 和五对 A/B 概念题。课程使用人工小数据、规则模拟、微型模型或有来源的固定响应时，教师必须说明证据能验证什么，不能把它们说成真实用户结果或真实大模型能力。
