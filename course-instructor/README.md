# 教师工作区

本课程让学生通过 32 个小项目学习现代机器学习。每课规定概念和判断要求，保留问题、数据、方法和结论的选择空间。起步实验帮助学生开始，参考分析用于检验推理，不用于规定唯一答案。

- [逐课运行单、参考分析和概念题](LESSON_INDEX.md)
- [课程设计标准](COURSE_DESIGN.md)
- [评价办法](GRADING.md)
- [发布与验证](RELEASE.md)

按课程作者的发布安排，完整课程、教师参考与题目答案在 GitHub 公开，供学习、备课与课程研究使用。学生模板仍单独组织，教师答案不嵌入学生任务目录。参考案例覆盖 C01、C02、S01–S30；覆盖脚本在临时输出目录运行，不改写学生原文件。

本版的实验、文档结构和数值检查可以在本地验证。普通学生是否能在 90 分钟内完成自主选择和解释，需要真实试教；CPU 上程序耗时短不能代替这项判断。
