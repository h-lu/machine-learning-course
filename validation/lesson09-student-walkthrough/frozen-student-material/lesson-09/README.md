# 第09课（S07）：同样的信息，线性模型和浅树怎样拟合

## 本课要解决什么问题

Bike 第8课中的误差，是否与模型只能把各输入的贡献相加有关？继续估计同小时实际天气和日历已知时的租借总数，比较线性模型与浅树。已见旧测试只作历史证据，本课在原训练、验证部分继续开发。

## 本课要学会什么

- 参数由冲突记录共同决定：在例题理解关系后，用自己的记录说明。
- 加性线性关系：在例题理解关系后，用自己的记录说明。
- 浅树的阈值与叶均值：在例题理解关系后，用自己的记录说明。
- 同信息公平比较：在例题理解关系后，用自己的记录说明。
- 历史测试与结论限制：在例题理解关系后，用自己的记录说明。

[LEARN完整小例](LEARN.md)解释计算；无机器学习先修要求。继续沿用Python 3.10+和NumPy。

## 课堂任务

选择一个值得解释的误差情形，并决定比较应强调什么指标或分组。两个模型必须使用相同原始字段、训练记录及验证记录；模型内部表示可不同，但不能暗中多给一方信息。构建线性与浅树预测，追踪一个真实小时的各项线性贡献和树路径；在同一批记录上核算两者的误差，检查所选失败情形。解释哪项证据支持保留或改变模型，不能从模型优劣推出干预效果。

至少保留一个实际例子的输入到输出追踪、一个同条件公平比较、一个用途限制；说明至少两个会影响实验或结论的选择。AI可协助完成代码、计算、分析与提交；无需完整对话日志，关键证据必须能核对。

有后果的自主选择包括：失败情形与用途指标；允许字段的选取或浅树深度。字段必须同时给两方，深度只能用开发数据选择。 默认路线帮助启动，不是全班必须照抄的研究。可以自拟等价数据/方法路线，但必须提前具备相同的真实数据、隔离评价、实际追踪、公平比较和本课概念证据；替代路线未准备好时先使用默认资源。

## 完成步骤

在学生仓库根目录运行起点：

```bash
python3 lesson-09/analysis.py
```

输出在本课artifacts/baseline。起点只给一个必要基线，不完成标准任务。再运行时用 `--output lesson-09/artifacts/你的新目录` 保留旧结果。你自主安排阅读、实现、比较和写作；[SUPPORT](SUPPORT.md)提供可选操作入口，[HINTS](HINTS.md)按卡点查，[EXERCISES](EXERCISES.md)检查能否换情境解释。

## 必须提交什么

沿用contract.json、submission.json与report.md。保存自己的问题、两项重要选择、运行命令/配置、实际例子、两方案同记录结果、失败检查、建议与限制；把submission.json中run/artifacts改成可重生成自己主要结果的路径。用v2-l09-final标记课堂版本，修订保留原标签并用v2-l09-revision-1等；上传按原[提交流程](../docs/WORKFLOW.md)，本课不增加评分项。

## 不同起点怎么做

先读完整人工小例并追踪起点的一条真实记录，再围绕自己的失败问题完成比较。较快者可检查第二个分组、不同训练预算或输入扰动，但要明确哪个因素改变、证据是否仍公平。证据支持保留原方案或暂停使用同样合理。
