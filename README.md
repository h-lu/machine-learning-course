# 现代机器学习：从问题到可检验的作品

16 周，32 次课。每次课学习一种理解数据或模型的办法，并用它完成一个小项目。你可以使用 AI 写代码、计算和整理表达；你需要说清自己要解决什么问题，为什么这样比较，以及结果能支持什么行动。

课程允许不同的作品：预测工具、数据检查程序、检索系统、图像实验、决策模拟器，或一份说明暂时不应使用模型的实验报告。每种作品都要有能运行的程序、具体的检查和有根据的结论。
