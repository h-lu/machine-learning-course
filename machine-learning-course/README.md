# 机器学习2026–2027课程规划

课程共32次，每次90分钟，仍按两次入门和五个六课模块组织，成绩制度沿用既有[评分说明](../course-instructor/GRADING.md)。

[完整逐课大纲](COURSE_MAP.md)逐次写明目标、概念、先修、真实数据与贯穿项目、90分钟活动、当堂作品、自检、课后挑战和衔接。前八课由真实分析逐步进入模型理解与严格验证；后续逐步进入表示、优化、概率、预训练、检索工具、反馈与迁移。

本轮具体材料只制作01–08。[学生入口](../course-student-template/README.md)和[教师入口](../course-instructor/LESSON_INDEX.md)只加载这些课包。09–32为完整规划，数据/模型资源和新输出尚待以后制作与验收；旧具体材料已经归档。

2026班第1–7课已授课，新版用于补学与改善当前教学，不追溯增加旧作业要求、改旧成绩或覆盖历史场次。本轮为独立本地副本，未推送、部署或切换线上服务。
