# 机器学习项目课

机器学习能帮助人从数据中作判断，但一个高分模型未必适合实际使用。这门课从简单规则和小数据开始，学习回归、分类、聚类、神经网络、语言模型与强化学习，再把其中一件作品带到新场景中重新检验。

课程共 16 周、32 次课，每次 90 分钟。每次都完成一个可以运行、检查和解释的小项目。前后项目可以共用数据和代码，也可以重新选题。

先读 [32 课学习地图](COURSE_MAP.md)，再到 [学生仓库](../course-student-template/README.md) 开始。所有必做实验使用普通 CPU、小型离线数据和预先安装的环境；单次运行目标不超过 3 分钟，从头重跑目标不超过 5 分钟。

## 你可以决定什么

每课有必须学会的概念，也有必须完成的检查。问题的使用者、数据、评价办法和使用建议可以由你选择；可以使用给定起点，也可以提出自己的问题。换题时，说明新题为什么仍需要本课概念，并把数据缩到课堂内能检验的大小。

例如，分类课可以研究如何安排有限复核名额，也可以研究何时提醒用户。两者对漏报和误报的要求不同，应有不同评价办法。你不用选教师使用的模型，但要拿出能支持自己选择的比较。

## 每课怎样学习

先写下预计会看到的结果，再让 AI 帮助解释、编程或修改。运行后，检查数据、指标的分母和一个具体样本；设计一条容易让模型出错的输入；根据结果保留或修改原来的判断。最后在新输出目录重新运行，保存程序、结果和说明。

程序运行失败时，可以缩小数据、回到入门示例，或使用本课给出的中间结果继续诊断。实验不支持使用模型时，说明失败发生在哪里、现阶段能做什么。失败本身不扣分；没有检查就宣称成功不能作为项目完成的依据。

## 怎样评价

评价看问题是否清楚、比较是否公平、检查是否切中用途、建议是否有证据，以及别人能否重新得到主要结果。模型大小、代码长度、图表数量和 AI 对话长度不单独计分。合理的规则方案和有依据的停止使用结论，都可以成为优秀作品。

课末的概念练习帮助发现误解：先独立判断，再用 AI 学习，最后回答一个不同场景的问题。平时成绩 50 分由课堂项目完成情况 25 分和五件代表作品质量 25 分组成；C01、C02 为不计分入门课，S01–S30 按五个模块每模块六课取最好五次。每次课的 A/B 概念检查由 [ml-check](../ml-check/README.md) 提供匿名完成凭据；详细补交、修订和考试安排由开课教师在开课前公布。
